# pdf2audio

Convertisseur PDF → livre audio (.m4a), 100 % local : extraction intelligente
du texte, description des images via un modèle de vision local (Ollama),
synthèse vocale (Kokoro-TTS ou Piper-TTS), fusion en un seul fichier audio.

Deux façons de l'utiliser : une **interface graphique** (recommandée) ou la
**ligne de commande**.

## 1. Installation (une seule fois)

Prérequis à installer manuellement avant de commencer :

- **Python 3.10+** — https://www.python.org/downloads/ (coche bien *"Add
  python.exe to PATH"* pendant l'installation)
- **FFmpeg** — https://www.gyan.dev/ffmpeg/builds/ (build "essentials"),
  à décompresser puis à ajouter au PATH Windows
- **Ollama** — https://ollama.com, puis dans un terminal :
  ```
  ollama pull llama3.2
  ollama pull llama3.2-vision
  ```

Ensuite, dans le dossier du projet, double-clique sur **`1_installer.bat`**.
Ce script crée un environnement Python isolé (`.venv`) et installe tout
automatiquement, sans toucher à ton installation Python globale.

## 2. Utilisation — Interface graphique

Double-clique sur **`2_lancer.bat`**. Ton navigateur s'ouvre avec l'interface :
dépose ton PDF, ajuste les options si besoin, clique sur *Convertir*, et
télécharge le fichier audio à la fin.

> Le `.bat` utilise toujours `python -m streamlit`, donc pas de souci de PATH
> même si la commande `streamlit` seule n'est pas reconnue par Windows.

## 3. Utilisation — Ligne de commande

```
.venv\Scripts\activate
python main.py --pdf mon_livre.pdf --output mon_livre.m4a ^
    --text-model llama3.2 --vision-model llama3.2-vision ^
    --tts-engine kokoro --voice ff_siwis
```

Options utiles :

| Option | Rôle |
|---|---|
| `--chunk-pages N` | taille des sections si le PDF n'a pas de sommaire |
| `--max-chars N` | taille max d'un bloc envoyé au LLM |
| `--tts-engine kokoro\|piper` | moteur vocal |
| `--voice` | voix Kokoro (ex: `ff_siwis` pour du français) |
| `--piper-model` / `--piper-binary` | requis si `--tts-engine piper` |
| `--no-resume` | ignore une conversion précédente interrompue |
| `--keep-temp` | conserve les fichiers audio intermédiaires |

La conversion reprend automatiquement là où elle s'était arrêtée si elle est
interrompue (sauf avec `--no-resume`).

## Dépannage rapide

- **`ModuleNotFoundError`** → relance `1_installer.bat`.
- **`streamlit : terme non reconnu`** → utilise `2_lancer.bat`, ou tape
  `python -m streamlit run streamlit_app.py` toi-même.
- **Erreur FFmpeg / export échoue** → FFmpeg doit être dans le PATH, vérifie
  avec `ffmpeg -version` dans un terminal.
- **Erreur Ollama / connexion refusée** → lance `ollama serve` dans un
  terminal séparé, et vérifie que les modèles sont bien téléchargés.

#!/usr/bin/env python3
"""
Convertisseur PDF -> Audio M4A enrichi, 100% local.

Exemple :
    python main.py --pdf mon_livre.pdf --output mon_livre.m4a \
        --text-model llama3.2 --vision-model llama3.2-vision \
        --tts-engine kokoro --voice ff_siwis
"""
import argparse
import sys
from pathlib import Path

from pdf2audio.config import Config
from pdf2audio.pipeline import run_pipeline


def parse_args():
    p = argparse.ArgumentParser(description="Convertisseur PDF en Audio M4A enrichi (100% local).")
    p.add_argument("--pdf", required=True, help="Chemin vers le fichier PDF source.")
    p.add_argument("--output", required=True, help="Chemin du fichier .m4a à produire.")
    p.add_argument("--tmp-dir", default="./_pdf2audio_tmp", help="Dossier de travail temporaire.")

    p.add_argument("--chunk-pages", type=int, default=20,
                   help="Taille des sections en pages si aucun sommaire n'est détecté.")
    p.add_argument("--max-chars", type=int, default=1800,
                   help="Taille max d'un bloc de texte envoyé au LLM à chaque appel.")

    p.add_argument("--ollama-host", default="http://localhost:11434")
    p.add_argument("--text-model", default="llama3.2")
    p.add_argument("--vision-model", default="llama3.2-vision")

    p.add_argument("--language", default="fr")

    p.add_argument("--tts-engine", choices=["kokoro", "piper"], default="kokoro")
    p.add_argument("--voice", default="ff_siwis", help="Voix Kokoro (ignoré si Piper).")
    p.add_argument("--piper-model", default="", help="Chemin du modèle .onnx Piper.")
    p.add_argument("--piper-binary", default="piper")

    p.add_argument("--no-resume", action="store_true", help="Ignore toute reprise précédente.")
    p.add_argument("--keep-temp", action="store_true", help="Conserve les fichiers audio intermédiaires.")

    p.add_argument("--hf-token", default="",
                   help="Jeton d'accès Hugging Face pour le téléchargement du modèle Kokoro "
                        "(sinon variable d'environnement HF_TOKEN / fichier .env).")

    return p.parse_args()


def main():
    args = parse_args()

    if not Path(args.pdf).exists():
        print(f"Fichier introuvable : {args.pdf}", file=sys.stderr)
        sys.exit(1)

    config = Config(
        pdf_path=args.pdf,
        output_path=args.output,
        tmp_dir=Path(args.tmp_dir),
        chapter_chunk_pages=args.chunk_pages,
        max_chars_per_llm_call=args.max_chars,
        ollama_host=args.ollama_host,
        text_model=args.text_model,
        vision_model=args.vision_model,
        language=args.language,
        tts_engine=args.tts_engine,
        tts_voice=args.voice,
        piper_model_path=args.piper_model,
        piper_binary=args.piper_binary,
        resume=not args.no_resume,
        keep_temp=args.keep_temp,
    )
    if args.hf_token:
        # Ne remplace la valeur par défaut (env HF_TOKEN / .env) que si explicitement fournie.
        config.hf_token = args.hf_token

    run_pipeline(config)


if __name__ == "__main__":
    main()

def build_command(pdf_path: Path, output_path: Path, tmp_dir: Path) -> list:
    cmd = [
        sys.executable,
        str(MAIN_SCRIPT),
        "--pdf", str(pdf_path),
        "--output", str(output_path),
        "--tmp-dir", str(tmp_dir),
        "--tts-engine", tts_engine,
        "--language", language,
    ]
    optional_flags = {
        "--voice": voice,
        "--chunk-pages": chunk_pages,
        "--max-chars": max_chars,
        "--ollama-host": ollama_host,
        "--text-model": text_model,
        "--vision-model": vision_model,
        "--piper-model": piper_model,
        "--piper-binary": piper_binary,
    }
    for flag, value in optional_flags.items():
        if value.strip():
            cmd.extend([flag, value.strip()])

    if no_resume:
        cmd.append("--no-resume")
    if keep_temp:
        cmd.append("--keep-temp")

    return cmd


def run_conversion(pdf_bytes: bytes, pdf_filename: str):
    work_dir = Path(tempfile.mkdtemp(prefix="pdf2audio_gui_"))
    pdf_path = work_dir / pdf_filename
    pdf_path.write_bytes(pdf_bytes)

    output_path = work_dir / (output_name if output_name.strip() else default_output_name)
    tmp_dir = work_dir / "tmp"
    tmp_dir.mkdir(exist_ok=True)

    cmd = build_command(pdf_path, output_path, tmp_dir)

    # Le jeton HF passe par une variable d'environnement du sous-processus plutôt que par un
    # argument en ligne de commande, pour ne jamais apparaître dans les logs affichés ci-dessous
    # ni dans la liste des processus du système.
    child_env = os.environ.copy()
    if hf_token.strip():
        child_env["HF_TOKEN"] = hf_token.strip()

    log_lines = []
    progress_bar = progress_placeholder.progress(0, text="Démarrage de la conversion…")

    process = subprocess.Popen(
        cmd,
        cwd=str(APP_DIR),
        env=child_env,
        stdout=subprocess.PIPE,
        stderr=subprocess.STDOUT,
        text=True,
        bufsize=1,
    )

    last_render = 0.0
    for line in iter(process.stdout.readline, ""):
        if not line:
            break
        log_lines.append(line.rstrip("\n"))

        match = PROGRESS_RE.findall(line)
        if match:
            try:
                pct = min(int(match[-1]), 100)
                progress_bar.progress(pct, text=line.strip()[:120])
            except ValueError:
                pass

        now = time.time()
        if now - last_render > 0.15:
            log_placeholder.markdown(
                f'<div class="log-box">{"<br>".join(log_lines[-300:])}</div>',
                unsafe_allow_html=True,
            )
            last_render = now

    process.wait()
    log_placeholder.markdown(
        f'<div class="log-box">{"<br>".join(log_lines[-300:])}</div>',
        unsafe_allow_html=True,
    )

    if process.returncode == 0 and output_path.exists():
        progress_placeholder.progress(100, text="Conversion terminée ✔️")
        audio_bytes = output_path.read_bytes()
        result_placeholder.success("🎉 Ton livre audio est prêt !")
        result_placeholder.download_button(
            "⬇️ Télécharger l'audio",
            data=audio_bytes,
            file_name=output_path.name,
            mime="audio/mp4",
            use_container_width=True,
        )
    else:
        progress_placeholder.empty()
        result_placeholder.error(
            f"La conversion a échoué (code {process.returncode}). "
            "Regarde le journal ci-dessus pour comprendre pourquoi."
        )


if launch and uploaded_pdf is not None:
    run_conversion(uploaded_pdf.getvalue(), uploaded_pdf.name)

from __future__ import annotations

import logging
from pathlib import Path
from typing import List

from pydub import AudioSegment

log = logging.getLogger(__name__)


def merge_wavs_to_segment(wav_paths: List[Path], silence_ms: int) -> AudioSegment:
    combined = AudioSegment.silent(duration=0)
    silence = AudioSegment.silent(duration=silence_ms)
    for p in wav_paths:
        if not p.exists():
            continue
        try:
            seg = AudioSegment.from_file(p)
        except Exception as e:
            log.warning("Segment audio illisible, ignoré (%s) : %s", p, e)
            continue
        combined += seg + silence
    return combined


def export_m4a(segment: AudioSegment, output_path: Path, bitrate: str = "128k") -> None:
    output_path.parent.mkdir(parents=True, exist_ok=True)
    # Le conteneur .m4a est un MP4 audio-only encodé en AAC.
    segment.export(str(output_path), format="mp4", codec="aac", bitrate=bitrate)
    log.info("Fichier audio final écrit : %s", output_path)


def merge_chapter_wavs(chapter_wav_paths: List[Path], output_path: Path,
                        silence_between_chapters_ms: int) -> None:
    full = merge_wavs_to_segment(chapter_wav_paths, silence_between_chapters_ms)
    if len(full) == 0:
        raise RuntimeError("Aucun segment audio valide n'a pu être fusionné.")
    export_m4a(full, output_path)

(Llama 3.2 Vision ou LLaVA, servis par Ollama)."""
from __future__ import annotations

import io
import logging

from PIL import Image

from .config import Config

VISION_SYSTEM_PROMPT = """Tu décris une image extraite d'un document, pour une personne qui
l'écoute sans la voir. Rédige 2 à 4 phrases en langage naturel et fluide, formant une transition
orale intégrée au texte (par exemple en commençant par "L'illustration ci-dessus montre...",
"Le schéma représente...", "On y voit..."). Ne mentionne jamais qu'il s'agit d'une consigne, ne
liste pas de mots-clés : produis directement une narration lisible à voix haute."""

MIN_IMAGE_DIMENSION = 40  # ignore les icônes/puces décoratives trop petites


def _should_skip(image_bytes: bytes) -> bool:
    try:
        with Image.open(io.BytesIO(image_bytes)) as im:
            w, h = im.size
            return w < MIN_IMAGE_DIMENSION or h < MIN_IMAGE_DIMENSION
    except Exception:
        return True


def describe_image(image_bytes: bytes, config: Config) -> str:
    if not image_bytes or _should_skip(image_bytes):
        return ""

    messages = [
        {"role": "system", "content": VISION_SYSTEM_PROMPT},
        {"role": "user", "content": "Décris cette image pour une lecture audio."},
    ]
    try:
        description = chat(config, config.vision_model, messages, images_b64=[image_to_b64(image_bytes)])
    except Exception as e:
        log.warning("Échec de la description d'image, image ignorée : %s", e)
        return ""

    return description.strip()

"""Client HTTP minimal pour Ollama (100% local, pas de dépendance externe hors `requests`)."""
from __future__ import annotations

import base64
import json
import logging

import requests

from .config import Config

log = logging.getLogger(__name__)


class OllamaError(RuntimeError):
    pass


def chat(config: Config, model: str, messages: list, images_b64: list | None = None) -> str:
    """Appelle /api/chat en mode non streaming et retourne le texte de la réponse."""
    url = f"{config.ollama_host.rstrip('/')}/api/chat"
    if images_b64:
        # Attache les images au dernier message utilisateur (format multimodal Ollama)
        messages = [dict(m) for m in messages]
        messages[-1]["images"] = images_b64

    payload = {"model": model, "messages": messages, "stream": False}
    try:
        resp = requests.post(url, json=payload, timeout=config.llm_timeout)
        resp.raise_for_status()
    except requests.RequestException as e:
        raise OllamaError(
            f"Impossible de contacter Ollama à {config.ollama_host} (modèle '{model}'). "
            f"Vérifiez que `ollama serve` tourne et que le modèle est installé "
            f"(`ollama pull {model}`). Détail : {e}"
        ) from e

    data = resp.json()
    return data.get("message", {}).get("content", "").strip()


def image_to_b64(image_bytes: bytes) -> str:
    return base64.b64encode(image_bytes).decode("utf-8")

"""
Extraction séquentielle du PDF avec PyMuPDF (fitz).

- Découpe le document en "chapitres" (via la table des matières si disponible,
  sinon par blocs de N pages) pour un traitement en flux et une empreinte
  mémoire bornée, quelle que soit la taille du document (5 à 1000+ pages).
- Détecte automatiquement en-têtes / pieds de page répétitifs.
- Détecte les notes de bas de page via la position et la taille de police.
- Restitue un flux ordonné d'unités "texte" et "image" dans l'ordre de lecture.
"""
from __future__ import annotations

import statistics
from dataclasses import dataclass
from typing import Iterator, List, Optional, Tuple

try:
    import pymupdf as fitz  # PyMuPDF (nom de paquet moderne, supprime le warning de dépréciation)
except ImportError:  # compat versions de PyMuPDF trop anciennes pour exposer le module `pymupdf`
    import fitz

from .config import Config


@dataclass
class ChapterRange:
    index: int
    title: str
    start_page: int  # inclus, 0-based
    end_page: int     # exclus, 0-based


@dataclass
class ContentUnit:
    kind: str          # "text" ou "image"
    page: int
    text: str = ""
    xref: int = 0


def get_chapter_ranges(doc: fitz.Document, config: Config) -> List[ChapterRange]:
    """Découpe le document en chapitres à partir du sommaire (TOC) si présent,
    sinon en tranches fixes de `chapter_chunk_pages` pages."""
    toc = doc.get_toc(simple=True)  # [[niveau, titre, page_1indexed], ...]
    n_pages = doc.page_count

    top_level = [t for t in toc if t[0] == 1] if toc else []
    if len(top_level) >= 2:
        ranges = []
        for i, (_, title, page1) in enumerate(top_level):
            start = max(page1 - 1, 0)
            end = (top_level[i + 1][2] - 1) if i + 1 < len(top_level) else n_pages
            if end > start:
                ranges.append(ChapterRange(i, title.strip() or f"Chapitre {i+1}", start, end))
        # Fusionne les chapitres trop courts avec le suivant pour éviter des micro-appels LLM
        merged: List[ChapterRange] = []
        for r in ranges:
            if merged and (r.end_page - r.start_page) < 2:
                merged[-1].end_page = r.end_page
            else:
                merged.append(r)
        if merged:
            return merged

    # Repli : découpage fixe par nombre de pages
    step = max(config.chapter_chunk_pages, 1)
    ranges = []
    for i, start in enumerate(range(0, n_pages, step)):
        end = min(start + step, n_pages)
        ranges.append(ChapterRange(i, f"Section {i+1} (pages {start+1}-{end})", start, end))
    return ranges


def _collect_boilerplate_lines(doc: fitz.Document, config: Config) -> set:
    """Identifie les lignes récurrentes en haut/bas de page (en-têtes, pieds de page,
    numérotation) en comparant leur fréquence d'apparition sur un échantillon de pages."""
    from collections import Counter

    counts: Counter = Counter()
    n_pages = doc.page_count
    sample = range(0, n_pages, max(1, n_pages // min(n_pages, 60) or 1))

    for pno in sample:
        page = doc[pno]
        h = page.rect.height
        margin = h * config.header_footer_margin_ratio
        for block in page.get_text("blocks"):
            x0, y0, x1, y1, text, *_ = block
            text = text.strip()
            if not text or len(text) > 90:
                continue
            if y0 <= margin or y1 >= h - margin:
                counts[text] += 1

    return {t for t, c in counts.items() if c >= config.header_footer_min_repeat}


def _median_font_size(page: fitz.Page) -> float:
    sizes = []
    d = page.get_text("dict")
    for block in d.get("blocks", []):
        for line in block.get("lines", []):
            for span in line.get("spans", []):
                if span.get("text", "").strip():
                    sizes.append(span["size"])
    return statistics.median(sizes) if sizes else 10.0


def _is_footnote(y0: float, y1: float, page_height: float, font_size: float,
                  median_size: float, config: Config) -> bool:
    near_bottom = y1 >= page_height * (1 - config.header_footer_margin_ratio * 1.5)
    small_font = font_size <= median_size * config.footnote_font_ratio
    return near_bottom and small_font


def iter_chapter_content(doc: fitz.Document, chapter: ChapterRange,
                          boilerplate: set, config: Config) -> Iterator[ContentUnit]:
    """Produit un flux ordonné d'unités de contenu (texte / image) pour un chapitre,
    en filtrant en-têtes, pieds de page et notes de bas de page."""
    for pno in range(chapter.start_page, chapter.end_page):
        page = doc[pno]
        h = page.rect.height
        margin = h * config.header_footer_margin_ratio
        median_size = _median_font_size(page)

        # Éléments positionnés : texte (avec taille de police) + images, triés par position verticale
        elements: List[Tuple[float, str, object]] = []

        d = page.get_text("dict")
        for block in d.get("blocks", []):
            if block.get("type") != 0:
                continue
            y0 = block["bbox"][1]
            y1 = block["bbox"][3]
            block_text_parts = []
            font_sizes = []
            for line in block.get("lines", []):
                for span in line.get("spans", []):
                    t = span.get("text", "")
                    if t.strip():
                        block_text_parts.append(t)
                        font_sizes.append(span["size"])
            text = "".join(block_text_parts).strip()
            if not text:
                continue
            if text in boilerplate:
                continue
            if y0 <= margin or y1 >= h - margin:
                continue
            avg_font = sum(font_sizes) / len(font_sizes) if font_sizes else median_size
            if _is_footnote(y0, y1, h, avg_font, median_size, config):
                continue
            elements.append((y0, "text", text))

        for img in page.get_images(full=True):
            xref = img[0]
            try:
                bbox = page.get_image_bbox(img)
                y0 = bbox.y0
            except Exception:
                y0 = h  # à défaut, placée en fin de page
            elements.append((y0, "image", xref))

        elements.sort(key=lambda e: e[0])

        for y0, kind, payload in elements:
            if kind == "text":
                yield ContentUnit(kind="text", page=pno, text=_clean_ponctuation_lourde(payload))
            else:
                yield ContentUnit(kind="image", page=pno, xref=payload)


def _clean_ponctuation_lourde(text: str) -> str:
    """Nettoyage syntaxique léger avant passage au LLM : espaces multiples,
    tirets de fin de ligne, puces."""
    import re

    text = re.sub(r"-\n", "", text)          # mots coupés en fin de ligne
    text = re.sub(r"\s*\n\s*", " ", text)     # retours à la ligne internes
    text = re.sub(r"[•▪●◦]+", " ", text)      # puces
    text = re.sub(r"\s{2,}", " ", text)
    return text.strip()


def extract_image_bytes(doc: fitz.Document, xref: int) -> Optional[bytes]:
    try:
        img_dict = doc.extract_image(xref)
        return img_dict["image"]
    except Exception:
        return None


def compute_boilerplate(config: Config) -> set:
    with fitz.open(config.pdf_path) as doc:
        return _collect_boilerplate_lines(doc, config)

"""Orchestration bout en bout : PDF -> texte nettoyé + images décrites -> audio -> M4A.

Traitement séquentiel chapitre par chapitre pour borner la consommation mémoire sur
les documents volumineux (1000+ pages), avec reprise possible en cas d'interruption.
"""
from __future__ import annotations

import json
import logging
import time
from pathlib import Path
from typing import List

import fitz
from tqdm import tqdm

from .audio_merger import merge_chapter_wavs, merge_wavs_to_segment, export_m4a
from .config import Config
from .image_describer import describe_image
from .pdf_extractor import (
    ContentUnit,
    compute_boilerplate,
    extract_image_bytes,
    get_chapter_ranges,
    iter_chapter_content,
)
from .text_cleaner import clean_and_reformulate
from .tts_engine import TTSEngine

log = logging.getLogger(__name__)


class Manifest:
    """Suivi de progression persisté sur disque pour permettre la reprise."""

    def __init__(self, path: Path):
        self.path = path
        self.data = {"chapters_done": [], "chapter_wavs": {}}
        if path.exists():
            try:
                self.data = json.loads(path.read_text(encoding="utf-8"))
            except Exception:
                log.warning("Manifeste corrompu, redémarrage à zéro.")

    def is_done(self, chapter_index: int) -> bool:
        return chapter_index in self.data["chapters_done"]

    def mark_done(self, chapter_index: int, wav_path: str):
        if chapter_index not in self.data["chapters_done"]:
            self.data["chapters_done"].append(chapter_index)
        self.data["chapter_wavs"][str(chapter_index)] = wav_path
        self._save()

    def _save(self):
        self.path.write_text(json.dumps(self.data, ensure_ascii=False, indent=2), encoding="utf-8")


def _build_final_units(doc: fitz.Document, chapter, boilerplate: set, config: Config) -> List[str]:
    """Construit, pour un chapitre, la liste ordonnée des unités de texte prêtes pour la
    synthèse vocale : texte nettoyé par le LLM, entrecoupé des narrations d'images."""
    units: List[str] = []
    text_buffer = ""

    def flush_text():
        nonlocal text_buffer
        if text_buffer.strip():
            units.append(clean_and_reformulate(text_buffer, config))
        text_buffer = ""

    for item in iter_chapter_content(doc, chapter, boilerplate, config):
        if item.kind == "text":
            candidate = f"{text_buffer}\n{item.text}" if text_buffer else item.text
            if len(candidate) > config.max_chars_per_llm_call and text_buffer:
                flush_text()
                text_buffer = item.text
            else:
                text_buffer = candidate
        else:  # image
            flush_text()
            img_bytes = extract_image_bytes(doc, item.xref)
            narration = describe_image(img_bytes, config) if img_bytes else ""
            if narration:
                units.append(narration)

    flush_text()
    return [u for u in units if u.strip()]


def run_pipeline(config: Config) -> Path:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")

    manifest = Manifest(config.tmp_dir / "manifest.json")
    tts = TTSEngine(config)

    log.info("Analyse du document et détection des en-têtes/pieds de page répétitifs...")
    boilerplate = compute_boilerplate(config)

    with fitz.open(config.pdf_path) as doc:
        chapters = get_chapter_ranges(doc, config)
        log.info("Document découpé en %d chapitre(s) / section(s) pour %d page(s).",
                  len(chapters), doc.page_count)

        total_chapters = len(chapters)
        for pos, chapter in enumerate(tqdm(chapters, desc="Chapitres", unit="chap"), start=1):
            pct = int(pos / total_chapters * 100) if total_chapters else 100
            print(f"PROGRESSION {pct}% - chapitre {pos}/{total_chapters}", flush=True)

            if config.resume and manifest.is_done(chapter.index):
                log.info("Chapitre %d déjà traité, reprise -> passage au suivant.", chapter.index)
                continue

            log.info("Traitement du chapitre %d : « %s » (pages %d-%d)",
                      chapter.index, chapter.title, chapter.start_page + 1, chapter.end_page)

            final_units = _build_final_units(doc, chapter, boilerplate, config)
            if not final_units:
                log.warning("Chapitre %d vide après nettoyage, ignoré.", chapter.index)
                manifest.mark_done(chapter.index, "")
                continue

            chapter_dir = config.tmp_dir / f"chapter_{chapter.index:04d}"
            chapter_dir.mkdir(parents=True, exist_ok=True)

            segment_wavs = []
            total_units = len(final_units)
            for i, unit_text in enumerate(final_units, start=1):
                seg_path = chapter_dir / f"unit_{i - 1:04d}.wav"
                log.info("  -> Segment audio %d/%d du chapitre %d (%d caractères)...",
                          i, total_units, chapter.index, len(unit_text))
                # Progression fine (imprimée pour l'UI Streamlit) : combine la progression
                # inter-chapitres avec la progression des segments à l'intérieur du chapitre
                # en cours, pour que la barre avance même sur un chapitre long.
                sub_pct = int(((pos - 1) + i / max(total_units, 1)) / total_chapters * 100) if total_chapters else 100
                print(f"PROGRESSION {sub_pct}% - chapitre {pos}/{total_chapters}, "
                      f"segment {i}/{total_units}", flush=True)
                t_seg = time.monotonic()
                try:
                    ok = tts.synthesize(unit_text, seg_path)
                except Exception:
                    # Filet de sécurité : même une exception inattendue (non prévue par
                    # TTSEngine) ne doit jamais interrompre silencieusement le pipeline.
                    log.exception("Erreur inattendue sur le segment %d/%d du chapitre %d, "
                                  "segment ignoré.", i, total_units, chapter.index)
                    ok = False
                log.info("  <- Segment %d/%d terminé en %.1fs (succès=%s)",
                          i, total_units, time.monotonic() - t_seg, ok)
                if ok:
                    segment_wavs.append(seg_path)

            if not segment_wavs:
                log.warning("Aucun segment audio généré pour le chapitre %d.", chapter.index)
                manifest.mark_done(chapter.index, "")
                continue

            chapter_wav = config.tmp_dir / f"chapter_{chapter.index:04d}.wav"
            combined = merge_wavs_to_segment(segment_wavs, config.silence_between_units_ms)
            combined.export(str(chapter_wav), format="wav")

            if not config.keep_temp:
                for p in segment_wavs:
                    p.unlink(missing_ok=True)
                try:
                    chapter_dir.rmdir()
                except OSError:
                    pass

            manifest.mark_done(chapter.index, str(chapter_wav))
            log.info("Chapitre %d terminé -> %s", chapter.index, chapter_wav)

    log.info("Fusion finale de tous les chapitres en un seul fichier .m4a...")
    ordered_wavs = [
        Path(manifest.data["chapter_wavs"][str(c.index)])
        for c in chapters
        if manifest.data["chapter_wavs"].get(str(c.index))
    ]
    merge_chapter_wavs(ordered_wavs, config.output_path, config.silence_between_chapters_ms)

    if not config.keep_temp:
        for p in ordered_wavs:
            p.unlink(missing_ok=True)

    log.info("Terminé. Fichier audio disponible : %s", config.output_path)
    return config.output_path

Règles strictes :
- Supprime toute numérotation de section, de page, ou de liste ("1.2.3", "Chapitre 4", "p. 12"...).
- Supprime les références bibliographiques et appels de notes ([12], (Dupont, 2020), *, †...).
- Supprime la ponctuation lourde ou décorative (tirets de puces, guillemets typographiques imbriqués,
  parenthèses d'appel de figure comme "(voir Fig. 3)").
- Ne résume PAS le contenu, ne coupe aucune idée : reformule uniquement la forme pour un flux
  oral naturel, fluide et continu, avec une ponctuation simple (points, virgules).
- Ne commente pas ta tâche, ne rajoute aucune introduction ni conclusion : réponds uniquement
  avec le texte prêt à être lu, dans la même langue que le texte source.
"""


def clean_and_reformulate(raw_text: str, config: Config) -> str:
    raw_text = raw_text.strip()
    if not raw_text:
        return ""
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": raw_text},
    ]
    try:
        result = chat(config, config.text_model, messages)
    except Exception as e:
        log.warning("Échec du nettoyage LLM, utilisation du texte brut nettoyé minimalement : %s", e)
        return raw_text
    return result if result else raw_text


def split_into_llm_chunks(text_units: list[str], max_chars: int) -> list[str]:
    """Regroupe une liste de paragraphes bruts en blocs de taille raisonnable
    pour limiter le nombre d'appels au LLM tout en respectant le contexte."""
    chunks, buffer = [], ""
    for unit in text_units:
        if len(buffer) + len(unit) + 1 > max_chars and buffer:
            chunks.append(buffer.strip())
            buffer = unit
        else:
            buffer = f"{buffer}\n{unit}" if buffer else unit
    if buffer.strip():
        chunks.append(buffer.strip())
    return chunks

"""Synthèse vocale locale : Kokoro-TTS (par défaut, voix neuronales naturelles)
avec repli automatique sur Piper-TTS si Kokoro n'est pas disponible."""
from __future__ import annotations

import logging
import os
import subprocess
import time
from concurrent.futures import ThreadPoolExecutor
from concurrent.futures import TimeoutError as FutureTimeoutError
from pathlib import Path

from .config import Config

log = logging.getLogger(__name__)

# Kokoro attend des codes de langue courts et spécifiques, différents des codes
# ISO habituels (ex: "fr" -> "f"). Cette table convertit les codes usuels.
KOKORO_LANG_MAP = {
    "fr": "f", "fr-fr": "f",
    "en": "a", "en-us": "a",
    "en-gb": "b",
    "es": "e",
    "hi": "h",
    "it": "i",
    "pt": "p", "pt-br": "p",
    "ja": "j",
    "zh": "z",
}


class TTSError(RuntimeError):
    pass


class TTSTimeoutError(TTSError):
    pass


def _run_with_timeout(fn, timeout: float, label: str):
    """Exécute `fn` (sans argument) dans un thread séparé et lève TTSTimeoutError
    si `timeout` secondes sont dépassées, au lieu de laisser le pipeline se
    bloquer indéfiniment (cas typique : téléchargement Hugging Face qui stalle
    sans jamais lever d'exception réseau).

    Le thread sous-jacent peut continuer de tourner en arrière-plan une fois le
    timeout atteint (Python ne permet pas de tuer un thread proprement) ; c'est
    un compromis volontaire pour rendre la main à l'utilisateur plutôt que de
    rester bloqué sans retour visuel.

    Important : on n'utilise volontairement PAS `with ThreadPoolExecutor(...) as
    executor:` ici, car la sortie de ce bloc appelle `shutdown(wait=True)` et
    attendrait silencieusement la fin du thread bloqué, annulant l'effet du
    timeout. `shutdown(wait=False)` est utilisé explicitement à la place."""
    executor = ThreadPoolExecutor(max_workers=1)
    future = executor.submit(fn)
    try:
        result = future.result(timeout=timeout)
        executor.shutdown(wait=False)
        return result
    except FutureTimeoutError:
        executor.shutdown(wait=False)
        raise TTSTimeoutError(
            f"{label} : délai dépassé après {timeout:.0f}s sans réponse."
        )


class TTSEngine:
    def __init__(self, config: Config):
        self.config = config
        self._kokoro_pipeline = None
        if config.tts_engine == "kokoro":
            self._init_kokoro()

    def _configure_hf_env(self):
        """Configure Hugging Face Hub (jeton + timeout réseau) avant tout
        téléchargement, pour limiter les blocages liés au rate limit imposé
        aux requêtes non authentifiées."""
        if self.config.hf_token:
            os.environ["HF_TOKEN"] = self.config.hf_token
            os.environ.setdefault("HUGGING_FACE_HUB_TOKEN", self.config.hf_token)
            log.info("Jeton HF_TOKEN détecté : les téléchargements Hugging Face seront authentifiés.")
        else:
            log.info(
                "Aucun HF_TOKEN configuré : téléchargement Hugging Face en mode anonyme "
                "(rate limit plus bas -> risque de blocage). Ajoutez HF_TOKEN dans un fichier "
                ".env ou dans config.py pour fiabiliser le téléchargement."
            )
        # Empêche huggingface_hub de rester bloqué indéfiniment sur une requête réseau.
        os.environ.setdefault("HF_HUB_DOWNLOAD_TIMEOUT", str(self.config.hf_download_timeout))

    def _init_kokoro(self):
        self._configure_hf_env()
        last_error: Exception | None = None
        init_timeout = max(self.config.hf_download_timeout * 4, 60)

        for attempt in range(1, self.config.hf_max_retries + 1):
            t0 = time.monotonic()
            try:
                log.info(
                    "Initialisation de Kokoro-TTS (tentative %d/%d) — téléchargement du modèle "
                    "kokoro-v1_0.pth depuis Hugging Face si absent du cache local (peut prendre "
                    "plusieurs minutes la première fois, timeout à %ds)...",
                    attempt, self.config.hf_max_retries, init_timeout,
                )

                def _load():
                    from kokoro import KPipeline  # import tardif : dépendance optionnelle
                    kokoro_lang = KOKORO_LANG_MAP.get(self.config.language.lower(), self.config.language)
                    return KPipeline(lang_code=kokoro_lang)

                self._kokoro_pipeline = _run_with_timeout(_load, init_timeout, "Chargement Kokoro-TTS")
                log.info("Kokoro-TTS initialisé en %.1fs (langue=%s, voix=%s).",
                          time.monotonic() - t0, self.config.language, self.config.tts_voice)
                return
            except Exception as e:
                last_error = e
                log.warning(
                    "Tentative %d/%d d'initialisation de Kokoro-TTS échouée après %.1fs : %s",
                    attempt, self.config.hf_max_retries, time.monotonic() - t0, e,
                )
                if attempt < self.config.hf_max_retries:
                    backoff = min(2 ** attempt, 30)
                    log.info("Nouvelle tentative dans %ds...", backoff)
                    time.sleep(backoff)

        log.warning(
            "Kokoro-TTS indisponible après %d tentative(s) (%s) -> repli sur Piper-TTS.",
            self.config.hf_max_retries, last_error,
        )
        self.config.tts_engine = "piper"

    def synthesize(self, text: str, out_wav: Path) -> bool:
        """Synthétise `text` vers le fichier `out_wav` (WAV mono). Retourne False si le
        segment est vide ou en cas d'échec (le segment est alors simplement ignoré)."""
        text = text.strip()
        if not text:
            return False

        if self.config.tts_engine == "kokoro" and self._kokoro_pipeline is not None:
            return self._synth_kokoro(text, out_wav)
        return self._synth_piper(text, out_wav)

    def _synth_kokoro(self, text: str, out_wav: Path) -> bool:
        t0 = time.monotonic()
        log.debug("Synthèse Kokoro démarrée -> %s (%d caractères)", out_wav.name, len(text))
        try:
            def _generate():
                import numpy as np
                import soundfile as sf

                audio_chunks = []
                generator = self._kokoro_pipeline(text, voice=self.config.tts_voice)
                for _graphemes, _phonemes, audio in generator:
                    audio_chunks.append(audio)
                if not audio_chunks:
                    return False
                full_audio = np.concatenate(audio_chunks)
                sf.write(str(out_wav), full_audio, self.config.sample_rate)
                return True

            # Toute la boucle de génération est bornée dans le temps : si Kokoro
            # reste bloqué sur un segment (ex: modèle mal chargé, deadlock GPU),
            # on lève une exception au lieu de figer tout le pipeline.
            ok = _run_with_timeout(_generate, self.config.tts_unit_timeout, "Synthèse Kokoro")
            log.debug("Segment Kokoro terminé en %.1fs -> %s", time.monotonic() - t0, out_wav.name)
            return ok
        except Exception as e:
            log.warning(
                "Échec Kokoro sur un segment après %.1fs (%s), tentative Piper : %s",
                time.monotonic() - t0, out_wav.name, e,
            )
            return self._synth_piper(text, out_wav)

    def _synth_piper(self, text: str, out_wav: Path) -> bool:
        if not self.config.piper_model_path:
            raise TTSError(
                "Aucun moteur TTS disponible : Kokoro a échoué et aucun modèle Piper "
                "(`piper_model_path`) n'est configuré."
            )
        t0 = time.monotonic()
        log.debug("Synthèse Piper démarrée -> %s (%d caractères)", out_wav.name, len(text))
        try:
            proc = subprocess.run(
                [self.config.piper_binary, "--model", self.config.piper_model_path,
                 "--output_file", str(out_wav)],
                input=text.encode("utf-8"),
                stdout=subprocess.PIPE, stderr=subprocess.PIPE, timeout=300,
            )
            if proc.returncode != 0 or not out_wav.exists():
                log.warning("Piper a échoué sur un segment (%.1fs) : %s",
                            time.monotonic() - t0, proc.stderr.decode(errors="ignore"))
                return False
            log.debug("Segment Piper terminé en %.1fs -> %s", time.monotonic() - t0, out_wav.name)
            return True
        except subprocess.TimeoutExpired:
            log.warning("Piper a dépassé le délai de 300s sur un segment (%s), segment ignoré.", out_wav.name)
            return False
        except Exception as e:
            log.warning("Échec Piper sur un segment après %.1fs, segment ignoré : %s",
                        time.monotonic() - t0, e)
            return False

# pdf2audio

Convertisseur PDF → livre audio (.m4a), 100 % local : extraction intelligente
du texte, description des images via un modèle de vision local (Ollama),
synthèse vocale (Kokoro-TTS ou Piper-TTS), fusion en un seul fichier audio.

Deux façons de l'utiliser : une **interface graphique** (recommandée) ou la
**ligne de commande**.

## 1. Installation (une seule fois)

Prérequis à installer manuellement avant de commencer :

- **Python 3.10+** — https://www.python.org/downloads/ (coche bien *"Add
  python.exe to PATH"* pendant l'installation)
- **FFmpeg** — https://www.gyan.dev/ffmpeg/builds/ (build "essentials"),
  à décompresser puis à ajouter au PATH Windows
- **Ollama** — https://ollama.com, puis dans un terminal :
  ```
  ollama pull llama3.2
  ollama pull llama3.2-vision
  ```

Ensuite, dans le dossier du projet, double-clique sur **`1_installer.bat`**.
Ce script crée un environnement Python isolé (`.venv`) et installe tout
automatiquement, sans toucher à ton installation Python globale.

## 2. Utilisation — Interface graphique

Double-clique sur **`2_lancer.bat`**. Ton navigateur s'ouvre avec l'interface :
dépose ton PDF, ajuste les options si besoin, clique sur *Convertir*, et
télécharge le fichier audio à la fin.

> Le `.bat` utilise toujours `python -m streamlit`, donc pas de souci de PATH
> même si la commande `streamlit` seule n'est pas reconnue par Windows.

## 3. Utilisation — Ligne de commande

```
.venv\Scripts\activate
python main.py --pdf mon_livre.pdf --output mon_livre.m4a ^
    --text-model llama3.2 --vision-model llama3.2-vision ^
    --tts-engine kokoro --voice ff_siwis
```

Options utiles :

| Option | Rôle |
|---|---|
| `--chunk-pages N` | taille des sections si le PDF n'a pas de sommaire |
| `--max-chars N` | taille max d'un bloc envoyé au LLM |
| `--tts-engine kokoro\|piper` | moteur vocal |
| `--voice` | voix Kokoro (ex: `ff_siwis` pour du français) |
| `--piper-model` / `--piper-binary` | requis si `--tts-engine piper` |
| `--no-resume` | ignore une conversion précédente interrompue |
| `--keep-temp` | conserve les fichiers audio intermédiaires |

La conversion reprend automatiquement là où elle s'était arrêtée si elle est
interrompue (sauf avec `--no-resume`).

## Dépannage rapide

- **`ModuleNotFoundError`** → relance `1_installer.bat`.
- **`streamlit : terme non reconnu`** → utilise `2_lancer.bat`, ou tape
  `python -m streamlit run streamlit_app.py` toi-même.
- **Erreur FFmpeg / export échoue** → FFmpeg doit être dans le PATH, vérifie
  avec `ffmpeg -version` dans un terminal.
- **Erreur Ollama / connexion refusée** → lance `ollama serve` dans un
  terminal séparé, et vérifie que les modèles sont bien téléchargés.

def session_dir_for(pdf_bytes: bytes, output_name: str) -> Path:
    """Dossier de travail déterministe basé sur le contenu du PDF et le nom de
    sortie choisi : un même fichier relancé avec les mêmes réglages de sortie
    retombe toujours sur le même dossier, donc sur le même manifeste de
    progression, donc reprend là où il s'était arrêté."""
    digest = hashlib.sha256(pdf_bytes + output_name.encode("utf-8")).hexdigest()[:16]
    d = SESSIONS_DIR / digest
    d.mkdir(parents=True, exist_ok=True)
    return d

def build_command(pdf_path: Path, output_path: Path, tmp_dir: Path) -> list:
    cmd = [

def run_conversion(pdf_bytes: bytes, pdf_filename: str):
    final_output_name = output_name if output_name.strip() else default_output_name
    work_dir = session_dir_for(pdf_bytes, final_output_name)
    pdf_path = work_dir / pdf_filename
    if not pdf_path.exists():
        pdf_path.write_bytes(pdf_bytes)

    output_path = work_dir / final_output_name
    tmp_dir = work_dir / "tmp"
    tmp_dir.mkdir(exist_ok=True)

    resuming = not no_resume and (tmp_dir / "manifest.json").exists()
    if resuming:
        st.info(
            "Une conversion précédente de ce même PDF a été détectée pour ce même nom de "
            "sortie : reprise là où elle s'était arrêtée.",
            icon="🔁",
        )

    cmd = build_command(pdf_path, output_path, tmp_dir)

    # Le jeton HF passe par une variable d'environnement du sous-processus plutôt que par un
    # argument en ligne de commande, pour ne jamais apparaître dans les logs affichés ci-dessous
    # ni dans la liste des processus du système.
    child_env = os.environ.copy()
    if hf_token.strip():
        child_env["HF_TOKEN"] = hf_token.strip()

    log_lines = []
    progress_bar = progress_placeholder.progress(0, text="Démarrage de la conversion…")

    process = subprocess.Popen(
        cmd,
        cwd=str(APP_DIR),
        env=child_env,
        stdout=subprocess.PIPE,
        stderr=subprocess.STDOUT,
        text=True,
        bufsize=1,
    )

    # Nombre de lignes affichées et fréquence de rafraîchissement volontairement
    # limités : sur un PDF volumineux, le pipeline peut produire des centaines
    # de lignes de log en quelques secondes, et un réaffichage trop fréquent ou
    # trop volumineux du journal fait planter le rendu de la page (le
    # navigateur n'arrive plus à suivre le rythme des mises à jour du DOM).
    MAX_DISPLAYED_LINES = 50
    MIN_REFRESH_INTERVAL_S = 0.5

    def render_log():
        log_placeholder.markdown(
            f'<div class="log-box">{"<br>".join(log_lines[-MAX_DISPLAYED_LINES:])}</div>',
            unsafe_allow_html=True,
        )

    last_render = 0.0
    for line in iter(process.stdout.readline, ""):
        if not line:
            break
        log_lines.append(line.rstrip("\n"))

        match = PROGRESS_RE.findall(line)
        if match:
            try:
                pct = min(int(match[-1]), 100)
                progress_bar.progress(pct, text=line.strip()[:120])
            except ValueError:
                pass

        now = time.time()
        if now - last_render > MIN_REFRESH_INTERVAL_S:
            render_log()
            last_render = now

    process.wait()
    render_log()

    if process.returncode == 0 and output_path.exists():
        progress_placeholder.progress(100, text="Conversion terminée ✔️")
        audio_bytes = output_path.read_bytes()
        result_placeholder.success("🎉 Ton livre audio est prêt !")
        result_placeholder.download_button(
            "⬇️ Télécharger l'audio",
            data=audio_bytes,
            file_name=output_path.name,
            mime="audio/mp4",
            use_container_width=True,
        )
    else:
        progress_placeholder.empty()
        result_placeholder.error(
            f"La conversion a échoué (code {process.returncode}). "
            "Regarde le journal ci-dessus pour comprendre pourquoi."
        )


if launch and uploaded_pdf is not None:
    run_conversion(uploaded_pdf.getvalue(), uploaded_pdf.name)

"""Fusion des segments WAV en un unique fichier audio .m4a (AAC), via pydub + FFmpeg."""
from __future__ import annotations

import logging
from pathlib import Path
from typing import List

from pydub import AudioSegment

log = logging.getLogger(__name__)


def merge_wavs_to_segment(wav_paths: List[Path], silence_ms: int) -> AudioSegment:
    combined = AudioSegment.silent(duration=0)
    silence = AudioSegment.silent(duration=silence_ms)
    for p in wav_paths:
        if not p.exists():
            continue
        try:
            seg = AudioSegment.from_file(p)
        except Exception as e:
            log.warning("Segment audio illisible, ignoré (%s) : %s", p, e)
            continue
        combined += seg + silence
    return combined


def export_m4a(segment: AudioSegment, output_path: Path, bitrate: str = "128k") -> None:
    output_path.parent.mkdir(parents=True, exist_ok=True)
    # Le conteneur .m4a est un MP4 audio-only encodé en AAC.
    segment.export(str(output_path), format="mp4", codec="aac", bitrate=bitrate)
    log.info("Fichier audio final écrit : %s", output_path)


def merge_chapter_wavs(chapter_wav_paths: List[Path], output_path: Path,
                        silence_between_chapters_ms: int) -> None:
    full = merge_wavs_to_segment(chapter_wav_paths, silence_between_chapters_ms)
    if len(full) == 0:
        raise RuntimeError("Aucun segment audio valide n'a pu être fusionné.")
    export_m4a(full, output_path)

"""Description narrative des images et schémas via un modèle multimodal local

VISION_SYSTEM_PROMPT = """Tu décris une image extraite d'un document, pour une personne qui
l'écoute sans la voir. Rédige 2 à 4 phrases en langage naturel et fluide, formant une transition
orale intégrée au texte (par exemple en commençant par "L'illustration ci-dessus montre...",

    try:
        with Image.open(io.BytesIO(image_bytes)) as im:
            w, h = im.size
            return w < MIN_IMAGE_DIMENSION or h < MIN_IMAGE_DIMENSION
    except Exception:
        return True

        return ""

    messages = [

    except Exception as e:
        log.warning("Échec de la description d'image, image ignorée : %s", e)
        return ""

    return description.strip()

"""Client HTTP minimal pour Ollama (100% local, pas de dépendance externe hors `requests`)."""
from __future__ import annotations

import base64
import json
import logging

import requests

from .config import Config

log = logging.getLogger(__name__)


class OllamaError(RuntimeError):
    pass


def chat(config: Config, model: str, messages: list, images_b64: list | None = None) -> str:
    """Appelle /api/chat en mode non streaming et retourne le texte de la réponse."""
    url = f"{config.ollama_host.rstrip('/')}/api/chat"
    if images_b64:
        # Attache les images au dernier message utilisateur (format multimodal Ollama)
        messages = [dict(m) for m in messages]
        messages[-1]["images"] = images_b64

    payload = {"model": model, "messages": messages, "stream": False}
    try:
        resp = requests.post(url, json=payload, timeout=config.llm_timeout)
        resp.raise_for_status()
    except requests.RequestException as e:
        raise OllamaError(
            f"Impossible de contacter Ollama à {config.ollama_host} (modèle '{model}'). "
            f"Vérifiez que `ollama serve` tourne et que le modèle est installé "
            f"(`ollama pull {model}`). Détail : {e}"
        ) from e

    data = resp.json()
    return data.get("message", {}).get("content", "").strip()


def image_to_b64(image_bytes: bytes) -> str:
    return base64.b64encode(image_bytes).decode("utf-8")


def list_models(ollama_host: str = "http://localhost:11434", timeout: float = 2.0) -> list[str]:
    """Retourne la liste des noms de modèles installés localement via `ollama pull`.

    Utilisé par l'interface pour proposer un menu déroulant plutôt qu'un champ de
    texte libre. Retourne une liste vide (sans lever d'exception) si Ollama n'est
    pas joignable, pour ne jamais bloquer l'affichage de l'interface."""
    url = f"{ollama_host.rstrip('/')}/api/tags"
    try:
        resp = requests.get(url, timeout=timeout)
        resp.raise_for_status()
        data = resp.json()
        return sorted(m["name"] for m in data.get("models", []))
    except Exception as e:
        log.info("Impossible de lister les modèles Ollama installés (%s) : %s", ollama_host, e)
        return []

"""
Extraction séquentielle du PDF avec PyMuPDF (fitz).

- Découpe le document en "chapitres" (via la table des matières si disponible,
  sinon par blocs de N pages) pour un traitement en flux et une empreinte
  mémoire bornée, quelle que soit la taille du document (5 à 1000+ pages).
- Détecte automatiquement en-têtes / pieds de page répétitifs.
- Détecte les notes de bas de page via la position et la taille de police.
- Restitue un flux ordonné d'unités "texte" et "image" dans l'ordre de lecture.
"""
from __future__ import annotations

import statistics
from dataclasses import dataclass
from typing import Iterator, List, Optional, Tuple

try:
    import pymupdf as fitz  # PyMuPDF (nom de paquet moderne, supprime le warning de dépréciation)
except ImportError:  # compat versions de PyMuPDF trop anciennes pour exposer le module `pymupdf`
    import fitz

from .config import Config


@dataclass
class ChapterRange:
    index: int
    title: str
    start_page: int  # inclus, 0-based
    end_page: int     # exclus, 0-based


@dataclass
class ContentUnit:
    kind: str          # "text" ou "image"
    page: int
    text: str = ""
    xref: int = 0


def get_chapter_ranges(doc: fitz.Document, config: Config) -> List[ChapterRange]:
    """Découpe le document en chapitres à partir du sommaire (TOC) si présent,
    sinon en tranches fixes de `chapter_chunk_pages` pages."""
    toc = doc.get_toc(simple=True)  # [[niveau, titre, page_1indexed], ...]
    n_pages = doc.page_count

    top_level = [t for t in toc if t[0] == 1] if toc else []
    if len(top_level) >= 2:
        ranges = []
        for i, (_, title, page1) in enumerate(top_level):
            start = max(page1 - 1, 0)
            end = (top_level[i + 1][2] - 1) if i + 1 < len(top_level) else n_pages
            if end > start:
                ranges.append(ChapterRange(i, title.strip() or f"Chapitre {i+1}", start, end))
        # Fusionne les chapitres trop courts avec le suivant pour éviter des micro-appels LLM
        merged: List[ChapterRange] = []
        for r in ranges:
            if merged and (r.end_page - r.start_page) < 2:
                merged[-1].end_page = r.end_page
            else:
                merged.append(r)
        if merged:
            return merged

    # Repli : découpage fixe par nombre de pages
    step = max(config.chapter_chunk_pages, 1)
    ranges = []
    for i, start in enumerate(range(0, n_pages, step)):
        end = min(start + step, n_pages)
        ranges.append(ChapterRange(i, f"Section {i+1} (pages {start+1}-{end})", start, end))
    return ranges


def _collect_boilerplate_lines(doc: fitz.Document, config: Config) -> set:
    """Identifie les lignes récurrentes en haut/bas de page (en-têtes, pieds de page,
    numérotation) en comparant leur fréquence d'apparition sur un échantillon de pages."""
    from collections import Counter

    counts: Counter = Counter()
    n_pages = doc.page_count
    sample = range(0, n_pages, max(1, n_pages // min(n_pages, 60) or 1))

    for pno in sample:
        page = doc[pno]
        h = page.rect.height
        margin = h * config.header_footer_margin_ratio
        for block in page.get_text("blocks"):
            x0, y0, x1, y1, text, *_ = block
            text = text.strip()
            if not text or len(text) > 90:
                continue
            if y0 <= margin or y1 >= h - margin:
                counts[text] += 1

    return {t for t, c in counts.items() if c >= config.header_footer_min_repeat}


def _median_font_size(page: fitz.Page) -> float:
    sizes = []
    d = page.get_text("dict")
    for block in d.get("blocks", []):
        for line in block.get("lines", []):
            for span in line.get("spans", []):
                if span.get("text", "").strip():
                    sizes.append(span["size"])
    return statistics.median(sizes) if sizes else 10.0


def _is_footnote(y0: float, y1: float, page_height: float, font_size: float,
                  median_size: float, config: Config) -> bool:
    near_bottom = y1 >= page_height * (1 - config.header_footer_margin_ratio * 1.5)
    small_font = font_size <= median_size * config.footnote_font_ratio
    return near_bottom and small_font


def iter_chapter_content(doc: fitz.Document, chapter: ChapterRange,
                          boilerplate: set, config: Config) -> Iterator[ContentUnit]:
    """Produit un flux ordonné d'unités de contenu (texte / image) pour un chapitre,
    en filtrant en-têtes, pieds de page et notes de bas de page."""
    for pno in range(chapter.start_page, chapter.end_page):
        page = doc[pno]
        h = page.rect.height
        margin = h * config.header_footer_margin_ratio
        median_size = _median_font_size(page)

        # Éléments positionnés : texte (avec taille de police) + images, triés par position verticale
        elements: List[Tuple[float, str, object]] = []

        d = page.get_text("dict")
        for block in d.get("blocks", []):
            if block.get("type") != 0:
                continue
            y0 = block["bbox"][1]
            y1 = block["bbox"][3]
            block_text_parts = []
            font_sizes = []
            for line in block.get("lines", []):
                for span in line.get("spans", []):
                    t = span.get("text", "")
                    if t.strip():
                        block_text_parts.append(t)
                        font_sizes.append(span["size"])
            text = "".join(block_text_parts).strip()
            if not text:
                continue
            if text in boilerplate:
                continue
            if y0 <= margin or y1 >= h - margin:
                continue
            avg_font = sum(font_sizes) / len(font_sizes) if font_sizes else median_size
            if _is_footnote(y0, y1, h, avg_font, median_size, config):
                continue
            elements.append((y0, "text", text))

        for img in page.get_images(full=True):
            xref = img[0]
            try:
                bbox = page.get_image_bbox(img)
                y0 = bbox.y0
            except Exception:
                y0 = h  # à défaut, placée en fin de page
            elements.append((y0, "image", xref))

        elements.sort(key=lambda e: e[0])

        for y0, kind, payload in elements:
            if kind == "text":
                yield ContentUnit(kind="text", page=pno, text=_clean_ponctuation_lourde(payload))
            else:
                yield ContentUnit(kind="image", page=pno, xref=payload)


def _clean_ponctuation_lourde(text: str) -> str:
    """Nettoyage syntaxique léger avant passage au LLM : espaces multiples,
    tirets de fin de ligne, puces."""
    import re

    text = re.sub(r"-\n", "", text)          # mots coupés en fin de ligne
    text = re.sub(r"\s*\n\s*", " ", text)     # retours à la ligne internes
    text = re.sub(r"[•▪●◦]+", " ", text)      # puces
    text = re.sub(r"\s{2,}", " ", text)
    return text.strip()


def extract_image_bytes(doc: fitz.Document, xref: int) -> Optional[bytes]:
    try:
        img_dict = doc.extract_image(xref)
        return img_dict["image"]
    except Exception:
        return None


def compute_boilerplate(config: Config) -> set:
    with fitz.open(config.pdf_path) as doc:
        return _collect_boilerplate_lines(doc, config)

"""Orchestration bout en bout : PDF -> texte nettoyé + images décrites -> audio -> M4A.

Traitement séquentiel chapitre par chapitre pour borner la consommation mémoire sur
les documents volumineux (1000+ pages), avec reprise possible en cas d'interruption.
"""
from __future__ import annotations

import json
import logging
import time
from pathlib import Path
from typing import List

import fitz
from tqdm import tqdm

from .audio_merger import merge_chapter_wavs, merge_wavs_to_segment, export_m4a
from .config import Config
from .image_describer import describe_image
from .pdf_extractor import (
    ContentUnit,
    compute_boilerplate,
    extract_image_bytes,
    get_chapter_ranges,
    iter_chapter_content,
)
from .text_cleaner import clean_and_reformulate
from .tts_engine import TTSEngine

log = logging.getLogger(__name__)


class Manifest:
    """Suivi de progression persisté sur disque pour permettre la reprise."""

    def __init__(self, path: Path):
        self.path = path
        self.data = {"chapters_done": [], "chapter_wavs": {}}
        if path.exists():
            try:
                self.data = json.loads(path.read_text(encoding="utf-8"))
            except Exception:
                log.warning("Manifeste corrompu, redémarrage à zéro.")

    def is_done(self, chapter_index: int) -> bool:
        return chapter_index in self.data["chapters_done"]

    def mark_done(self, chapter_index: int, wav_path: str):
        if chapter_index not in self.data["chapters_done"]:
            self.data["chapters_done"].append(chapter_index)
        self.data["chapter_wavs"][str(chapter_index)] = wav_path
        self._save()

    def _save(self):
        self.path.write_text(json.dumps(self.data, ensure_ascii=False, indent=2), encoding="utf-8")


def _build_final_units(doc: fitz.Document, chapter, boilerplate: set, config: Config) -> List[str]:
    """Construit, pour un chapitre, la liste ordonnée des unités de texte prêtes pour la
    synthèse vocale : texte nettoyé par le LLM, entrecoupé des narrations d'images."""
    units: List[str] = []
    text_buffer = ""

    def flush_text():
        nonlocal text_buffer
        if text_buffer.strip():
            units.append(clean_and_reformulate(text_buffer, config))
        text_buffer = ""

    for item in iter_chapter_content(doc, chapter, boilerplate, config):
        if item.kind == "text":
            candidate = f"{text_buffer}\n{item.text}" if text_buffer else item.text
            if len(candidate) > config.max_chars_per_llm_call and text_buffer:
                flush_text()
                text_buffer = item.text
            else:
                text_buffer = candidate
        else:  # image
            flush_text()
            img_bytes = extract_image_bytes(doc, item.xref)
            narration = describe_image(img_bytes, config) if img_bytes else ""
            if narration:
                units.append(narration)

    flush_text()
    return [u for u in units if u.strip()]


def run_pipeline(config: Config) -> Path:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")

    manifest = Manifest(config.tmp_dir / "manifest.json")
    tts = TTSEngine(config)

    log.info("Analyse du document et détection des en-têtes/pieds de page répétitifs...")
    boilerplate = compute_boilerplate(config)

    with fitz.open(config.pdf_path) as doc:
        chapters = get_chapter_ranges(doc, config)
        log.info("Document découpé en %d chapitre(s) / section(s) pour %d page(s).",
                  len(chapters), doc.page_count)

        total_chapters = len(chapters)
        for pos, chapter in enumerate(tqdm(chapters, desc="Chapitres", unit="chap"), start=1):
            pct = int(pos / total_chapters * 100) if total_chapters else 100
            print(f"PROGRESSION {pct}% - chapitre {pos}/{total_chapters}", flush=True)

            if config.resume and manifest.is_done(chapter.index):
                log.info("Chapitre %d déjà traité, reprise -> passage au suivant.", chapter.index)
                continue

            log.info("Traitement du chapitre %d : « %s » (pages %d-%d)",
                      chapter.index, chapter.title, chapter.start_page + 1, chapter.end_page)

            final_units = _build_final_units(doc, chapter, boilerplate, config)
            if not final_units:
                log.warning("Chapitre %d vide après nettoyage, ignoré.", chapter.index)
                manifest.mark_done(chapter.index, "")
                continue

            chapter_dir = config.tmp_dir / f"chapter_{chapter.index:04d}"
            chapter_dir.mkdir(parents=True, exist_ok=True)

            segment_wavs = []
            total_units = len(final_units)
            for i, unit_text in enumerate(final_units, start=1):
                seg_path = chapter_dir / f"unit_{i - 1:04d}.wav"
                log.info("  -> Segment audio %d/%d du chapitre %d (%d caractères)...",
                          i, total_units, chapter.index, len(unit_text))
                # Progression fine (imprimée pour l'UI Streamlit) : combine la progression
                # inter-chapitres avec la progression des segments à l'intérieur du chapitre
                # en cours, pour que la barre avance même sur un chapitre long.
                sub_pct = int(((pos - 1) + i / max(total_units, 1)) / total_chapters * 100) if total_chapters else 100
                print(f"PROGRESSION {sub_pct}% - chapitre {pos}/{total_chapters}, "
                      f"segment {i}/{total_units}", flush=True)
                t_seg = time.monotonic()
                try:
                    ok = tts.synthesize(unit_text, seg_path)
                except Exception:
                    # Filet de sécurité : même une exception inattendue (non prévue par
                    # TTSEngine) ne doit jamais interrompre silencieusement le pipeline.
                    log.exception("Erreur inattendue sur le segment %d/%d du chapitre %d, "
                                  "segment ignoré.", i, total_units, chapter.index)
                    ok = False
                log.info("  <- Segment %d/%d terminé en %.1fs (succès=%s)",
                          i, total_units, time.monotonic() - t_seg, ok)
                if ok:
                    segment_wavs.append(seg_path)

            if not segment_wavs:
                log.warning("Aucun segment audio généré pour le chapitre %d.", chapter.index)
                manifest.mark_done(chapter.index, "")
                continue

            chapter_wav = config.tmp_dir / f"chapter_{chapter.index:04d}.wav"
            combined = merge_wavs_to_segment(segment_wavs, config.silence_between_units_ms)
            combined.export(str(chapter_wav), format="wav")

            if not config.keep_temp:
                for p in segment_wavs:
                    p.unlink(missing_ok=True)
                try:
                    chapter_dir.rmdir()
                except OSError:
                    pass

            manifest.mark_done(chapter.index, str(chapter_wav))
            log.info("Chapitre %d terminé -> %s", chapter.index, chapter_wav)

    log.info("Fusion finale de tous les chapitres en un seul fichier .m4a...")
    ordered_wavs = [
        Path(manifest.data["chapter_wavs"][str(c.index)])
        for c in chapters
        if manifest.data["chapter_wavs"].get(str(c.index))
    ]
    merge_chapter_wavs(ordered_wavs, config.output_path, config.silence_between_chapters_ms)

    if not config.keep_temp:
        for p in ordered_wavs:
            p.unlink(missing_ok=True)

    log.info("Terminé. Fichier audio disponible : %s", config.output_path)
    return config.output_path

"""Nettoyage et reformulation du texte extrait, via le LLM local (Ollama)."""
from __future__ import annotations

import logging

from .config import Config
from .ollama_client import chat

log = logging.getLogger(__name__)

SYSTEM_PROMPT = """Tu prépares un texte pour une lecture audio à voix haute.
Règles strictes :
- Supprime toute numérotation de section, de page, ou de liste ("1.2.3", "Chapitre 4", "p. 12"...).
- Supprime les références bibliographiques et appels de notes ([12], (Dupont, 2020), *, †...).
- Supprime la ponctuation lourde ou décorative (tirets de puces, guillemets typographiques imbriqués,
  parenthèses d'appel de figure comme "(voir Fig. 3)").
- Ne résume PAS le contenu, ne coupe aucune idée : reformule uniquement la forme pour un flux
  oral naturel, fluide et continu, avec une ponctuation simple (points, virgules).
- Ne commente pas ta tâche, ne rajoute aucune introduction ni conclusion : réponds uniquement
  avec le texte prêt à être lu, dans la même langue que le texte source.
"""


def clean_and_reformulate(raw_text: str, config: Config) -> str:
    raw_text = raw_text.strip()
    if not raw_text:
        return ""
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": raw_text},
    ]
    try:
        result = chat(config, config.text_model, messages)
    except Exception as e:
        log.warning("Échec du nettoyage LLM, utilisation du texte brut nettoyé minimalement : %s", e)
        return raw_text
    return result if result else raw_text


def split_into_llm_chunks(text_units: list[str], max_chars: int) -> list[str]:
    """Regroupe une liste de paragraphes bruts en blocs de taille raisonnable
    pour limiter le nombre d'appels au LLM tout en respectant le contexte."""
    chunks, buffer = [], ""
    for unit in text_units:
        if len(buffer) + len(unit) + 1 > max_chars and buffer:
            chunks.append(buffer.strip())
            buffer = unit
        else:
            buffer = f"{buffer}\n{unit}" if buffer else unit
    if buffer.strip():
        chunks.append(buffer.strip())
    return chunks

"""Synthèse vocale locale : Kokoro-TTS (par défaut, voix neuronales naturelles)
avec repli automatique sur Piper-TTS si Kokoro n'est pas disponible."""
from __future__ import annotations

import logging
import os
import subprocess
import time
from concurrent.futures import ThreadPoolExecutor
from concurrent.futures import TimeoutError as FutureTimeoutError
from pathlib import Path

from .config import Config

log = logging.getLogger(__name__)

# Kokoro attend des codes de langue courts et spécifiques, différents des codes
# ISO habituels (ex: "fr" -> "f"). Cette table convertit les codes usuels.
KOKORO_LANG_MAP = {
    "fr": "f", "fr-fr": "f",
    "en": "a", "en-us": "a",
    "en-gb": "b",
    "es": "e",
    "hi": "h",
    "it": "i",
    "pt": "p", "pt-br": "p",
    "ja": "j",
    "zh": "z",
}


class TTSError(RuntimeError):
    pass


class TTSTimeoutError(TTSError):
    pass


def _run_with_timeout(fn, timeout: float, label: str):
    """Exécute `fn` (sans argument) dans un thread séparé et lève TTSTimeoutError
    si `timeout` secondes sont dépassées, au lieu de laisser le pipeline se
    bloquer indéfiniment (cas typique : téléchargement Hugging Face qui stalle
    sans jamais lever d'exception réseau).

    Le thread sous-jacent peut continuer de tourner en arrière-plan une fois le
    timeout atteint (Python ne permet pas de tuer un thread proprement) ; c'est
    un compromis volontaire pour rendre la main à l'utilisateur plutôt que de
    rester bloqué sans retour visuel.

    Important : on n'utilise volontairement PAS `with ThreadPoolExecutor(...) as
    executor:` ici, car la sortie de ce bloc appelle `shutdown(wait=True)` et
    attendrait silencieusement la fin du thread bloqué, annulant l'effet du
    timeout. `shutdown(wait=False)` est utilisé explicitement à la place."""
    executor = ThreadPoolExecutor(max_workers=1)
    future = executor.submit(fn)
    try:
        result = future.result(timeout=timeout)
        executor.shutdown(wait=False)
        return result
    except FutureTimeoutError:
        executor.shutdown(wait=False)
        raise TTSTimeoutError(
            f"{label} : délai dépassé après {timeout:.0f}s sans réponse."
        )


class TTSEngine:
    def __init__(self, config: Config):
        self.config = config
        self._kokoro_pipeline = None
        if config.tts_engine == "kokoro":
            self._init_kokoro()

    def _configure_hf_env(self):
        """Configure Hugging Face Hub (jeton + timeout réseau) avant tout
        téléchargement, pour limiter les blocages liés au rate limit imposé
        aux requêtes non authentifiées."""
        if self.config.hf_token:
            os.environ["HF_TOKEN"] = self.config.hf_token
            os.environ.setdefault("HUGGING_FACE_HUB_TOKEN", self.config.hf_token)
            log.info("Jeton HF_TOKEN détecté : les téléchargements Hugging Face seront authentifiés.")
        else:
            log.info(
                "Aucun HF_TOKEN configuré : téléchargement Hugging Face en mode anonyme "
                "(rate limit plus bas -> risque de blocage). Ajoutez HF_TOKEN dans un fichier "
                ".env ou dans config.py pour fiabiliser le téléchargement."
            )
        # Empêche huggingface_hub de rester bloqué indéfiniment sur une requête réseau.
        os.environ.setdefault("HF_HUB_DOWNLOAD_TIMEOUT", str(self.config.hf_download_timeout))

    def _init_kokoro(self):
        self._configure_hf_env()
        last_error: Exception | None = None
        init_timeout = max(self.config.hf_download_timeout * 4, 60)

        for attempt in range(1, self.config.hf_max_retries + 1):
            t0 = time.monotonic()
            try:
                log.info(
                    "Initialisation de Kokoro-TTS (tentative %d/%d) — téléchargement du modèle "
                    "kokoro-v1_0.pth depuis Hugging Face si absent du cache local (peut prendre "
                    "plusieurs minutes la première fois, timeout à %ds)...",
                    attempt, self.config.hf_max_retries, init_timeout,
                )

                def _load():
                    from kokoro import KPipeline  # import tardif : dépendance optionnelle
                    kokoro_lang = KOKORO_LANG_MAP.get(self.config.language.lower(), self.config.language)
                    return KPipeline(lang_code=kokoro_lang)

                self._kokoro_pipeline = _run_with_timeout(_load, init_timeout, "Chargement Kokoro-TTS")
                log.info("Kokoro-TTS initialisé en %.1fs (langue=%s, voix=%s).",
                          time.monotonic() - t0, self.config.language, self.config.tts_voice)
                return
            except Exception as e:
                last_error = e
                log.warning(
                    "Tentative %d/%d d'initialisation de Kokoro-TTS échouée après %.1fs : %s",
                    attempt, self.config.hf_max_retries, time.monotonic() - t0, e,
                )
                if attempt < self.config.hf_max_retries:
                    backoff = min(2 ** attempt, 30)
                    log.info("Nouvelle tentative dans %ds...", backoff)
                    time.sleep(backoff)

        log.warning(
            "Kokoro-TTS indisponible après %d tentative(s) (%s) -> repli sur Piper-TTS.",
            self.config.hf_max_retries, last_error,
        )
        self.config.tts_engine = "piper"

    def synthesize(self, text: str, out_wav: Path) -> bool:
        """Synthétise `text` vers le fichier `out_wav` (WAV mono). Retourne False si le
        segment est vide ou en cas d'échec (le segment est alors simplement ignoré)."""
        text = text.strip()
        if not text:
            return False

        if self.config.tts_engine == "kokoro" and self._kokoro_pipeline is not None:
            return self._synth_kokoro(text, out_wav)
        return self._synth_piper(text, out_wav)

    def _synth_kokoro(self, text: str, out_wav: Path) -> bool:
        t0 = time.monotonic()
        log.debug("Synthèse Kokoro démarrée -> %s (%d caractères)", out_wav.name, len(text))
        try:
            def _generate():
                import numpy as np
                import soundfile as sf

                audio_chunks = []
                generator = self._kokoro_pipeline(text, voice=self.config.tts_voice)
                for _graphemes, _phonemes, audio in generator:
                    audio_chunks.append(audio)
                if not audio_chunks:
                    return False
                full_audio = np.concatenate(audio_chunks)
                sf.write(str(out_wav), full_audio, self.config.sample_rate)
                return True

            # Toute la boucle de génération est bornée dans le temps : si Kokoro
            # reste bloqué sur un segment (ex: modèle mal chargé, deadlock GPU),
            # on lève une exception au lieu de figer tout le pipeline.
            ok = _run_with_timeout(_generate, self.config.tts_unit_timeout, "Synthèse Kokoro")
            log.debug("Segment Kokoro terminé en %.1fs -> %s", time.monotonic() - t0, out_wav.name)
            return ok
        except Exception as e:
            log.warning(
                "Échec Kokoro sur un segment après %.1fs (%s), tentative Piper : %s",
                time.monotonic() - t0, out_wav.name, e,
            )
            return self._synth_piper(text, out_wav)

    def _synth_piper(self, text: str, out_wav: Path) -> bool:
        if not self.config.piper_model_path:
            raise TTSError(
                "Aucun moteur TTS disponible : Kokoro a échoué et aucun modèle Piper "
                "(`piper_model_path`) n'est configuré."
            )
        t0 = time.monotonic()
        log.debug("Synthèse Piper démarrée -> %s (%d caractères)", out_wav.name, len(text))
        try:
            proc = subprocess.run(
                [self.config.piper_binary, "--model", self.config.piper_model_path,
                 "--output_file", str(out_wav)],
                input=text.encode("utf-8"),
                stdout=subprocess.PIPE, stderr=subprocess.PIPE, timeout=300,
            )
            if proc.returncode != 0 or not out_wav.exists():
                log.warning("Piper a échoué sur un segment (%.1fs) : %s",
                            time.monotonic() - t0, proc.stderr.decode(errors="ignore"))
                return False
            log.debug("Segment Piper terminé en %.1fs -> %s", time.monotonic() - t0, out_wav.name)
            return True
        except subprocess.TimeoutExpired:
            log.warning("Piper a dépassé le délai de 300s sur un segment (%s), segment ignoré.", out_wav.name)
            return False
        except Exception as e:
            log.warning("Échec Piper sur un segment après %.1fs, segment ignoré : %s",
                        time.monotonic() - t0, e)
            return False

# pdf2audio

Convertisseur PDF → livre audio (.m4a), 100 % local : extraction intelligente
du texte, description des images via un modèle de vision local (Ollama),
synthèse vocale (Kokoro-TTS ou Piper-TTS), fusion en un seul fichier audio.

Deux façons de l'utiliser : une **interface graphique** (recommandée) ou la
**ligne de commande**.

## 1. Installation (une seule fois)

Prérequis à installer manuellement avant de commencer :

- **Python 3.10+** — https://www.python.org/downloads/ (coche bien *"Add
  python.exe to PATH"* pendant l'installation)
- **FFmpeg** — https://www.gyan.dev/ffmpeg/builds/ (build "essentials"),
  à décompresser puis à ajouter au PATH Windows
- **Ollama** — https://ollama.com, puis dans un terminal :
  ```
  ollama pull llama3.2
  ollama pull llama3.2-vision
  ```

Ensuite, dans le dossier du projet, double-clique sur **`1_installer.bat`**.
Ce script crée un environnement Python isolé (`.venv`) et installe tout
automatiquement, sans toucher à ton installation Python globale.

## 2. Utilisation — Interface graphique

Double-clique sur **`2_lancer.bat`**. Ton navigateur s'ouvre avec l'interface :
dépose ton PDF, ajuste les options si besoin, clique sur *Convertir*, et
télécharge le fichier audio à la fin.

> Le `.bat` utilise toujours `python -m streamlit`, donc pas de souci de PATH
> même si la commande `streamlit` seule n'est pas reconnue par Windows.

## 3. Utilisation — Ligne de commande

```
.venv\Scripts\activate
python main.py --pdf mon_livre.pdf --output mon_livre.m4a ^
    --text-model llama3.2 --vision-model llama3.2-vision ^
    --tts-engine kokoro --voice ff_siwis
```

Options utiles :

| Option | Rôle |
|---|---|
| `--chunk-pages N` | taille des sections si le PDF n'a pas de sommaire |
| `--max-chars N` | taille max d'un bloc envoyé au LLM |
| `--tts-engine kokoro\|piper` | moteur vocal |
| `--voice` | voix Kokoro (ex: `ff_siwis` pour du français) |
| `--piper-model` / `--piper-binary` | requis si `--tts-engine piper` |
| `--no-resume` | ignore une conversion précédente interrompue |
| `--keep-temp` | conserve les fichiers audio intermédiaires |

La conversion reprend automatiquement là où elle s'était arrêtée si elle est
interrompue (sauf avec `--no-resume`).

## Dépannage rapide

- **`ModuleNotFoundError`** → relance `1_installer.bat`.
- **`streamlit : terme non reconnu`** → utilise `2_lancer.bat`, ou tape
  `python -m streamlit run streamlit_app.py` toi-même.
- **Erreur FFmpeg / export échoue** → FFmpeg doit être dans le PATH, vérifie
  avec `ffmpeg -version` dans un terminal.
- **Erreur Ollama / connexion refusée** → lance `ollama serve` dans un
  terminal séparé, et vérifie que les modèles sont bien téléchargés.

#!/usr/bin/env python3
"""
Convertisseur PDF -> Audio M4A enrichi, 100% local.

Exemple :
    python main.py --pdf mon_livre.pdf --output mon_livre.m4a \
        --text-model llama3.2 --vision-model llama3.2-vision \
        --tts-engine kokoro --voice ff_siwis
"""
import argparse
import sys
from pathlib import Path

from pdf2audio.config import Config
from pdf2audio.pipeline import run_pipeline


def parse_args():
    p = argparse.ArgumentParser(description="Convertisseur PDF en Audio M4A enrichi (100% local).")
    p.add_argument("--pdf", required=True, help="Chemin vers le fichier PDF source.")
    p.add_argument("--output", required=True, help="Chemin du fichier .m4a à produire.")
    p.add_argument("--tmp-dir", default="./_pdf2audio_tmp", help="Dossier de travail temporaire.")

    p.add_argument("--chunk-pages", type=int, default=20,
                   help="Taille des sections en pages si aucun sommaire n'est détecté.")
    p.add_argument("--max-chars", type=int, default=1800,
                   help="Taille max d'un bloc de texte envoyé au LLM à chaque appel.")

    p.add_argument("--ollama-host", default="http://localhost:11434")
    p.add_argument("--text-model", default="llama3.2")
    p.add_argument("--vision-model", default="llama3.2-vision")

    p.add_argument("--language", default="fr")

    p.add_argument("--tts-engine", choices=["kokoro", "piper"], default="kokoro")
    p.add_argument("--voice", default="ff_siwis", help="Voix Kokoro (ignoré si Piper).")
    p.add_argument("--piper-model", default="", help="Chemin du modèle .onnx Piper.")
    p.add_argument("--piper-binary", default="piper")

    p.add_argument("--no-resume", action="store_true", help="Ignore toute reprise précédente.")
    p.add_argument("--keep-temp", action="store_true", help="Conserve les fichiers audio intermédiaires.")

    p.add_argument("--hf-token", default="",
                   help="Jeton d'accès Hugging Face pour le téléchargement du modèle Kokoro "
                        "(sinon variable d'environnement HF_TOKEN / fichier .env).")

    return p.parse_args()


def main():
    args = parse_args()

    if not Path(args.pdf).exists():
        print(f"Fichier introuvable : {args.pdf}", file=sys.stderr)
        sys.exit(1)

    config = Config(
        pdf_path=args.pdf,
        output_path=args.output,
        tmp_dir=Path(args.tmp_dir),
        chapter_chunk_pages=args.chunk_pages,
        max_chars_per_llm_call=args.max_chars,
        ollama_host=args.ollama_host,
        text_model=args.text_model,
        vision_model=args.vision_model,
        language=args.language,
        tts_engine=args.tts_engine,
        tts_voice=args.voice,
        piper_model_path=args.piper_model,
        piper_binary=args.piper_binary,
        resume=not args.no_resume,
        keep_temp=args.keep_temp,
    )
    if args.hf_token:
        # Ne remplace la valeur par défaut (env HF_TOKEN / .env) que si explicitement fournie.
        config.hf_token = args.hf_token

    run_pipeline(config)


if __name__ == "__main__":
    main()

def session_dir_for(pdf_bytes: bytes, output_name: str) -> Path:
    """Dossier de travail déterministe basé sur le contenu du PDF et le nom de
    sortie choisi : un même fichier relancé avec les mêmes réglages de sortie
    retombe toujours sur le même dossier, donc sur le même manifeste de
    progression, donc reprend là où il s'était arrêté."""
    digest = hashlib.sha256(pdf_bytes + output_name.encode("utf-8")).hexdigest()[:16]
    d = SESSIONS_DIR / digest
    d.mkdir(parents=True, exist_ok=True)
    return d

        "--text-model": text_model,
        "--vision-model": vision_model,

        "--piper-binary": piper_binary,
    }

    if no_resume:

    if keep_temp:

def run_conversion(pdf_bytes: bytes, pdf_filename: str):
    final_output_name = output_name if output_name.strip() else default_output_name
    work_dir = session_dir_for(pdf_bytes, final_output_name)
    pdf_path = work_dir / pdf_filename
    if not pdf_path.exists():
        pdf_path.write_bytes(pdf_bytes)

    output_path = work_dir / final_output_name
    tmp_dir = work_dir / "tmp"
    tmp_dir.mkdir(exist_ok=True)

    resuming = not no_resume and (tmp_dir / "manifest.json").exists()
    if resuming:
        st.info(
            "Une conversion précédente de ce même PDF a été détectée pour ce même nom de "
            "sortie : reprise là où elle s'était arrêtée.",
            icon="🔁",
        )

    cmd = build_command(pdf_path, output_path, tmp_dir)

    # Le jeton HF passe par une variable d'environnement du sous-processus plutôt que par un
    # argument en ligne de commande, pour ne jamais apparaître dans les logs affichés ci-dessous
    # ni dans la liste des processus du système.
    child_env = os.environ.copy()
    if hf_token.strip():
        child_env["HF_TOKEN"] = hf_token.strip()

    log_lines = []
    progress_bar = progress_placeholder.progress(0, text="Démarrage de la conversion…")

    process = subprocess.Popen(
        cmd,
        cwd=str(APP_DIR),
        env=child_env,
        stdout=subprocess.PIPE,
        stderr=subprocess.STDOUT,
        text=True,
        bufsize=1,
    )

    # Nombre de lignes affichées et fréquence de rafraîchissement volontairement
    # limités : sur un PDF volumineux, le pipeline peut produire des centaines
    # de lignes de log en quelques secondes, et un réaffichage trop fréquent ou
    # trop volumineux du journal fait planter le rendu de la page (le
    # navigateur n'arrive plus à suivre le rythme des mises à jour du DOM).
    MAX_DISPLAYED_LINES = 50
    MIN_REFRESH_INTERVAL_S = 0.5

    def render_log():
        log_placeholder.markdown(
            f'<div class="log-box">{"<br>".join(log_lines[-MAX_DISPLAYED_LINES:])}</div>',
            unsafe_allow_html=True,
        )

    last_render = 0.0
    for line in iter(process.stdout.readline, ""):
        if not line:
            break
        log_lines.append(line.rstrip("\n"))

        match = PROGRESS_RE.findall(line)
        if match:
            try:
                pct = min(int(match[-1]), 100)
                progress_bar.progress(pct, text=line.strip()[:120])
            except ValueError:
                pass

        now = time.time()
        if now - last_render > MIN_REFRESH_INTERVAL_S:
            render_log()
            last_render = now

    process.wait()
    render_log()

    if process.returncode == 0 and output_path.exists():
        progress_placeholder.progress(100, text="Conversion terminée ✔️")
        audio_bytes = output_path.read_bytes()
        result_placeholder.success("🎉 Ton livre audio est prêt !")
        result_placeholder.download_button(

"""Fusion des segments WAV en un unique fichier audio .m4a (AAC), via pydub + FFmpeg."""
from __future__ import annotations

import logging
from pathlib import Path
from typing import List

from pydub import AudioSegment

log = logging.getLogger(__name__)


def merge_wavs_to_segment(wav_paths: List[Path], silence_ms: int) -> AudioSegment:
    combined = AudioSegment.silent(duration=0)
    silence = AudioSegment.silent(duration=silence_ms)
    for p in wav_paths:
        if not p.exists():
            continue
        try:
            seg = AudioSegment.from_file(p)
        except Exception as e:
            log.warning("Segment audio illisible, ignoré (%s) : %s", p, e)
            continue
        combined += seg + silence
    return combined


def export_m4a(segment: AudioSegment, output_path: Path, bitrate: str = "128k") -> None:
    output_path.parent.mkdir(parents=True, exist_ok=True)
    # Le conteneur .m4a est un MP4 audio-only encodé en AAC.
    segment.export(str(output_path), format="mp4", codec="aac", bitrate=bitrate)
    log.info("Fichier audio final écrit : %s", output_path)


def merge_chapter_wavs(chapter_wav_paths: List[Path], output_path: Path,
                        silence_between_chapters_ms: int) -> None:
    full = merge_wavs_to_segment(chapter_wav_paths, silence_between_chapters_ms)
    if len(full) == 0:
        raise RuntimeError("Aucun segment audio valide n'a pu être fusionné.")
    export_m4a(full, output_path)

"""Client HTTP minimal pour Ollama (100% local, pas de dépendance externe hors `requests`)."""
from __future__ import annotations

import base64
import json
import logging

import requests

from .config import Config

log = logging.getLogger(__name__)


class OllamaError(RuntimeError):
    pass


def chat(config: Config, model: str, messages: list, images_b64: list | None = None) -> str:
    """Appelle /api/chat en mode non streaming et retourne le texte de la réponse."""
    url = f"{config.ollama_host.rstrip('/')}/api/chat"
    if images_b64:
        # Attache les images au dernier message utilisateur (format multimodal Ollama)
        messages = [dict(m) for m in messages]
        messages[-1]["images"] = images_b64

    payload = {"model": model, "messages": messages, "stream": False}
    try:
        resp = requests.post(url, json=payload, timeout=config.llm_timeout)
        resp.raise_for_status()
    except requests.RequestException as e:
        raise OllamaError(
            f"Impossible de contacter Ollama à {config.ollama_host} (modèle '{model}'). "
            f"Vérifiez que `ollama serve` tourne et que le modèle est installé "
            f"(`ollama pull {model}`). Détail : {e}"
        ) from e

    data = resp.json()
    return data.get("message", {}).get("content", "").strip()


def image_to_b64(image_bytes: bytes) -> str:
    return base64.b64encode(image_bytes).decode("utf-8")


def list_models(ollama_host: str = "http://localhost:11434", timeout: float = 2.0) -> list[str]:
    """Retourne la liste des noms de modèles installés localement via `ollama pull`.

    Utilisé par l'interface pour proposer un menu déroulant plutôt qu'un champ de
    texte libre. Retourne une liste vide (sans lever d'exception) si Ollama n'est
    pas joignable, pour ne jamais bloquer l'affichage de l'interface."""
    url = f"{ollama_host.rstrip('/')}/api/tags"
    try:
        resp = requests.get(url, timeout=timeout)
        resp.raise_for_status()
        data = resp.json()
        return sorted(m["name"] for m in data.get("models", []))
    except Exception as e:
        log.info("Impossible de lister les modèles Ollama installés (%s) : %s", ollama_host, e)
        return []

"""
Extraction séquentielle du PDF avec PyMuPDF (fitz).

- Découpe le document en "chapitres" (via la table des matières si disponible,
  sinon par blocs de N pages) pour un traitement en flux et une empreinte
  mémoire bornée, quelle que soit la taille du document (5 à 1000+ pages).
- Détecte automatiquement en-têtes / pieds de page répétitifs.
- Détecte les notes de bas de page via la position et la taille de police.
- Restitue un flux ordonné d'unités "texte" et "image" dans l'ordre de lecture.
"""
from __future__ import annotations

import statistics
from dataclasses import dataclass
from typing import Iterator, List, Optional, Tuple

try:
    import pymupdf as fitz  # PyMuPDF (nom de paquet moderne, supprime le warning de dépréciation)
except ImportError:  # compat versions de PyMuPDF trop anciennes pour exposer le module `pymupdf`
    import fitz

from .config import Config


@dataclass
class ChapterRange:
    index: int
    title: str
    start_page: int  # inclus, 0-based
    end_page: int     # exclus, 0-based


@dataclass
class ContentUnit:
    kind: str          # "text" ou "image"
    page: int
    text: str = ""
    xref: int = 0


def get_chapter_ranges(doc: fitz.Document, config: Config) -> List[ChapterRange]:
    """Découpe le document en chapitres à partir du sommaire (TOC) si présent,
    sinon en tranches fixes de `chapter_chunk_pages` pages."""
    toc = doc.get_toc(simple=True)  # [[niveau, titre, page_1indexed], ...]
    n_pages = doc.page_count

    top_level = [t for t in toc if t[0] == 1] if toc else []
    if len(top_level) >= 2:
        ranges = []
        for i, (_, title, page1) in enumerate(top_level):
            start = max(page1 - 1, 0)
            end = (top_level[i + 1][2] - 1) if i + 1 < len(top_level) else n_pages
            if end > start:
                ranges.append(ChapterRange(i, title.strip() or f"Chapitre {i+1}", start, end))
        # Fusionne les chapitres trop courts avec le suivant pour éviter des micro-appels LLM
        merged: List[ChapterRange] = []
        for r in ranges:
            if merged and (r.end_page - r.start_page) < 2:
                merged[-1].end_page = r.end_page
            else:
                merged.append(r)
        if merged:
            return merged

    # Repli : découpage fixe par nombre de pages
    step = max(config.chapter_chunk_pages, 1)
    ranges = []
    for i, start in enumerate(range(0, n_pages, step)):
        end = min(start + step, n_pages)
        ranges.append(ChapterRange(i, f"Section {i+1} (pages {start+1}-{end})", start, end))
    return ranges


def _collect_boilerplate_lines(doc: fitz.Document, config: Config) -> set:
    """Identifie les lignes récurrentes en haut/bas de page (en-têtes, pieds de page,
    numérotation) en comparant leur fréquence d'apparition sur un échantillon de pages."""
    from collections import Counter

    counts: Counter = Counter()
    n_pages = doc.page_count
    sample = range(0, n_pages, max(1, n_pages // min(n_pages, 60) or 1))

    for pno in sample:
        page = doc[pno]
        h = page.rect.height
        margin = h * config.header_footer_margin_ratio
        for block in page.get_text("blocks"):
            x0, y0, x1, y1, text, *_ = block
            text = text.strip()
            if not text or len(text) > 90:
                continue
            if y0 <= margin or y1 >= h - margin:
                counts[text] += 1

    return {t for t, c in counts.items() if c >= config.header_footer_min_repeat}


def _median_font_size(page: fitz.Page) -> float:
    sizes = []
    d = page.get_text("dict")
    for block in d.get("blocks", []):
        for line in block.get("lines", []):
            for span in line.get("spans", []):
                if span.get("text", "").strip():
                    sizes.append(span["size"])
    return statistics.median(sizes) if sizes else 10.0


def _is_footnote(y0: float, y1: float, page_height: float, font_size: float,
                  median_size: float, config: Config) -> bool:
    near_bottom = y1 >= page_height * (1 - config.header_footer_margin_ratio * 1.5)
    small_font = font_size <= median_size * config.footnote_font_ratio
    return near_bottom and small_font


def iter_chapter_content(doc: fitz.Document, chapter: ChapterRange,
                          boilerplate: set, config: Config) -> Iterator[ContentUnit]:
    """Produit un flux ordonné d'unités de contenu (texte / image) pour un chapitre,
    en filtrant en-têtes, pieds de page et notes de bas de page."""
    for pno in range(chapter.start_page, chapter.end_page):
        page = doc[pno]
        h = page.rect.height
        margin = h * config.header_footer_margin_ratio
        median_size = _median_font_size(page)

        # Éléments positionnés : texte (avec taille de police) + images, triés par position verticale
        elements: List[Tuple[float, str, object]] = []

        d = page.get_text("dict")
        for block in d.get("blocks", []):
            if block.get("type") != 0:
                continue
            y0 = block["bbox"][1]
            y1 = block["bbox"][3]
            block_text_parts = []
            font_sizes = []
            for line in block.get("lines", []):
                for span in line.get("spans", []):
                    t = span.get("text", "")
                    if t.strip():
                        block_text_parts.append(t)
                        font_sizes.append(span["size"])
            text = "".join(block_text_parts).strip()
            if not text:
                continue
            if text in boilerplate:
                continue
            if y0 <= margin or y1 >= h - margin:
                continue
            avg_font = sum(font_sizes) / len(font_sizes) if font_sizes else median_size
            if _is_footnote(y0, y1, h, avg_font, median_size, config):
                continue
            elements.append((y0, "text", text))

        for img in page.get_images(full=True):
            xref = img[0]
            try:
                bbox = page.get_image_bbox(img)
                y0 = bbox.y0
            except Exception:
                y0 = h  # à défaut, placée en fin de page
            elements.append((y0, "image", xref))

        elements.sort(key=lambda e: e[0])

        for y0, kind, payload in elements:
            if kind == "text":
                yield ContentUnit(kind="text", page=pno, text=_clean_ponctuation_lourde(payload))
            else:
                yield ContentUnit(kind="image", page=pno, xref=payload)


def _clean_ponctuation_lourde(text: str) -> str:
    """Nettoyage syntaxique léger avant passage au LLM : espaces multiples,
    tirets de fin de ligne, puces."""
    import re

    text = re.sub(r"-\n", "", text)          # mots coupés en fin de ligne
    text = re.sub(r"\s*\n\s*", " ", text)     # retours à la ligne internes
    text = re.sub(r"[•▪●◦]+", " ", text)      # puces
    text = re.sub(r"\s{2,}", " ", text)
    return text.strip()


def extract_image_bytes(doc: fitz.Document, xref: int) -> Optional[bytes]:
    try:
        img_dict = doc.extract_image(xref)
        return img_dict["image"]
    except Exception:
        return None


def compute_boilerplate(config: Config) -> set:
    with fitz.open(config.pdf_path) as doc:
        return _collect_boilerplate_lines(doc, config)

"""Orchestration bout en bout : PDF -> texte nettoyé + images décrites -> audio -> M4A.

Traitement séquentiel chapitre par chapitre pour borner la consommation mémoire sur
les documents volumineux (1000+ pages), avec reprise possible en cas d'interruption.
"""
from __future__ import annotations

import json
import logging
import time
from pathlib import Path
from typing import List

import fitz
from tqdm import tqdm

from .audio_merger import merge_chapter_wavs, merge_wavs_to_segment, export_m4a
from .config import Config
from .image_describer import describe_image
from .pdf_extractor import (
    ContentUnit,
    compute_boilerplate,
    extract_image_bytes,
    get_chapter_ranges,
    iter_chapter_content,
)
from .text_cleaner import clean_and_reformulate
from .tts_engine import TTSEngine

log = logging.getLogger(__name__)


class Manifest:
    """Suivi de progression persisté sur disque pour permettre la reprise."""

    def __init__(self, path: Path):
        self.path = path
        self.data = {"chapters_done": [], "chapter_wavs": {}}
        if path.exists():
            try:
                self.data = json.loads(path.read_text(encoding="utf-8"))
            except Exception:
                log.warning("Manifeste corrompu, redémarrage à zéro.")

    def is_done(self, chapter_index: int) -> bool:
        return chapter_index in self.data["chapters_done"]

    def mark_done(self, chapter_index: int, wav_path: str):
        if chapter_index not in self.data["chapters_done"]:
            self.data["chapters_done"].append(chapter_index)
        self.data["chapter_wavs"][str(chapter_index)] = wav_path
        self._save()

    def _save(self):
        self.path.write_text(json.dumps(self.data, ensure_ascii=False, indent=2), encoding="utf-8")


def _build_final_units(doc: fitz.Document, chapter, boilerplate: set, config: Config) -> List[str]:
    """Construit, pour un chapitre, la liste ordonnée des unités de texte prêtes pour la
    synthèse vocale : texte nettoyé par le LLM, entrecoupé des narrations d'images."""
    units: List[str] = []
    text_buffer = ""

    def flush_text():
        nonlocal text_buffer
        if text_buffer.strip():
            units.append(clean_and_reformulate(text_buffer, config))
        text_buffer = ""

    for item in iter_chapter_content(doc, chapter, boilerplate, config):
        if item.kind == "text":
            candidate = f"{text_buffer}\n{item.text}" if text_buffer else item.text
            if len(candidate) > config.max_chars_per_llm_call and text_buffer:
                flush_text()
                text_buffer = item.text
            else:
                text_buffer = candidate
        else:  # image
            flush_text()
            img_bytes = extract_image_bytes(doc, item.xref)
            narration = describe_image(img_bytes, config) if img_bytes else ""
            if narration:
                units.append(narration)

    flush_text()
    return [u for u in units if u.strip()]


def run_pipeline(config: Config) -> Path:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")

    manifest = Manifest(config.tmp_dir / "manifest.json")
    tts = TTSEngine(config)

    log.info("Analyse du document et détection des en-têtes/pieds de page répétitifs...")
    boilerplate = compute_boilerplate(config)

    with fitz.open(config.pdf_path) as doc:
        chapters = get_chapter_ranges(doc, config)
        log.info("Document découpé en %d chapitre(s) / section(s) pour %d page(s).",
                  len(chapters), doc.page_count)

        total_chapters = len(chapters)
        for pos, chapter in enumerate(tqdm(chapters, desc="Chapitres", unit="chap"), start=1):
            pct = int(pos / total_chapters * 100) if total_chapters else 100
            print(f"PROGRESSION {pct}% - chapitre {pos}/{total_chapters}", flush=True)

            if config.resume and manifest.is_done(chapter.index):
                log.info("Chapitre %d déjà traité, reprise -> passage au suivant.", chapter.index)
                continue

            log.info("Traitement du chapitre %d : « %s » (pages %d-%d)",
                      chapter.index, chapter.title, chapter.start_page + 1, chapter.end_page)

            final_units = _build_final_units(doc, chapter, boilerplate, config)
            if not final_units:
                log.warning("Chapitre %d vide après nettoyage, ignoré.", chapter.index)
                manifest.mark_done(chapter.index, "")
                continue

            chapter_dir = config.tmp_dir / f"chapter_{chapter.index:04d}"
            chapter_dir.mkdir(parents=True, exist_ok=True)

            segment_wavs = []
            total_units = len(final_units)
            for i, unit_text in enumerate(final_units, start=1):
                seg_path = chapter_dir / f"unit_{i - 1:04d}.wav"
                log.info("  -> Segment audio %d/%d du chapitre %d (%d caractères)...",
                          i, total_units, chapter.index, len(unit_text))
                # Progression fine (imprimée pour l'UI Streamlit) : combine la progression
                # inter-chapitres avec la progression des segments à l'intérieur du chapitre
                # en cours, pour que la barre avance même sur un chapitre long.
                sub_pct = int(((pos - 1) + i / max(total_units, 1)) / total_chapters * 100) if total_chapters else 100
                print(f"PROGRESSION {sub_pct}% - chapitre {pos}/{total_chapters}, "
                      f"segment {i}/{total_units}", flush=True)
                t_seg = time.monotonic()
                try:
                    ok = tts.synthesize(unit_text, seg_path)
                except Exception:
                    # Filet de sécurité : même une exception inattendue (non prévue par
                    # TTSEngine) ne doit jamais interrompre silencieusement le pipeline.
                    log.exception("Erreur inattendue sur le segment %d/%d du chapitre %d, "
                                  "segment ignoré.", i, total_units, chapter.index)
                    ok = False
                log.info("  <- Segment %d/%d terminé en %.1fs (succès=%s)",
                          i, total_units, time.monotonic() - t_seg, ok)
                if ok:
                    segment_wavs.append(seg_path)

            if not segment_wavs:
                log.warning("Aucun segment audio généré pour le chapitre %d.", chapter.index)
                manifest.mark_done(chapter.index, "")
                continue

            chapter_wav = config.tmp_dir / f"chapter_{chapter.index:04d}.wav"
            combined = merge_wavs_to_segment(segment_wavs, config.silence_between_units_ms)
            combined.export(str(chapter_wav), format="wav")

            if not config.keep_temp:
                for p in segment_wavs:
                    p.unlink(missing_ok=True)
                try:
                    chapter_dir.rmdir()
                except OSError:
                    pass

            manifest.mark_done(chapter.index, str(chapter_wav))
            log.info("Chapitre %d terminé -> %s", chapter.index, chapter_wav)

    log.info("Fusion finale de tous les chapitres en un seul fichier .m4a...")
    ordered_wavs = [
        Path(manifest.data["chapter_wavs"][str(c.index)])
        for c in chapters
        if manifest.data["chapter_wavs"].get(str(c.index))
    ]
    merge_chapter_wavs(ordered_wavs, config.output_path, config.silence_between_chapters_ms)

    if not config.keep_temp:
        for p in ordered_wavs:
            p.unlink(missing_ok=True)

    log.info("Terminé. Fichier audio disponible : %s", config.output_path)
    return config.output_path

"""Nettoyage et reformulation du texte extrait, via le LLM local (Ollama)."""
from __future__ import annotations

import logging

from .config import Config
from .ollama_client import chat

log = logging.getLogger(__name__)

SYSTEM_PROMPT = """Tu prépares un texte pour une lecture audio à voix haute.
Règles strictes :
- Supprime toute numérotation de section, de page, ou de liste ("1.2.3", "Chapitre 4", "p. 12"...).
- Supprime les références bibliographiques et appels de notes ([12], (Dupont, 2020), *, †...).
- Supprime la ponctuation lourde ou décorative (tirets de puces, guillemets typographiques imbriqués,
  parenthèses d'appel de figure comme "(voir Fig. 3)").
- Ne résume PAS le contenu, ne coupe aucune idée : reformule uniquement la forme pour un flux
  oral naturel, fluide et continu, avec une ponctuation simple (points, virgules).
- Ne commente pas ta tâche, ne rajoute aucune introduction ni conclusion : réponds uniquement
  avec le texte prêt à être lu, dans la même langue que le texte source.
"""


def clean_and_reformulate(raw_text: str, config: Config) -> str:
    raw_text = raw_text.strip()
    if not raw_text:
        return ""
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": raw_text},
    ]
    try:
        result = chat(config, config.text_model, messages)
    except Exception as e:
        log.warning("Échec du nettoyage LLM, utilisation du texte brut nettoyé minimalement : %s", e)
        return raw_text
    return result if result else raw_text


def split_into_llm_chunks(text_units: list[str], max_chars: int) -> list[str]:
    """Regroupe une liste de paragraphes bruts en blocs de taille raisonnable
    pour limiter le nombre d'appels au LLM tout en respectant le contexte."""
    chunks, buffer = [], ""
    for unit in text_units:
        if len(buffer) + len(unit) + 1 > max_chars and buffer:
            chunks.append(buffer.strip())
            buffer = unit
        else:
            buffer = f"{buffer}\n{unit}" if buffer else unit
    if buffer.strip():
        chunks.append(buffer.strip())
    return chunks

"""Synthèse vocale locale : Kokoro-TTS (par défaut, voix neuronales naturelles)
avec repli automatique sur Piper-TTS si Kokoro n'est pas disponible."""
from __future__ import annotations

import logging
import os
import subprocess
import time
from concurrent.futures import ThreadPoolExecutor
from concurrent.futures import TimeoutError as FutureTimeoutError
from pathlib import Path

from .config import Config

log = logging.getLogger(__name__)

# Kokoro attend des codes de langue courts et spécifiques, différents des codes
# ISO habituels (ex: "fr" -> "f"). Cette table convertit les codes usuels.
KOKORO_LANG_MAP = {
    "fr": "f", "fr-fr": "f",
    "en": "a", "en-us": "a",
    "en-gb": "b",
    "es": "e",
    "hi": "h",
    "it": "i",
    "pt": "p", "pt-br": "p",
    "ja": "j",
    "zh": "z",
}


class TTSError(RuntimeError):
    pass


class TTSTimeoutError(TTSError):
    pass


def _run_with_timeout(fn, timeout: float, label: str):
    """Exécute `fn` (sans argument) dans un thread séparé et lève TTSTimeoutError
    si `timeout` secondes sont dépassées, au lieu de laisser le pipeline se
    bloquer indéfiniment (cas typique : téléchargement Hugging Face qui stalle
    sans jamais lever d'exception réseau).

    Le thread sous-jacent peut continuer de tourner en arrière-plan une fois le
    timeout atteint (Python ne permet pas de tuer un thread proprement) ; c'est
    un compromis volontaire pour rendre la main à l'utilisateur plutôt que de
    rester bloqué sans retour visuel.

    Important : on n'utilise volontairement PAS `with ThreadPoolExecutor(...) as
    executor:` ici, car la sortie de ce bloc appelle `shutdown(wait=True)` et
    attendrait silencieusement la fin du thread bloqué, annulant l'effet du
    timeout. `shutdown(wait=False)` est utilisé explicitement à la place."""
    executor = ThreadPoolExecutor(max_workers=1)
    future = executor.submit(fn)
    try:
        result = future.result(timeout=timeout)
        executor.shutdown(wait=False)
        return result
    except FutureTimeoutError:
        executor.shutdown(wait=False)
        raise TTSTimeoutError(
            f"{label} : délai dépassé après {timeout:.0f}s sans réponse."
        )


class TTSEngine:
    def __init__(self, config: Config):
        self.config = config
        self._kokoro_pipeline = None
        if config.tts_engine == "kokoro":
            self._init_kokoro()

    def _configure_hf_env(self):
        """Configure Hugging Face Hub (jeton + timeout réseau) avant tout
        téléchargement, pour limiter les blocages liés au rate limit imposé
        aux requêtes non authentifiées."""
        if self.config.hf_token:
            os.environ["HF_TOKEN"] = self.config.hf_token
            os.environ.setdefault("HUGGING_FACE_HUB_TOKEN", self.config.hf_token)
            log.info("Jeton HF_TOKEN détecté : les téléchargements Hugging Face seront authentifiés.")
        else:
            log.info(
                "Aucun HF_TOKEN configuré : téléchargement Hugging Face en mode anonyme "
                "(rate limit plus bas -> risque de blocage). Ajoutez HF_TOKEN dans un fichier "
                ".env ou dans config.py pour fiabiliser le téléchargement."
            )
        # Empêche huggingface_hub de rester bloqué indéfiniment sur une requête réseau.
        os.environ.setdefault("HF_HUB_DOWNLOAD_TIMEOUT", str(self.config.hf_download_timeout))

    def _init_kokoro(self):
        self._configure_hf_env()
        last_error: Exception | None = None
        init_timeout = max(self.config.hf_download_timeout * 4, 60)

        for attempt in range(1, self.config.hf_max_retries + 1):
            t0 = time.monotonic()
            try:
                log.info(
                    "Initialisation de Kokoro-TTS (tentative %d/%d) — téléchargement du modèle "
                    "kokoro-v1_0.pth depuis Hugging Face si absent du cache local (peut prendre "
                    "plusieurs minutes la première fois, timeout à %ds)...",
                    attempt, self.config.hf_max_retries, init_timeout,
                )

                def _load():
                    import torch
                    from kokoro import KPipeline  # import tardif : dépendance optionnelle

                    # Sélection explicite du device : sans ce paramètre, Kokoro se
                    # rabat silencieusement sur le CPU, y compris quand une carte
                    # NVIDIA dédiée est disponible (cas fréquent sur PC portable
                    # avec double carte graphique intégrée + dédiée).
                    cuda_ok = torch.cuda.is_available()
                    device = "cuda" if cuda_ok else "cpu"
                    if cuda_ok:
                        log.info("GPU détecté par PyTorch : %s -> Kokoro-TTS va s'exécuter dessus.",
                                  torch.cuda.get_device_name(0))
                    else:
                        log.warning(
                            "Aucun GPU CUDA détecté par PyTorch : Kokoro-TTS va tourner sur le "
                            "processeur (beaucoup plus lent). Si tu as une carte NVIDIA, ta version "
                            "de PyTorch est probablement une build CPU-only (pip a installé la "
                            "mauvaise variante) -> réinstalle torch depuis "
                            "https://pytorch.org/get-started/locally/ avec la version CUDA adaptée "
                            "à ton driver."
                        )

                    kokoro_lang = KOKORO_LANG_MAP.get(self.config.language.lower(), self.config.language)
                    return KPipeline(lang_code=kokoro_lang, device=device)

                self._kokoro_pipeline = _run_with_timeout(_load, init_timeout, "Chargement Kokoro-TTS")
                log.info("Kokoro-TTS initialisé en %.1fs (langue=%s, voix=%s).",
                          time.monotonic() - t0, self.config.language, self.config.tts_voice)
                return
            except Exception as e:
                last_error = e
                log.warning(
                    "Tentative %d/%d d'initialisation de Kokoro-TTS échouée après %.1fs : %s",
                    attempt, self.config.hf_max_retries, time.monotonic() - t0, e,
                )
                if attempt < self.config.hf_max_retries:
                    backoff = min(2 ** attempt, 30)
                    log.info("Nouvelle tentative dans %ds...", backoff)
                    time.sleep(backoff)

        log.warning(
            "Kokoro-TTS indisponible après %d tentative(s) (%s) -> repli sur Piper-TTS.",
            self.config.hf_max_retries, last_error,
        )
        self.config.tts_engine = "piper"

    def synthesize(self, text: str, out_wav: Path) -> bool:
        """Synthétise `text` vers le fichier `out_wav` (WAV mono). Retourne False si le
        segment est vide ou en cas d'échec (le segment est alors simplement ignoré)."""
        text = text.strip()
        if not text:
            return False

        if self.config.tts_engine == "kokoro" and self._kokoro_pipeline is not None:
            return self._synth_kokoro(text, out_wav)
        return self._synth_piper(text, out_wav)

    def _synth_kokoro(self, text: str, out_wav: Path) -> bool:
        t0 = time.monotonic()
        log.debug("Synthèse Kokoro démarrée -> %s (%d caractères)", out_wav.name, len(text))
        try:
            def _generate():
                import numpy as np
                import soundfile as sf

                audio_chunks = []
                generator = self._kokoro_pipeline(text, voice=self.config.tts_voice)
                for _graphemes, _phonemes, audio in generator:
                    audio_chunks.append(audio)
                if not audio_chunks:
                    return False
                full_audio = np.concatenate(audio_chunks)
                sf.write(str(out_wav), full_audio, self.config.sample_rate)
                return True

            # Toute la boucle de génération est bornée dans le temps : si Kokoro
            # reste bloqué sur un segment (ex: modèle mal chargé, deadlock GPU),
            # on lève une exception au lieu de figer tout le pipeline.
            ok = _run_with_timeout(_generate, self.config.tts_unit_timeout, "Synthèse Kokoro")
            log.debug("Segment Kokoro terminé en %.1fs -> %s", time.monotonic() - t0, out_wav.name)
            return ok
        except Exception as e:
            log.warning(
                "Échec Kokoro sur un segment après %.1fs (%s), tentative Piper : %s",
                time.monotonic() - t0, out_wav.name, e,
            )
            return self._synth_piper(text, out_wav)

    def _synth_piper(self, text: str, out_wav: Path) -> bool:
        if not self.config.piper_model_path:
            raise TTSError(
                "Aucun moteur TTS disponible : Kokoro a échoué et aucun modèle Piper "
                "(`piper_model_path`) n'est configuré."
            )
        t0 = time.monotonic()
        log.debug("Synthèse Piper démarrée -> %s (%d caractères)", out_wav.name, len(text))
        try:
            proc = subprocess.run(
                [self.config.piper_binary, "--model", self.config.piper_model_path,
                 "--output_file", str(out_wav)],
                input=text.encode("utf-8"),
                stdout=subprocess.PIPE, stderr=subprocess.PIPE, timeout=300,
            )
            if proc.returncode != 0 or not out_wav.exists():
                log.warning("Piper a échoué sur un segment (%.1fs) : %s",
                            time.monotonic() - t0, proc.stderr.decode(errors="ignore"))
                return False
            log.debug("Segment Piper terminé en %.1fs -> %s", time.monotonic() - t0, out_wav.name)
            return True
        except subprocess.TimeoutExpired:
            log.warning("Piper a dépassé le délai de 300s sur un segment (%s), segment ignoré.", out_wav.name)
            return False
        except Exception as e:
            log.warning("Échec Piper sur un segment après %.1fs, segment ignoré : %s",
                        time.monotonic() - t0, e)
            return False
