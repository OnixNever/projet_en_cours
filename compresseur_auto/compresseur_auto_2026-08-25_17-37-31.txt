# Auto Context Sync

Surveille tes projets, régénère le fichier de contexte (format blinder) uniquement
pour les projets modifiés, et le pousse sur Git en gardant les 3 dernières versions.

## 1. Installation

1. Installe Git si ce n'est pas déjà fait, et vérifie que la commande `git` fonctionne
   dans un terminal (`git --version`).
2. Configure l'accès à ton dépôt distant sans mot de passe à chaque fois :
   - soit via une clé SSH liée à ton compte GitHub,
   - soit via le Git Credential Manager (Windows le propose automatiquement au
     premier push, il retient ensuite tes identifiants).
3. Crée un dépôt GitHub vide (ex: `context-sync-repo`), qui ne contiendra QUE les
   fichiers texte générés, jamais ton code source.
4. Copie ce dossier `auto_context_sync` où tu veux sur ton PC.
5. Ouvre `config.json` et adapte :
   - `repo_local_path` : où le dépôt sera cloné localement sur ton PC
   - `repo_remote_url` : l'URL de ton dépôt GitHub
   - `projects` : la liste de tes projets à surveiller (nom + chemin du dossier)

## 2. Test manuel

Dans un terminal, à la racine du dossier :

```
python auto_context_sync.py
```

Premier lancement : le dépôt est cloné, tous les projets sont considérés comme
"changés" (pas d'état précédent), donc tout est généré et poussé une première fois.
Les lancements suivants ne régénèrent que ce qui a réellement changé.

## 3. Lancement automatique au démarrage de Windows

1. Ouvre le "Planificateur de tâches" Windows (rechercher "Planificateur de tâches"
   dans le menu Démarrer).
2. "Créer une tâche" (pas "tâche de base", pour avoir plus d'options).
3. Onglet Général : nom "AutoContextSync", coche "Exécuter même si l'utilisateur
   n'est pas connecté" si tu veux que ça marche sans être ouvert de session,
   sinon laisse par défaut.
4. Onglet Déclencheurs : Nouveau -> "Au démarrage de l'ordinateur" (ou "À l'ouverture
   de session" si tu préfères que ça se lance à ta connexion).
5. Onglet Actions : Nouveau -> Programme : chemin vers `lancer_sync.bat` (ou vers
   `python.exe` avec comme argument `auto_context_sync.py --watch --interval 300`
   si tu veux qu'il tourne en continu en tâche de fond plutôt qu'une passe unique).
6. Valide.

## 4. Passage supplémentaire avant extinction (optionnel)

Windows n'a pas de déclencheur "avant extinction" direct, mais on peut se brancher
sur l'événement système qui apparaît quand une extinction est demandée :

1. Dans le Planificateur de tâches, crée une nouvelle tâche "AutoContextSync-Shutdown".
2. Onglet Déclencheurs : Nouveau -> "Lors d'un événement" -> Personnalisé ->
   Journal : `System`, Source : `User32`, ID de l'événement : `1074`.
3. Onglet Actions : même action que ci-dessus, mais sans `--watch` (une passe unique
   suffit, il faut que ce soit rapide).

C'est une astuce reposant sur un événement Windows standard, pas une garantie à 100%
si l'extinction est très brutale, mais ça couvre les extinctions normales.

## 5. Mode surveillance continue (alternative plus simple)

Plutôt que de gérer démarrage + extinction séparément, tu peux simplement lancer :

```
python auto_context_sync.py --watch --interval 300
```

au démarrage de Windows (étape 3), et le laisser tourner en fond. Il revérifie tous
les projets toutes les 300 secondes (5 min, ajustable) et pousse dès qu'il détecte un
changement, sans que tu aies à y penser.

## 6. Logs

Toutes les actions sont journalisées dans `auto_context_sync.log`, à côté du script.

"""
Auto Context Sync
------------------
Surveille des projets de code, régénère automatiquement un fichier de contexte
(au format "blinder" : arborescence + contenu complet des fichiers) dès qu'un
fichier a été modifié, puis pousse ce fichier texte sur un dépôt Git en ne
gardant que les 3 dernières versions par projet.

Ne pousse JAMAIS le code source lui-même : seuls les fichiers .txt générés
sont envoyés sur Git.

Dépendances :
    - Python 3.9+
    - Git installé et accessible dans le PATH, avec accès en écriture au
      dépôt distant déjà configuré (SSH ou credential manager Windows)

Utilisation :
    python auto_context_sync.py            -> passe unique (scan + push si besoin)
    python auto_context_sync.py --watch     -> reste actif et surveille en continu

Configuration : voir config.json à côté de ce script.
"""

import os
import sys
import json
import time
import hashlib
import shutil
import subprocess
import argparse
from datetime import datetime

SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
CONFIG_PATH = os.path.join(SCRIPT_DIR, "config.json")
STATE_PATH = os.path.join(SCRIPT_DIR, "state.json")
LOG_PATH = os.path.join(SCRIPT_DIR, "auto_context_sync.log")

# ---------------------------------------------------------------------------
# Reprend les règles de filtrage de blinder.py pour rester cohérent avec
# le format que tu utilises déjà.
# ---------------------------------------------------------------------------
IGNORE_DIRS = {
    ".git", "node_modules", "__pycache__", ".venv", "venv", "dist", "build",
    ".idea", ".vscode", ".mypy_cache", ".pytest_cache", "target", ".next",
    "coverage", ".tox", "egg-info",
}
IGNORE_EXTS = {
    ".exe", ".dll", ".so", ".dylib", ".png", ".jpg", ".jpeg", ".gif", ".bmp",
    ".ico", ".webp", ".zip", ".tar", ".gz", ".7z", ".rar", ".pyc", ".pyo",
    ".class", ".jar", ".pdf", ".mp3", ".mp4", ".mov", ".avi", ".woff",
    ".woff2", ".ttf", ".eot", ".lock", ".db", ".sqlite", ".bin",
}
MAX_FILE_SIZE = 2 * 1024 * 1024  # 2 Mo, comme dans blinder
VERSIONS_TO_KEEP = 3


def log(message: str):
    stamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    line = f"[{stamp}] {message}"
    print(line)
    try:
        with open(LOG_PATH, "a", encoding="utf-8") as f:
            f.write(line + "\n")
    except OSError:
        pass


def human_size(n: int) -> str:
    size = float(n)
    for unit in ("o", "Ko", "Mo", "Go"):
        if size < 1024:
            return f"{size:.0f} {unit}" if unit == "o" else f"{size:.1f} {unit}"
        size /= 1024
    return f"{size:.1f} To"


# ---------------------------------------------------------------------------
# Config / état
# ---------------------------------------------------------------------------
def load_config() -> dict:
    if not os.path.exists(CONFIG_PATH):
        log(f"Fichier de config introuvable : {CONFIG_PATH}")
        sys.exit(1)
    with open(CONFIG_PATH, "r", encoding="utf-8") as f:
        return json.load(f)


def load_state() -> dict:
    if os.path.exists(STATE_PATH):
        with open(STATE_PATH, "r", encoding="utf-8") as f:
            return json.load(f)
    return {}


def save_state(state: dict):
    with open(STATE_PATH, "w", encoding="utf-8") as f:
        json.dump(state, f, indent=2, ensure_ascii=False)


# ---------------------------------------------------------------------------
# Scan d'un projet : liste des fichiers pertinents + hash de chacun
# ---------------------------------------------------------------------------
def hash_file(path: str) -> str:
    h = hashlib.sha256()
    try:
        with open(path, "rb") as f:
            for chunk in iter(lambda: f.read(65536), b""):
                h.update(chunk)
        return h.hexdigest()
    except OSError:
        return ""


def scan_project(project_path: str):
    """Retourne (liste des fichiers retenus dans l'ordre, dict chemin->hash)."""
    files_to_read = []
    hashes = {}

    for root, dirs, files in os.walk(project_path):
        dirs[:] = sorted(d for d in dirs if d not in IGNORE_DIRS)
        for f in sorted(files):
            ext = os.path.splitext(f)[1].lower()
            if ext in IGNORE_EXTS:
                continue
            full_path = os.path.join(root, f)
            try:
                if os.path.getsize(full_path) > MAX_FILE_SIZE:
                    continue
            except OSError:
                continue
            file_hash = hash_file(full_path)
            if not file_hash:
                continue
            files_to_read.append(full_path)
            hashes[full_path] = file_hash

    return files_to_read, hashes


def project_changed(previous_hashes: dict, current_hashes: dict) -> bool:
    """True si un fichier a été ajouté, supprimé ou modifié depuis le dernier scan."""
    if previous_hashes.keys() != current_hashes.keys():
        return True
    for path, h in current_hashes.items():
        if previous_hashes.get(path) != h:
            return True
    return False


# ---------------------------------------------------------------------------
# Génération du bundle, au même format que blinder.py
# ---------------------------------------------------------------------------
def generate_bundle_text(project_name: str, project_path: str, files_to_read: list) -> str:
    lines = []
    lines.append("=========================================\n")
    lines.append("STRUCTURE DES ÉLÉMENTS SÉLECTIONNÉS\n")
    lines.append("=========================================\n\n")
    lines.append(f"[DOSSIER] {project_path}\n")
    for full_path in files_to_read:
        rel = os.path.relpath(full_path, project_path)
        lines.append(f"  ├── {rel}\n")

    lines.append("\n\n=========================================\n")
    lines.append("CONTENU COMPLET DES FICHIERS\n")
    lines.append("=========================================\n\n")

    for file_path in files_to_read:
        lines.append(f"--- DEBUT FICHIER: {file_path} ---\n")
        try:
            with open(file_path, "r", encoding="utf-8", errors="replace") as f:
                lines.append(f.read())
        except Exception as e:
            lines.append(f"[Erreur de lecture: {e}]\n")
        lines.append(f"\n--- FIN FICHIER: {file_path} ---\n\n")

    return "".join(lines)


# ---------------------------------------------------------------------------
# Git : rotation des versions + commit/push
# ---------------------------------------------------------------------------
def run_git(repo_path: str, args: list, check=True):
    result = subprocess.run(
        ["git"] + args, cwd=repo_path,
        capture_output=True, text=True
    )
    if check and result.returncode != 0:
        log(f"Erreur git {args} : {result.stderr.strip()}")
    return result


def ensure_repo(repo_path: str, remote_url: str):
    if not os.path.exists(os.path.join(repo_path, ".git")):
        os.makedirs(repo_path, exist_ok=True)
        log(f"Dépôt absent, clonage de {remote_url} dans {repo_path}")
        result = subprocess.run(
            ["git", "clone", remote_url, repo_path],
            capture_output=True, text=True
        )
        if result.returncode != 0:
            log(f"Échec du clonage : {result.stderr.strip()}")
            sys.exit(1)
    else:
        run_git(repo_path, ["pull", "--rebase"])


def rotate_and_write(repo_path: str, project_name: str, bundle_text: str):
    """Écrit la nouvelle version horodatée et supprime les plus anciennes
    au-delà de VERSIONS_TO_KEEP pour ce projet."""
    project_dir = os.path.join(repo_path, project_name)
    os.makedirs(project_dir, exist_ok=True)

    stamp = datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
    new_file = os.path.join(project_dir, f"{project_name}_{stamp}.txt")
    with open(new_file, "w", encoding="utf-8") as f:
        f.write(bundle_text)

    existing = sorted(
        [f for f in os.listdir(project_dir) if f.startswith(project_name + "_") and f.endswith(".txt")]
    )
    while len(existing) > VERSIONS_TO_KEEP:
        oldest = existing.pop(0)
        try:
            os.remove(os.path.join(project_dir, oldest))
            log(f"Ancienne version supprimée : {oldest}")
        except OSError:
            pass

    return new_file


def git_commit_and_push(repo_path: str, project_name: str):
    run_git(repo_path, ["add", "."])
    result = run_git(repo_path, ["diff", "--cached", "--quiet"], check=False)
    if result.returncode == 0:
        log(f"[{project_name}] Rien à committer.")
        return
    msg = f"Mise à jour contexte {project_name} - {datetime.now().strftime('%Y-%m-%d %H:%M')}"
    run_git(repo_path, ["commit", "-m", msg])
    push_result = run_git(repo_path, ["push"], check=False)
    if push_result.returncode != 0:
        log(f"Échec du push, on retente après un pull --rebase : {push_result.stderr.strip()}")
        run_git(repo_path, ["pull", "--rebase"])
        run_git(repo_path, ["push"])
    log(f"[{project_name}] Poussé sur Git.")


# ---------------------------------------------------------------------------
# Boucle principale
# ---------------------------------------------------------------------------
def sync_once(config: dict):
    state = load_state()
    repo_path = config["repo_local_path"]
    remote_url = config["repo_remote_url"]

    ensure_repo(repo_path, remote_url)

    any_change = False

    for project in config["projects"]:
        name = project["name"]
        path = project["path"]

        if not os.path.isdir(path):
            log(f"[{name}] Dossier introuvable, ignoré : {path}")
            continue

        files_to_read, current_hashes = scan_project(path)
        previous_hashes = state.get(name, {})

        if not project_changed(previous_hashes, current_hashes):
            log(f"[{name}] Aucun changement détecté.")
            continue

        log(f"[{name}] Changement détecté ({len(files_to_read)} fichier(s)), régénération du contexte...")
        bundle_text = generate_bundle_text(name, path, files_to_read)
        out_file = rotate_and_write(repo_path, name, bundle_text)
        log(f"[{name}] Fichier généré : {out_file} ({human_size(os.path.getsize(out_file))})")

        state[name] = current_hashes
        any_change = True

    if any_change:
        # Un seul commit/push groupé pour tous les projets modifiés dans ce passage
        run_git(repo_path, ["add", "."])
        result = run_git(repo_path, ["diff", "--cached", "--quiet"], check=False)
        if result.returncode != 0:
            msg = f"Mise à jour contexte - {datetime.now().strftime('%Y-%m-%d %H:%M')}"
            run_git(repo_path, ["commit", "-m", msg])
            push_result = run_git(repo_path, ["push"], check=False)
            if push_result.returncode != 0:
                log("Échec du push, tentative de pull --rebase puis nouveau push...")
                run_git(repo_path, ["pull", "--rebase"])
                run_git(repo_path, ["push"])
            log("Poussé sur Git.")
        save_state(state)
    else:
        log("Aucun projet modifié, rien à pousser.")


def watch_mode(config: dict, interval_seconds: int):
    log(f"Mode surveillance actif (vérification toutes les {interval_seconds} s). Ctrl+C pour arrêter.")
    while True:
        try:
            sync_once(config)
        except Exception as e:
            log(f"Erreur pendant la synchronisation : {e}")
        time.sleep(interval_seconds)


def main():
    parser = argparse.ArgumentParser(description="Synchronisation automatique de contexte de projets vers Git")
    parser.add_argument("--watch", action="store_true", help="Reste actif et vérifie périodiquement au lieu de faire une seule passe")
    parser.add_argument("--interval", type=int, default=300, help="Intervalle en secondes en mode --watch (défaut : 300)")
    args = parser.parse_args()

    config = load_config()

    if args.watch:
        watch_mode(config, args.interval)
    else:
        sync_once(config)


if __name__ == "__main__":
    main()
