# Tunnel Manager

Un seul fichier à lancer, une seule URL à ouvrir sur ton téléphone. Pas de terminal à toucher côté mobile.

## Mise en route (une seule fois)

1. Dézippe le dossier où tu veux sur ton PC.
2. Installe `cloudflared` (le programme de tunnel de Cloudflare) et vérifie que la commande `cloudflared --version` fonctionne dans un terminal. Aucun compte, aucun domaine ni aucune configuration Cloudflare n'est nécessaire : le programme utilise un « tunnel rapide » gratuit.

**Important :** l'adresse publique (du type `https://xxxx-xxxx.trycloudflare.com`) est **différente à chaque démarrage**. Elle s'affiche dans le terminal du PC et s'écrit dans le fichier `tunnel-url.txt`.

Pour la recevoir sur ton téléphone sans retourner devant le PC, tu peux activer une notification (optionnel) dans `tunnels.config.json` :

```json
"notify": { "ntfyTopic": "un-nom-long-et-impossible-a-deviner-123" }
```

Installe l'app gratuite **ntfy** sur ton téléphone et abonne-toi à ce même nom de topic : à chaque démarrage, tu reçois l'URL en notification et un toucher l'ouvre. Laisse vide pour désactiver. Choisis un nom long et secret : quiconque le connaît peut lire tes notifications (il lui faudrait quand même la clé d'accès pour entrer).

## Démarrer

**Windows :** double-clique sur `start.bat`
**Linux/Mac :** `./start.sh`

Ce fichier fait tout, à chaque fois : il installe automatiquement ce qui manque la première fois, lance Cloudflare, et démarre l'interface. Laisse la fenêtre ouverte tant que tu veux garder tes tunnels actifs.

## Clé d'accès (important, à lire)

Toute l'interface — gestion des tunnels **et** explorateur de fichiers — est maintenant protégée par une clé.

- Au tout premier lancement, le programme génère une clé aléatoire et l'affiche dans le terminal, en plus de l'écrire dans un fichier `access.key` créé à côté d'`index.js`.
- La première fois que tu ouvres l'URL sur ton téléphone, un écran de verrouillage te la demande. Une fois entrée, elle reste enregistrée sur ce téléphone (dans le navigateur) — tu n'as plus à la retaper.
- **Ne partage jamais** le lien du tunnel et la clé dans le même message ou au même endroit : si les deux fuitent ensemble, n'importe qui peut accéder à ton PC.
- Ne commite jamais `access.key` sur un dépôt public, et ne l'envoie à personne.
- Si tu veux forcer une nouvelle clé (par exemple si tu penses qu'elle a fuité), supprime le fichier `access.key` et relance le programme : une nouvelle sera générée. Il faudra alors la ressaisir sur tous tes appareils.

## Depuis ton téléphone

Ouvre l'adresse `trycloudflare.com` affichée au démarrage (ou reçue en notification) dans un navigateur et entre la clé. Comme l'adresse change à chaque démarrage du programme, le navigateur la considère comme un nouveau site : tu devras donc **ressaisir la clé à chaque nouvelle adresse**.

### Onglet Écran (nouveau)

Voir et piloter l'écran du PC depuis le téléphone : clics, défilement, clavier, raccourcis. Utile quand une conversation s'arrête et qu'il faut la relancer dans le navigateur du PC, quelle que soit son adresse.

- **Windows uniquement.** Le programme lance `screen-helper.ps1` (PowerShell) pour capturer l'écran et envoyer souris/clavier. Ne sépare pas ce fichier de `index.js`.
- **Le PC doit rester allumé et déverrouillé.** Quand Windows est verrouillé (Win+L) ou qu'une fenêtre d'administrateur (UAC) est affichée, la capture est impossible.
- **Gestes** : toucher = clic gauche, appui long = clic droit. Trois modes en bas :
  - **Vue** : pince avec deux doigts pour zoomer / dézoomer (le zoom suit tes doigts, de la vue d'ensemble jusqu'à ×5), glisse à un doigt pour déplacer la vue (avec un petit élan au lâcher). Les boutons − / + restent disponibles. Un simple toucher clique toujours.
  - **Défiler** : glisser = molette de la souris
  - **Glisser** : glisser = cliquer-déplacer (sélectionner du texte, déplacer une fenêtre)
- **⌨ Clavier** : touche le champ et écris, le texte part directement vers le PC (accents compris). **Touches** ouvre un petit panneau qui flotte par-dessus l'écran (il ne le rétrécit pas), avec 5 onglets : Flèches (croix + Début/Fin/Pg ↑/Pg ↓), Vidéo (F plein écran, M muet, Espace/K pause, J/L ±10 s), Web (F11, F5, Ctrl+L/F/T/W, retour/avant), Édition (Échap, Tab, copier/coller…) et Fenêtres (⊞ Windows, Alt+Tab, Win+Tab, Bureau). Le bouton **⊞ Windows** envoie la touche Windows une seule fois (le **Win** du haut, lui, est la version collante pour les raccourcis). **Ctrl, Win, Alt, Maj** (premiers boutons de la liste) : touches « collantes » pour les raccourcis. 1 appui = la prochaine touche part avec le modificateur (ex. **Win** puis → pour envoyer la fenêtre à droite, **Ctrl** puis → pour réorganiser), 2 appuis = il reste maintenu pour enchaîner (affiché « Win ∞ »), 3 appuis = relâché. On peut en combiner plusieurs (ex. Ctrl + Maj + →). Marche aussi avec une lettre tapée dans le champ clavier. Le bouton **Démarrer** envoie la touche Win seule. Attention : Ctrl+V colle le presse-papiers **du PC**, pas celui du téléphone. Pour envoyer du texte copié sur le téléphone, colle-le dans le champ clavier.
- **Paysage / plein écran** : à zoom 1 l'écran du PC prend toute la largeur du téléphone (on défile en hauteur, et en zoomant on se déplace dans tous les sens). Pince vers l'intérieur pour la vue d'ensemble. Les commandes (fermer, état de la connexion, ⛶, ☰ et le dock des gestes/clavier en bas) flottent par-dessus l'écran du PC, en verre translucide : l'écran reste toujours visible derrière, et elles s'estompent après quelques secondes sans y toucher (toucher une commande les réveille, toucher l'écran du PC les efface). Le bouton **⛶** (en haut à droite) masque tout et passe en plein écran : le téléphone devient l'écran ; seul le petit bouton rond ☰ reste.
- **Plusieurs écrans** : un menu apparaît en haut (ta tablette en écran secondaire compte comme un écran).
- **🔒** : passe en lecture seule (plus aucun clic ni frappe envoyé) pour déplacer la vue sans risque.

**Attention à la data.** Cloudflare n'impose pas le plafond de 1 Go par mois de l'ancien plan Ngrok, mais un flux d'écran constant reste lourd et un tunnel rapide est prévu pour des usages légers. Bonnes pratiques :

- Une image identique à la précédente n'est jamais renvoyée : un écran immobile ne consomme presque rien.
- Le menu de qualité (dans le menu ☰) propose **Éco** (le plus léger), **Normal** et **Net**. Reste en Éco quand tu n'as pas besoin de netteté.
- Le programme compte les données envoyées par l'écran dans `screen-usage.json`. Par défaut la limite est désactivée (`monthlyBudgetMB: 0`) ; mets par exemple `3000` si tu veux un garde-fou mensuel.

Réglages dans `tunnels.config.json` :

```json
"screen": { "enabled": true, "viewOnly": false, "monthlyBudgetMB": 0 }
```

- `enabled: false` désactive complètement la fonction.
- `viewOnly: true` interdit tout contrôle côté serveur : tu vois l'écran, c'est tout.
- `monthlyBudgetMB: 0` supprime la limite.

**Sécurité.** Avec cet onglet, quiconque a l'URL **et** la clé contrôle ton PC. Ne partage jamais les deux. Si tu penses que la clé a fuité, supprime `access.key` et relance.

const express = require('express');
const multer = require('multer');
const { spawn, exec } = require('child_process');
const fs = require('fs');
const path = require('path');
const crypto = require('crypto');
const os = require('os');
const { WebSocketServer } = require('ws');
const { URL } = require('url');

const CONFIG_PATH = path.join(__dirname, 'tunnels.config.json');
const config = JSON.parse(fs.readFileSync(CONFIG_PATH, 'utf8'));
const STATUS_PORT = config.statusServerPort || 4041; // port interne du Tunnel Manager

let tunnels = {};      // { id: { id, name, port, url, error, handle } }
let ngrokPublicUrl = null;
let ngrokError = null;
let runningFiles = {}; // { [filePath]: { pid, startedAt } } — fichiers lancés depuis l'explorateur, encore ouverts

function log(...args) {
  console.log(new Date().toLocaleTimeString(), '-', ...args);
}

// ---------- Clé d'accès ----------
// Générée une seule fois au premier lancement, stockée dans access.key.
// Le téléphone doit la fournir (header x-access-key) pour toute requête /api/*.

const KEY_PATH = path.join(__dirname, 'access.key');

function loadOrCreateAccessKey() {
  if (fs.existsSync(KEY_PATH)) return fs.readFileSync(KEY_PATH, 'utf8').trim();
  const key = crypto.randomBytes(24).toString('hex');
  fs.writeFileSync(KEY_PATH, key, 'utf8');
  return key;
}

const ACCESS_KEY = loadOrCreateAccessKey();

log('========================================================');
log(" Cle d'acces (a entrer UNE SEULE FOIS sur ton telephone) :");
log(' ' + ACCESS_KEY);
log(' (egalement dans le fichier access.key, a ne jamais partager)');
log('========================================================');

function checkKey(req, res, next) {
  const provided = String(req.headers['x-access-key'] || '');
  const a = Buffer.from(provided);
  const b = Buffer.from(ACCESS_KEY);
  const valid = a.length === b.length && crypto.timingSafeEqual(a, b);
  if (!valid) return res.status(401).json({ error: 'cle invalide' });
  next();
}

// Même vérification, mais lue dans l'URL plutôt que dans un header.
// Nécessaire pour les cas où le navigateur ne peut pas ajouter de header
// personnalisé : un lien de téléchargement direct, et la connexion WebSocket
// du terminal (l'API WebSocket du navigateur ne permet pas de header non plus).
function isValidKey(provided) {
  const a = Buffer.from(String(provided || ''));
  const b = Buffer.from(ACCESS_KEY);
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}

function checkKeyQuery(req, res, next) {
  if (!isValidKey(req.query.key)) return res.status(401).send('Clé invalide');
  next();
}

// ---------- Cloudflare (tunnel rapide, gratuit, sans compte ni domaine) ----------
// NB : les variables ngrokPublicUrl / ngrokError gardent leur ancien nom pour ne rien
// changer côté interface ; elles contiennent maintenant l'URL trycloudflare.com.

const URL_FILE = path.join(__dirname, 'tunnel-url.txt');
let cfProcess = null;
let cfStopping = false;

function announceUrl(url) {
  log('==================================================');
  log(' URL PUBLIQUE : ' + url);
  log('==================================================');
  try { fs.writeFileSync(URL_FILE, url + '\n'); } catch (e) {}

  // Optionnel : notification sur le téléphone via ntfy.sh (config.notify.ntfyTopic).
  // Désactivé par défaut. Choisis un nom de topic long et impossible à deviner.
  const topic = config.notify && config.notify.ntfyTopic;
  if (topic) {
    fetch('https://ntfy.sh/' + encodeURIComponent(topic), {
      method: 'POST',
      body: url,
      headers: { Title: 'Tunnel Manager - nouvelle URL', Click: url },
    }).catch((err) => log('Notification ntfy impossible :', err.message));
  }
}

function startCloudflare() {
  cfStopping = false;
  log('Lancement de Cloudflare...');
  cfProcess = spawn(
    'cloudflared',
    ['tunnel', '--no-autoupdate', '--url', `http://127.0.0.1:${STATUS_PORT}`],
    { shell: process.platform === 'win32' }
  );

  // cloudflared écrit l'URL publique dans ses logs (sur stderr).
  const onData = (d) => {
    const text = String(d);
    // Plusieurs lignes peuvent arriver d'un coup : on les parcourt toutes et on ignore
    // "api.trycloudflare.com" (adresse interne de Cloudflare, pas notre tunnel).
    for (const m of text.matchAll(/https:\/\/([a-z0-9-]+)\.trycloudflare\.com/g)) {
      if (m[1] === 'api') continue;
      if (m[0] !== ngrokPublicUrl) {
        ngrokPublicUrl = m[0];
        ngrokError = null;
        announceUrl(ngrokPublicUrl);
      }
      break;
    }
    if (/ERR|error/i.test(text)) process.stderr.write(`[cloudflared] ${text}`);
  };
  cfProcess.stdout.on('data', onData);
  cfProcess.stderr.on('data', onData);

  cfProcess.on('error', (err) => {
    ngrokError = `cloudflared introuvable (${err.message}). Vérifie qu'il est installé : tape "cloudflared --version" dans un terminal.`;
    log('ERREUR:', ngrokError);
  });

  cfProcess.on('exit', (code) => {
    if (cfStopping) return;
    log(`Cloudflare s'est arrêté (code ${code}), relance dans 5s... (l'URL va changer)`);
    ngrokPublicUrl = null;
    setTimeout(startCloudflare, 5000);
  });
}

function stopCloudflare() {
  cfStopping = true;
  if (!cfProcess || !cfProcess.pid) return;
  try {
    if (process.platform === 'win32') {
      require('child_process').execSync(`taskkill /pid ${cfProcess.pid} /T /F`, { stdio: 'ignore' });
    } else {
      cfProcess.kill();
    }
  } catch (e) {}
}
process.on('exit', stopCloudflare);
process.on('SIGINT', () => process.exit(0));
process.on('SIGTERM', () => process.exit(0));

// ---------- Local Tunnel ----------

function nextId() {
  return Date.now().toString(36) + Math.random().toString(36).slice(2, 6);
}

async function startTunnel({ id, name, port, https }) {
  tunnels[id] = { id, name, port, https: !!https, url: null, error: null, handle: null };

  try {
    const options = { port };
    if (https) {
      options.local_https = true;
      options.allow_invalid_cert = true; // accepte les certificats auto-signés (courant en local)
    }
    const handle = await localtunnel(options);
    if (!tunnels[id]) { handle.close(); return; } // retiré entre-temps
    tunnels[id].handle = handle;
    tunnels[id].url = handle.url;
    tunnels[id].error = null;
    log(`[${name}] actif :`, handle.url);

    handle.on('close', () => {
      if (!tunnels[id]) return;
      log(`[${name}] fermé, relance dans 5s...`);
      tunnels[id].url = null;
      tunnels[id].error = 'reconnexion...';
      setTimeout(() => { if (tunnels[id]) startTunnel(tunnels[id]); }, 5000);
    });
    handle.on('error', (err) => { if (tunnels[id]) tunnels[id].error = err.message; });
  } catch (err) {
    if (!tunnels[id]) return;
    tunnels[id].error = err.message;
    log(`[${name}] échec :`, err.message, '- nouvelle tentative dans 10s');
    setTimeout(() => { if (tunnels[id]) startTunnel(tunnels[id]); }, 10000);
  }
}

function stopTunnel(id) {
  const t = tunnels[id];
  if (!t) return;
  if (t.handle) { try { t.handle.close(); } catch (e) {} }
  delete tunnels[id];
}

// ---------- Explorateur de fichiers ----------
// Limité aux dossiers listés dans tunnels.config.json -> fileBrowser.roots
// (par défaut : ton dossier utilisateur). Impossible de sortir de ces dossiers.

const fbConfig = config.fileBrowser || {};
const FB_ENABLED = fbConfig.enabled !== false;
const FB_ALL_DRIVES = !!(fbConfig.roots && fbConfig.roots.includes('*'));

// Détecte les lettres de lecteur actives sur Windows (C:, D:, clé USB E:, etc.).
// Rejoué à chaque requête (pas mis en cache) pour qu'une clé USB branchée après
// le lancement du programme apparaisse sans avoir à relancer.
function detectWindowsDrives() {
  const drives = [];
  for (let i = 65; i <= 90; i++) {
    const drivePath = `${String.fromCharCode(i)}:\\`;
    try { if (fs.existsSync(drivePath)) drives.push(drivePath); } catch (e) {}
  }
  return drives;
}

// Calcule la liste des racines autorisées. Si tunnels.config.json contient
// "*" dans fileBrowser.roots, on est en mode "tout l'ordinateur" : tous les
// disques (dont les périphériques amovibles) sur Windows, ou "/" ailleurs.
// Sinon, comportement inchangé : les dossiers listés, ou le dossier utilisateur par défaut.
function getRoots() {
  if (FB_ALL_DRIVES) {
    if (process.platform === 'win32') return detectWindowsDrives().map((p) => path.resolve(p));
    return ['/'];
  }
  return (fbConfig.roots && fbConfig.roots.length ? fbConfig.roots : [os.homedir()])
    .map((p) => path.resolve(p))
    .filter((p) => {
      try { return fs.statSync(p).isDirectory(); } catch (e) { log('ATTENTION dossier racine introuvable ignoré :', p); return false; }
    });
}

function isPathAllowed(target) {
  const resolved = path.resolve(target);
  return getRoots().some((root) => {
    // Une racine "disque" comme "C:\" se termine déjà par un séparateur ;
    // on la normalise pour ne pas doubler le séparateur dans la comparaison.
    const normRoot = root.endsWith(path.sep) ? root.slice(0, -1) : root;
    return resolved === root || resolved === normRoot || resolved.startsWith(normRoot + path.sep);
  });
}

// ---------- Import depuis le téléphone ----------
// Un fichier envoyé seul n'a qu'un nom ("photo.jpg"). Un import de dossier
// entier envoie chaque fichier avec un chemin relatif dans son "originalname"
// ("mon-dossier/sous-dossier/fichier.txt"), reconstitué ici pour recréer la
// même arborescence côté PC.
const upload = multer({
  storage: multer.diskStorage({
    destination: (req, file, cb) => {
      try {
        const targetDir = req.body && req.body.targetDir;
        if (!targetDir || !isPathAllowed(targetDir)) return cb(new Error('Dossier cible non autorisé'));
        const relParts = file.originalname.split(/[\\/]/).filter((p) => p && p !== '.' && p !== '..');
        const destDir = relParts.length > 1 ? path.join(targetDir, ...relParts.slice(0, -1)) : targetDir;
        if (!isPathAllowed(destDir)) return cb(new Error('Chemin non autorisé'));
        fs.mkdirSync(destDir, { recursive: true });
        cb(null, destDir);
      } catch (err) { cb(err); }
    },
    filename: (req, file, cb) => {
      const relParts = file.originalname.split(/[\\/]/).filter((p) => p && p !== '.' && p !== '..');
      cb(null, relParts.length ? relParts[relParts.length - 1] : file.originalname);
    },
  }),
  limits: { fileSize: 2 * 1024 * 1024 * 1024 }, // 2 Go par fichier, ajustable si besoin
});

function listRootsEntries() {
  return getRoots().map((root) => ({ name: root, path: root, type: 'dir', size: 0, mtime: 0 }));
}

function listDir(dirPath) {
  const entries = fs.readdirSync(dirPath, { withFileTypes: true });
  const result = [];
  for (const entry of entries) {
    if (entry.name.startsWith('.')) continue; // fichiers/dossiers cachés ignorés
    const full = path.join(dirPath, entry.name);
    let stat;
    try { stat = fs.statSync(full); } catch (e) { continue; } // lien cassé, permission refusée...
    result.push({
      name: entry.name,
      path: full,
      type: entry.isDirectory() ? 'dir' : 'file',
      size: stat.size,
      mtime: stat.mtimeMs,
      running: !entry.isDirectory() && !!runningFiles[full],
    });
  }
  result.sort((a, b) => (a.type === b.type ? a.name.localeCompare(b.name) : a.type === 'dir' ? -1 : 1));
  return result;
}

// Taille max d'un fichier qu'on accepte de charger dans l'éditeur mobile.
// Au-delà, on refuse : éditer un gros fichier texte depuis un téléphone n'a pas de sens.
const MAX_EDIT_SIZE = 2 * 1024 * 1024; // 2 Mo

// Lance le fichier avec son programme associé et, quand c'est possible, retient
// le PID du programme lancé pour pouvoir savoir plus tard s'il tourne encore
// et le fermer à la demande. Retourne une Promise<boolean> : true si le
// témoin "fichier ouvert" pourra être suivi, false si on ne peut pas le suivre
// (le fichier est quand même bien lancé dans ce cas).
function launchFile(filePath) {
  return new Promise((resolve) => {
    if (process.platform === 'win32') {
      // Start-Process -PassThru (contrairement à "start") renvoie le PID du
      // programme réellement ouvert, pas celui de cmd.exe qui se termine aussitôt.
      const escaped = filePath.replace(/'/g, "''");
      const ps = spawn('powershell.exe', [
        '-NoProfile', '-NonInteractive', '-Command',
        `$p = Start-Process -FilePath '${escaped}' -PassThru; Write-Output $p.Id`
      ], { windowsHide: true });
      let out = '';
      ps.stdout.on('data', (d) => { out += d.toString(); });
      ps.on('close', () => {
        const pid = parseInt(out.trim(), 10);
        if (Number.isFinite(pid)) runningFiles[filePath] = { pid, startedAt: Date.now() };
        resolve(Number.isFinite(pid));
      });
      ps.on('error', () => resolve(false));
    } else {
      const opener = process.platform === 'darwin' ? 'open' : 'xdg-open';
      const child = spawn(opener, [filePath], { detached: true, stdio: 'ignore' });
      child.unref();
      // Sur Mac/Linux, ce PID est celui de l'ouvreur, pas toujours celui de
      // l'application elle-même : le témoin peut donc s'éteindre un peu avant
      // ou après la fermeture réelle selon le programme. Limite du système,
      // pas du programme.
      if (child.pid) runningFiles[filePath] = { pid: child.pid, startedAt: Date.now() };
      resolve(!!child.pid);
    }
  });
}

function isPidAlive(pid, cb) {
  if (process.platform === 'win32') {
    exec(`tasklist /FI "PID eq ${pid}" /FO CSV /NH`, { windowsHide: true }, (err, stdout) => {
      cb(!err && !!stdout && stdout.toLowerCase().includes(String(pid)));
    });
  } else {
    let alive = true;
    try { process.kill(pid, 0); } catch (e) { alive = false; }
    cb(alive);
  }
}

// Ferme le programme associé à un fichier lancé depuis l'explorateur.
// Retourne true si un processus suivi a bien été trouvé (et une tentative de
// fermeture envoyée), false si ce fichier n'était pas suivi comme ouvert.
function stopRunningFile(filePath) {
  const entry = runningFiles[filePath];
  if (!entry) return false;
  if (process.platform === 'win32') {
    exec(`taskkill /PID ${entry.pid} /T /F`, { windowsHide: true }, () => {});
  } else {
    try { process.kill(entry.pid, 'SIGTERM'); } catch (e) {}
  }
  delete runningFiles[filePath];
  return true;
}

// Vérifie périodiquement quels fichiers lancés sont encore ouverts, pour
// éteindre automatiquement le témoin dès que le programme se ferme tout seul.
setInterval(() => {
  for (const filePath of Object.keys(runningFiles)) {
    const pid = runningFiles[filePath].pid;
    isPidAlive(pid, (alive) => { if (!alive) delete runningFiles[filePath]; });
  }
}, 2000);

// ---------- Terminal distant ----------
// Ouvre un vrai shell (cmd.exe sous Windows, bash/sh ailleurs) dans un dossier
// autorisé de l'explorateur, et le pilote via WebSocket depuis le téléphone.
// Ce n'est pas un vrai pseudo-terminal (pas de rendu ANSI avancé), mais
// largement suffisant pour lancer des commandes et lire leur sortie.

function spawnShell(cwd) {
  if (process.platform === 'win32') {
    return spawn('cmd.exe', ['/Q'], { cwd, windowsHide: true });
  }
  const shell = process.env.SHELL || 'bash';
  return spawn(shell, ['-i'], { cwd, env: process.env });
}

function attachTerminal(ws, cwd) {
  let proc;
  try {
    proc = spawnShell(cwd);
  } catch (err) {
    ws.send(`[erreur au démarrage du terminal] ${err.message}\r\n`);
    ws.close();
    return;
  }

  const onData = (d) => { if (ws.readyState === ws.OPEN) ws.send(d.toString('utf8')); };
  proc.stdout.on('data', onData);
  proc.stderr.on('data', onData);
  proc.on('error', (err) => onData(Buffer.from(`[erreur] ${err.message}\r\n`)));
  proc.on('exit', (code) => {
    if (ws.readyState === ws.OPEN) { ws.send(`\r\n[session terminée, code ${code}]\r\n`); ws.close(); }
  });

  ws.on('message', (msg) => {
    try { proc.stdin.write(msg.toString()); } catch (e) {}
  });
  ws.on('close', () => { try { proc.kill(); } catch (e) {} });
}

// ---------- Écran distant ----------
// Un petit programme PowerShell (screen-helper.ps1) capture l'écran du PC et
// injecte souris/clavier. Ici on le pilote et on relaie les images au téléphone
// par WebSocket (/ws/screen). Windows uniquement.
//
// ATTENTION data : l'ancien plan Ngrok gratuit plafonnait à 1 Go/mois. On n'envoie
// donc JAMAIS deux fois la même image, et on compte la consommation (screen-usage.json)
// avec un budget mensuel de sécurité (screen.monthlyBudgetMB, 0 = désactivé).

const screenCfg = config.screen || {};
const SCREEN_HELPER = path.join(__dirname, 'screen-helper.ps1');
const SCREEN_USAGE_PATH = path.join(__dirname, 'screen-usage.json');
const SCREEN_VIEW_ONLY = !!screenCfg.viewOnly;
const SCREEN_BUDGET_BYTES = (screenCfg.monthlyBudgetMB === undefined ? 800 : Number(screenCfg.monthlyBudgetMB)) * 1024 * 1024;

function screenUnavailableReason() {
  if (screenCfg.enabled === false) return 'Désactivé dans tunnels.config.json (screen.enabled)';
  if (process.platform !== 'win32') return 'Disponible uniquement quand le programme tourne sous Windows';
  if (!fs.existsSync(SCREEN_HELPER)) return 'Fichier screen-helper.ps1 introuvable à côté de index.js';
  return null;
}

const monthKey = () => new Date().toISOString().slice(0, 7);
let screenUsage = { month: monthKey(), bytes: 0 };
try {
  const saved = JSON.parse(fs.readFileSync(SCREEN_USAGE_PATH, 'utf8'));
  if (saved && saved.month === monthKey()) screenUsage = saved;
} catch (e) { /* premier lancement */ }

function addScreenUsage(n) {
  if (screenUsage.month !== monthKey()) screenUsage = { month: monthKey(), bytes: 0 };
  screenUsage.bytes += n;
}
function budgetExceeded() {
  return SCREEN_BUDGET_BYTES > 0 && screenUsage.bytes >= SCREEN_BUDGET_BYTES;
}
setInterval(() => { try { fs.writeFileSync(SCREEN_USAGE_PATH, JSON.stringify(screenUsage)); } catch (e) {} }, 30000);
process.on('exit', () => { try { fs.writeFileSync(SCREEN_USAGE_PATH, JSON.stringify(screenUsage)); } catch (e) {} });

// Les commandes passent en JSON, une par ligne, sur l'entrée standard de PowerShell.
// On échappe tout caractère non-ASCII (\uXXXX) : la console Windows n'est pas en UTF-8
// par défaut et les accents seraient sinon abîmés.
function asciiJson(obj) {
  return JSON.stringify(obj).replace(/[\u007f-\uffff]/g, (c) => '\\u' + c.charCodeAt(0).toString(16).padStart(4, '0'));
}

const KEY_NAMES = new Set(['ctrl', 'control', 'shift', 'alt', 'win', 'enter', 'esc', 'escape', 'tab', 'backspace',
  'delete', 'del', 'insert', 'home', 'end', 'pageup', 'pagedown', 'left', 'up', 'right', 'down', 'space',
  'f1', 'f2', 'f3', 'f4', 'f5', 'f6', 'f7', 'f8', 'f9', 'f10', 'f11', 'f12']);
function isValidKeyCombo(k) {
  if (typeof k !== 'string' || k.length > 40) return false;
  return k.toLowerCase().split('+').every((part) => KEY_NAMES.has(part) || /^[a-z0-9]$/.test(part));
}

const clampNum = (v, min, max, fallback) => {
  const n = Number(v);
  return Number.isFinite(n) ? Math.min(max, Math.max(min, n)) : fallback;
};
const BUTTONS = ['left', 'right', 'middle'];

let activeScreenSession = null; // une seule session à la fois (la nouvelle remplace l'ancienne)

function spawnScreenHelper() {
  return spawn('powershell.exe', [
    '-NoProfile', '-NonInteractive', '-ExecutionPolicy', 'Bypass', '-File', SCREEN_HELPER,
  ], { windowsHide: true });
}

function attachScreen(ws) {
  if (activeScreenSession) activeScreenSession.close('Remplacée par une autre connexion');

  const helper = spawnScreenHelper();        // capture d'écran uniquement
  let inputHelper = spawnScreenHelper();     // souris / clavier uniquement : ne reste jamais bloqué derrière une capture
  const settings = { w: 1280, q: 50, fps: 5 };
  let closed = false;
  let pending = false;
  let shotStartedAt = 0;
  let lastFrame = '';
  let timer = null;
  let pingTimer = null;
  let missedPongs = 0;
  ws.on('pong', () => { missedPongs = 0; });

  const sendJson = (obj) => { if (ws.readyState === ws.OPEN) ws.send(JSON.stringify(obj)); };
  const cmd = (obj) => { if (!closed) { try { helper.stdin.write(asciiJson(obj) + '\n'); } catch (e) {} } };
  const cmdIn = (obj) => { if (!closed) { try { inputHelper.stdin.write(asciiJson(obj) + '\n'); } catch (e) {} } };
  // Après une action (touche, clic…) on accélère un instant les captures pour voir le résultat tout de suite
  let boostUntil = 0;
  const boosting = () => Date.now() < boostUntil;
  function boost() {
    boostUntil = Date.now() + 1500;
    if (!pending && !closed) { clearTimeout(timer); timer = setTimeout(requestShot, 60); }
  }

  function close(reason) {
    if (closed) return;
    closed = true;
    clearTimeout(timer);
    clearInterval(pingTimer);
    try { helper.kill(); } catch (e) {}
    try { inputHelper.kill(); } catch (e) {}
    if (reason) sendJson({ t: 'error', message: reason });
    try { ws.close(); } catch (e) {}
    if (activeScreenSession && activeScreenSession.helper === helper) activeScreenSession = null;
  }
  activeScreenSession = { helper, close };

  function requestShot() {
    if (closed || pending) return;
    if (budgetExceeded()) {
      close('Budget data du mois atteint (' + (screenUsage.bytes / 1048576).toFixed(1) + ' Mo). Augmente screen.monthlyBudgetMB (ou mets 0 pour désactiver la limite) dans tunnels.config.json si tu le souhaites.');
      return;
    }
    if (ws.bufferedAmount > 1.5 * 1024 * 1024) { timer = setTimeout(requestShot, 200); return; } // réseau lent : on attend
    pending = true;
    shotStartedAt = Date.now();
    cmd({ c: 'shot', w: settings.w, q: settings.q });
  }
  function scheduleNext(extraMs) {
    const interval = boosting() ? Math.min(1000 / settings.fps, 90) : 1000 / settings.fps;
    const wait = Math.max(0, interval - (Date.now() - shotStartedAt)) + (extraMs || 0);
    clearTimeout(timer);
    timer = setTimeout(requestShot, wait);
  }

  let buf = '';
  helper.stdout.setEncoding('utf8');
  helper.stdout.on('data', (chunk) => {
    buf += chunk;
    let nl;
    while ((nl = buf.indexOf('\n')) >= 0) {
      const line = buf.slice(0, nl).replace(/\r$/, '');
      buf = buf.slice(nl + 1);
      handleHelperLine(line);
    }
  });

  function handleHelperLine(line) {
    if (line.startsWith('R|')) {
      sendJson({ t: 'ready', viewOnly: SCREEN_VIEW_ONLY });
      requestShot();
    } else if (line.startsWith('S|')) {
      try {
        let list = JSON.parse(line.slice(2));
        if (!Array.isArray(list)) list = [list];
        sendJson({ t: 'screens', list });
      } catch (e) {}
    } else if (line.startsWith('F|')) {
      pending = false;
      const frame = line.slice(2);
      if (frame === lastFrame) { scheduleNext(boosting() ? 30 : 250); return; } // écran inchangé : rien à envoyer
      lastFrame = frame;
      const jpeg = Buffer.from(frame, 'base64');
      addScreenUsage(jpeg.length);
      if (ws.readyState === ws.OPEN) ws.send(jpeg);
      scheduleNext(0);
    } else if (line.startsWith('E|')) {
      const [, which, ...rest] = line.split('|');
      const message = rest.join('|');
      log('[écran] erreur', which + ':', message);
      if (which === 'shot') {
        pending = false;
        sendJson({ t: 'error', message: "Capture impossible (écran verrouillé ou fenêtre d'administrateur au premier plan ?) : " + message, soft: true });
        scheduleNext(1500);
      } else {
        sendJson({ t: 'error', message, soft: true });
      }
    }
  }

  helper.stderr.on('data', (d) => log('[écran/ps]', String(d).trim()));
  inputHelper.stdout.setEncoding('utf8');
  inputHelper.stdout.on('data', (chunk) => {
    chunk.split('\n').forEach((l) => {
      l = l.replace(/\r$/, '');
      if (l.startsWith('E|')) { const [, which, ...rest] = l.split('|'); log('[écran/saisie] erreur', which + ':', rest.join('|')); sendJson({ t: 'error', message: rest.join('|'), soft: true }); }
    });
  });
  inputHelper.stderr.on('data', (d) => log('[écran/ps saisie]', String(d).trim()));
  inputHelper.on('error', () => { inputHelper = helper; });
  inputHelper.on('exit', () => { if (!closed) inputHelper = helper; });
  helper.on('error', (err) => close('Impossible de lancer PowerShell : ' + err.message));
  helper.on('exit', (code) => { if (!closed) close('Le programme de capture s\'est arrêté (code ' + code + ')'); });

  ws.on('message', (raw) => {
    let m;
    try { m = JSON.parse(raw.toString()); } catch (e) { return; }
    if (!m || typeof m.t !== 'string') return;

    switch (m.t) {
      case 'cfg':
        settings.w = Math.round(clampNum(m.w, 480, 2560, settings.w));
        settings.q = Math.round(clampNum(m.q, 20, 90, settings.q));
        settings.fps = clampNum(m.fps, 0.5, 10, settings.fps);
        lastFrame = '';
        break;
      case 'screen':
        cmd({ c: 'screen', i: Math.round(clampNum(m.i, 0, 15, 0)) });
        if (inputHelper !== helper) cmdIn({ c: 'screen', i: Math.round(clampNum(m.i, 0, 15, 0)) });
        lastFrame = '';
        break;
      case 'refresh':
        lastFrame = '';
        break;
    }
    if (SCREEN_VIEW_ONLY) return; // mode lecture seule : on ignore tout ce qui touche au PC

    const x = clampNum(m.x, 0, 1, 0), y = clampNum(m.y, 0, 1, 0);
    const b = BUTTONS.includes(m.b) ? m.b : 'left';
    switch (m.t) {
      case 'move': cmdIn({ c: 'move', x, y }); break;
      case 'down': cmdIn({ c: 'down', x, y, b }); break;
      case 'up': cmdIn({ c: 'up', x, y, b }); boost(); break;
      case 'click': cmdIn({ c: 'click', x, y, b }); boost(); break;
      case 'wheel': cmdIn({ c: 'wheel', d: Math.round(clampNum(m.d, -20, 20, 0)) }); boost(); break;
      case 'text':
        if (typeof m.s === 'string' && m.s.length > 0 && m.s.length <= 500) { cmdIn({ c: 'text', s: m.s }); boost(); }
        break;
      case 'key':
        if (isValidKeyCombo(m.k)) { cmdIn({ c: 'key', k: m.k }); boost(); }
        break;
    }
  });
  ws.on('close', () => close());
  ws.on('error', () => close());
  // Toutes les 10 s : ping WebSocket (garde la connexion ouverte quand l'écran ne bouge pas), signal « hb » vers le
  // téléphone (lui permet de détecter une connexion morte), relance d'une capture bloquée et nettoyage d'un client disparu.
  pingTimer = setInterval(() => {
    if (closed) return;
    if (missedPongs >= 4) { try { ws.terminate(); } catch (e) {} return; } // plus de réponse depuis ~40 s : on libère PowerShell
    missedPongs++;
    try { ws.ping(); } catch (e) {}
    sendJson({ t: 'hb' });
    if (pending && Date.now() - shotStartedAt > 10000) { // capture sans réponse : on repart au lieu de rester bloqué
      pending = false;
      requestShot();
    }
  }, 10000);
}

<script>
let currentFbPath = null; // null = racine (liste des dossiers autorisés)

// ---------- Clé / déverrouillage ----------

function getKey() { return localStorage.getItem('tm_key') || ''; }

function authHeaders() {
  return { 'x-access-key': getKey(), 'Content-Type': 'application/json' };
}

async function tryUnlock() {
  const key = document.getElementById('keyInput').value.trim();
  if (!key) return;
  localStorage.setItem('tm_key', key);
  const ok = await checkAuth();
  if (ok) {
    document.getElementById('lockScreen').style.display = 'none';
    document.getElementById('app').style.display = 'block';
    refresh();
  } else {
    document.getElementById('lockError').textContent = 'Clé incorrecte.';
    localStorage.removeItem('tm_key');
  }
}

async function checkAuth() {
  try {
    const res = await fetch('/api/status', { headers: authHeaders() });
    return res.status === 200;
  } catch (e) { return false; }
}

async function boot() {
  if (getKey()) {
    const ok = await checkAuth();
    if (ok) {
      document.getElementById('lockScreen').style.display = 'none';
      document.getElementById('app').style.display = 'block';
      refresh();
      return;
    }
  }
  document.getElementById('lockScreen').style.display = 'flex';
}

// ---------- Alimentation du PC ----------

var PWR = {
  'app':         { title: 'Couper le tunnel ?', go: 'Couper', pc: false,
                   text: 'Les tunnels seront coupés et tu ne pourras plus y accéder tant que le programme n’est pas relancé sur le PC.' },
  'restart-app': { title: 'Redémarrer le tunnel ?', go: 'Redémarrer', pc: false,
                   text: 'Les tunnels seront coupés quelques secondes et l’adresse publique va changer.' },
  'shutdown':    { title: 'Éteindre le PC ?', go: 'Éteindre', pc: true,
                   text: 'Un délai de 10 s te laisse le temps d’annuler. Ensuite, tu ne pourras plus le rallumer à distance.' },
  'restart':     { title: 'Redémarrer le PC ?', go: 'Redémarrer', pc: true,
                   text: 'Windows risque de demander ton mot de passe au démarrage : tu ne pourras pas le saisir à distance.' }
};
var pwrAction = null, pwrBusy = false, pwrTimer = null;

function pwrShow(name) {
  ['pwrChoices', 'pwrConfirm', 'pwrStatus'].forEach(function (id) {
    document.getElementById(id).classList.toggle('on', id === name);
  });
}

function togglePower(force) {
  var menu = document.getElementById('pwrMenu');
  var open = typeof force === 'boolean' ? force : !menu.classList.contains('open');
  menu.classList.toggle('open', open);
  document.getElementById('pwrBtn').classList.toggle('open', open);
  if (open) pwrShow(pwrBusy ? 'pwrStatus' : 'pwrChoices');
}

// Toucher en dehors du menu le referme
document.addEventListener('click', function (e) {
  var menu = document.getElementById('pwrMenu');
  if (!menu || !menu.classList.contains('open')) return;
  if (menu.contains(e.target) || document.getElementById('pwrBtn').contains(e.target)) return;
  togglePower(false);
});

// Étape 1 : on choisit une action -> écran de confirmation dans le menu
function powerAsk(action) {
  var p = PWR[action];
  if (!p) return;
  pwrAction = action;
  document.getElementById('pwrConfirm').classList.toggle('pc', p.pc);
  document.getElementById('pwrCi').innerHTML = document.querySelector('[data-pwr="' + action + '"] .pwr-ico').innerHTML;
  document.getElementById('pwrCt').textContent = p.title;
  document.getElementById('pwrCd').textContent = p.text;
  document.getElementById('pwrGo').textContent = p.go;
  pwrShow('pwrConfirm');
}

function powerBack() {
  pwrAction = null;
  pwrShow('pwrChoices');
}

function pwrStatus(text, isErr, canCancel) {
  var msg = document.getElementById('pwrMsg');
  msg.textContent = text;
  msg.className = 'pwr-msg' + (isErr ? ' err' : '');
  document.getElementById('pwrCancel').style.display = canCancel ? '' : 'none';
  document.getElementById('pwrBack').style.display = pwrBusy ? 'none' : '';
  pwrShow('pwrStatus');
}

// Étape 2 : confirmation -> envoi de la commande
async function powerConfirm() {
  var action = pwrAction;
  if (!action) return;
  pwrStatus('Envoi de la commande...', false, false);
  try {
    var r = await fetch('/api/power', { method: 'POST', headers: authHeaders(), body: JSON.stringify({ action: action }) });
    var d = await r.json().catch(function () { return {}; });
    if (!r.ok) { pwrStatus('Erreur : ' + (d.error || ('HTTP ' + r.status)), true, false); return; }
    if (d.cancellable) {
      pwrBusy = true;
      pwrStatus((action === 'restart' ? 'Redémarrage' : 'Extinction') + ' du PC dans ' + d.delay + ' s. Tu peux encore annuler.', false, true);
      clearTimeout(pwrTimer);
      pwrTimer = setTimeout(function () {
        pwrBusy = false;
        pwrStatus('Commande exécutée : la connexion va se couper.', false, false);
      }, d.delay * 1000);
    } else if (action === 'restart-app') {
      pwrStatus('Redémarrage en cours : recharge la page dans quelques secondes (la nouvelle adresse est dans tunnel-url.txt ou la notification).', false, false);
    } else {
      pwrStatus(action === 'app' ? 'Tunnel coupé. Relance le programme sur le PC pour le remettre en route.' : 'Commande envoyée : la connexion va se couper.', false, false);
    }
  } catch (e) { pwrStatus('Erreur : ' + e.message, true, false); }
}

async function powerCancel() {
  try {
    var r = await fetch('/api/power/cancel', { method: 'POST', headers: authHeaders() });
    var d = await r.json().catch(function () { return {}; });
    if (r.ok) {
      clearTimeout(pwrTimer);
      pwrBusy = false;
      pwrStatus('Annulé : le PC ne sera pas touché.', false, false);
    } else {
      pwrStatus('Erreur : ' + (d.error || ('HTTP ' + r.status)), true, true);
    }
  } catch (e) { pwrStatus('Erreur : ' + e.message, true, true); }
}

async function addTunnel() {
  const name = document.getElementById('inputName').value.trim() || 'Sans nom';
  const port = parseInt(document.getElementById('inputPort').value, 10);
  const https = document.getElementById('inputHttps').checked;
  if (!port || port < 1 || port > 65535) { alert('Entre un port valide (ex : 8000)'); return; }
  await fetch('/api/tunnels', {
    method: 'POST', headers: authHeaders(),
    body: JSON.stringify({ name, port, https })
  });
  closeSheet();
  refresh();
}

async function removeTunnel(id) {
  await fetch('/api/tunnels/' + id, { method: 'DELETE', headers: authHeaders() });
  refresh();
}

function copyUrl(url, btn) {
  navigator.clipboard.writeText(url).then(() => {
    const old = btn.textContent;
    btn.textContent = 'Copié !';
    setTimeout(() => btn.textContent = old, 1200);
  });
}

async function refresh() {
  try {
    const res = await fetch('/api/status', { headers: authHeaders() });
    if (res.status === 401) { logout(); return; }
    const data = await res.json();

    const s = document.getElementById('ngrokStatus');
    if (data.ngrok.url) {
      s.innerHTML = '<span class="dot"></span> Connecté';
    } else if (data.ngrok.error) {
      s.innerHTML = '<span class="dot off"></span> ' + data.ngrok.error;
    } else {
      s.innerHTML = '<span class="dot wait"></span> Connexion en cours...';
    }

    const list = document.getElementById('list');
    if (data.tunnels.length === 0) {
      list.innerHTML = '<div class="empty">Aucun tunnel actif.<br>Appuie sur "+ Nouveau port" pour en créer un.</div>';
      return;
    }
    list.innerHTML = data.tunnels.map(t => \`
      <div class="card">
        <div class="top">
          <div>
            <div class="name">\${t.name}\${t.https ? '<span class="badge-https">HTTPS</span>' : ''}</div>
            <div class="port">Port local \${t.port}</div>
          </div>
        </div>
        \${t.url
          ? \`<a class="url" href="\${t.url}" target="_blank">\${t.url}</a>\`
          : \`<div class="err">\${t.error || 'Démarrage en cours...'}</div>\`
        }
        <div class="actions">
          \${t.url ? \`<button class="btn btn-copy" onclick="copyUrl('\${t.url}', this)">Copier le lien</button>\` : ''}
          <button class="btn btn-remove" onclick="removeTunnel('\${t.id}')">Retirer</button>
        </div>
      </div>
    \`).join('');
  } catch (e) { /* silencieux, on réessaiera */ }
}

function escapeHtml(s) {
  return s.replace(/[&<>"']/g, (c) => ({ '&':'&amp;', '<':'&lt;', '>':'&gt;', '"':'&quot;', "'":'&#39;' }[c]));
}

function handleUploadInputChange(event) {
  const files = event.target.files;
  event.target.value = ''; // permet de re-sélectionner les mêmes fichiers plus tard
  if (files && files.length) uploadFiles(files);
}

function uploadFiles(fileList) {
  if (!currentFbPath) { alert("Ouvre d'abord un dossier avant d'importer."); return; }
  const formData = new FormData();
  formData.append('targetDir', currentFbPath);
  for (const file of fileList) {
    // webkitRelativePath est rempli par le navigateur pour un import de dossier
    // (ex. "mon-dossier/photo.jpg"), vide pour un simple import de fichiers.
    const relPath = file.webkitRelativePath || file.name;
    formData.append('files', file, relPath);
  }

  const fab = document.getElementById('importFab');
  const originalLabel = fab.textContent;
  fab.disabled = true;

  const xhr = new XMLHttpRequest();
  xhr.open('POST', '/api/fb/upload');
  xhr.setRequestHeader('x-access-key', getKey());
  xhr.upload.onprogress = (ev) => {
    if (ev.lengthComputable) fab.textContent = 'Import... ' + Math.round((ev.loaded / ev.total) * 100) + '%';
  };
  xhr.onload = () => {
    fab.disabled = false;
    fab.textContent = originalLabel;
    if (xhr.status === 401) { logout(); return; }
    let data = {};
    try { data = JSON.parse(xhr.responseText); } catch (e) {}
    if (xhr.status >= 400) { alert('Erreur : ' + (data.error || xhr.status)); return; }
    loadFiles(currentFbPath);
  };
  xhr.onerror = () => {
    fab.disabled = false;
    fab.textContent = originalLabel;
    alert("Erreur de connexion pendant l'import.");
  };
  xhr.send(formData);
}

async function loadFiles(dirPath) {
  const fbList = document.getElementById('fbList');
  const fbPathEl = document.getElementById('fbPath');
  const fbBack = document.getElementById('fbBack');
  fbList.innerHTML = '<div class="empty">Chargement...</div>';

  const url = dirPath ? '/api/fb/list?path=' + encodeURIComponent(dirPath) : '/api/fb/list';
  try {
    const res = await fetch(url, { headers: authHeaders() });
    if (res.status === 401) { logout(); return; }
    const data = await res.json();
    if (data.error) { fbList.innerHTML = '<div class="empty">' + escapeHtml(data.error) + '</div>'; return; }

    currentFbPath = data.path;
    fbPathEl.textContent = data.path || 'Dossiers autorisés';
    fbBack.innerHTML = data.parent !== undefined && data.parent !== null
      ? '<button class="btn btn-back" data-path="' + encodeURIComponent(data.parent) + '" onclick="loadFiles(decodeURIComponent(this.dataset.path))">← Retour</button>'
      : (data.path ? '<button class="btn btn-back" onclick="loadFiles(null)">← Retour</button>' : '');

    if (data.entries.length === 0) {
      fbList.innerHTML = '<div class="empty">Dossier vide.</div>';
      return;
    }

    fbList.innerHTML = data.entries.map(e => {
      const encPath = encodeURIComponent(e.path);
      if (e.type === 'dir') {
        return '<div class="file-row dir">' +
          '<div class="left" data-path="' + encPath + '" onclick="loadFiles(decodeURIComponent(this.dataset.path))"><span class="icon">📁</span><span class="name">' + escapeHtml(e.name) + '</span></div>' +
          '<div class="right"><button class="btn btn-sm btn-term" data-path="' + encPath + '" onclick="event.stopPropagation();openTerminal(decodeURIComponent(this.dataset.path))">Terminal</button></div>' +
        '</div>';
      }
      return '<div class="file-row">' +
        '<div class="left"><span class="icon">📄</span><span class="name">' + escapeHtml(e.name) + '</span></div>' +
        '<div class="right">' +
          '<span class="proc-dot' + (e.running ? ' on' : '') + '" data-path="' + encPath + '" ' +
            'title="' + (e.running ? 'Fichier ouvert' : 'Fichier fermé') + '"></span>' +
          '<div class="dropdown">' +
            '<button class="btn btn-sm btn-menu" onclick="event.stopPropagation();toggleMenu(event.currentTarget)">⋮</button>' +
            '<div class="dropdown-menu">' +
              '<button class="dropdown-item" data-path="' + encPath + '" onclick="closeAllMenus();openEditor(decodeURIComponent(this.dataset.path))">Modifier</button>' +
              '<a class="dropdown-item" href="/download?path=' + encPath + '&key=' + encodeURIComponent(getKey()) + '" onclick="closeAllMenus()">Télécharger</a>' +
              '<button class="dropdown-item launch-toggle" data-path="' + encPath + '" onclick="closeAllMenus();handleLaunchToggle(decodeURIComponent(this.dataset.path), this)">' + (e.running ? 'Fermer' : 'Lancer') + '</button>' +
              '<button class="dropdown-item" data-path="' + encPath + '" onclick="closeAllMenus();renameFile(decodeURIComponent(this.dataset.path))">Renommer</button>' +
              '<button class="dropdown-item danger" data-path="' + encPath + '" onclick="closeAllMenus();deleteFile(decodeURIComponent(this.dataset.path))">Supprimer</button>' +
            '</div>' +
          '</div>' +
        '</div>' +
      '</div>';
    }).join('');
  } catch (e) {
    fbList.innerHTML = '<div class="empty">Erreur de chargement.</div>';
  }
}

// Le bouton du menu ⋮ fait office d'interrupteur : "Lancer" si le fichier est
// fermé, "Fermer" s'il est ouvert. L'état réel est lu sur le témoin (la
// loupiote), qui lui n'est que visuel et jamais cliquable.
function handleLaunchToggle(filePath, btn) {
  const dot = document.querySelector('.proc-dot[data-path="' + encodeURIComponent(filePath) + '"]');
  const isRunning = !!(dot && dot.classList.contains('on'));
  if (isRunning) stopFile(filePath, dot, btn);
  else launchFile(filePath, dot, btn);
}

async function launchFile(filePath, dot, btn) {
  if (!confirm('Lancer ce fichier sur ton PC ?\\n' + filePath)) return;
  try {
    const res = await fetch('/api/fb/launch', {
      method: 'POST', headers: authHeaders(),
      body: JSON.stringify({ path: filePath })
    });
    if (res.status === 401) { logout(); return; }
    const data = await res.json();
    if (data.error) { alert('Erreur : ' + data.error); return; }
    setProcState(filePath, true);
  } catch (e) { alert('Erreur de connexion.'); }
}

async function stopFile(filePath, dot, btn) {
  if (!confirm('Fermer ce fichier sur ton PC ?\\n' + filePath)) return;
  try {
    const res = await fetch('/api/fb/stop', {
      method: 'POST', headers: authHeaders(),
      body: JSON.stringify({ path: filePath })
    });
    if (res.status === 401) { logout(); return; }
    setProcState(filePath, false);
  } catch (e) { alert('Erreur de connexion.'); }
}

// Met à jour à la fois la loupiote et le texte du bouton ⋮ > Lancer/Fermer
// pour un chemin donné, sans recharger toute la liste.
function setProcState(filePath, running) {
  const enc = encodeURIComponent(filePath);
  const dot = document.querySelector('.proc-dot[data-path="' + enc + '"]');
  if (dot) {
    dot.classList.toggle('on', running);
    dot.title = running ? 'Fichier ouvert' : 'Fichier fermé';
  }
  document.querySelectorAll('.launch-toggle[data-path="' + enc + '"]').forEach((b) => {
    b.textContent = running ? 'Fermer' : 'Lancer';
  });
}

// Sonde périodiquement quels fichiers sont encore ouverts, pour que la
// loupiote et le bouton ⋮ restent à jour même si le programme se ferme tout
// seul (sans recharger toute la liste, ce qui fermerait les menus ouverts).
async function refreshProcLights() {
  if (!document.getElementById('filesView').classList.contains('active')) return;
  try {
    const res = await fetch('/api/fb/running', { headers: authHeaders() });
    if (res.status !== 200) return;
    const data = await res.json();
    const runningSet = new Set(data.running || []);
    document.querySelectorAll('.proc-dot').forEach((dot) => {
      const p = decodeURIComponent(dot.dataset.path);
      setProcState(p, runningSet.has(p));
    });
  } catch (e) { /* silencieux, on réessaiera */ }
}

let termSocket = null;

function openTerminal(dirPath) {
  document.getElementById('termTitle').textContent = 'Terminal — ' + dirPath;
  document.getElementById('termOutput').textContent = '';
  document.getElementById('termOverlay').classList.add('active');
  document.getElementById('termInput').value = '';

  const proto = location.protocol === 'https:' ? 'wss:' : 'ws:';
  const url = proto + '//' + location.host + '/ws/terminal?key=' + encodeURIComponent(getKey()) + '&cwd=' + encodeURIComponent(dirPath);
  termSocket = new WebSocket(url);

  termAppend('[connexion au terminal...]\\r\\n');
  termSocket.onopen = () => termAppend('[connecté]\\r\\n');
  termSocket.onmessage = (ev) => termAppend(ev.data);
  termSocket.onclose = () => termAppend('\\r\\n[connexion fermée]\\r\\n');
  termSocket.onerror = () => termAppend('\\r\\n[erreur de connexion]\\r\\n');

  document.getElementById('termInput').focus();
}

function termAppend(text) {
  const out = document.getElementById('termOutput');
  out.textContent += text;
  out.scrollTop = out.scrollHeight;
}

function sendTermCommand() {
  const input = document.getElementById('termInput');
  const cmd = input.value;
  if (termSocket && termSocket.readyState === WebSocket.OPEN) {
    termSocket.send(cmd + '\\n');
  }
  input.value = '';
}

document.getElementById('termInput').addEventListener('keydown', (e) => { if (e.key === 'Enter') sendTermCommand(); });

function closeTerminal() {
  document.getElementById('termOverlay').classList.remove('active');
  if (termSocket) { try { termSocket.close(); } catch (e) {} termSocket = null; }
}

// ---------- Alimentation du PC (redémarrer / éteindre) ----------
// Éteindre / redémarrer le PC (Windows : « shutdown » avec un délai de 10 s pour pouvoir annuler),
// ou arrêter / relancer seulement le Tunnel Manager.
// Désactivable : "power": { "enabled": false }.
const POWER_ENABLED = (config.power || {}).enabled !== false;
const POWER_DELAY_S = 10;
let powerPending = null; // { action, at }

app.post('/api/power', (req, res) => {
  if (!POWER_ENABLED) return res.status(403).json({ error: 'Alimentation désactivée dans tunnels.config.json' });
  const action = String((req.body || {}).action || '');
  if (['app', 'restart-app', 'shutdown', 'restart'].indexOf(action) < 0) return res.status(400).json({ error: 'action invalide' });
  if (action === 'app' || action === 'restart-app') {
    // Arrête (ou relance) uniquement Tunnel Manager : tunnels, cloudflared et écran sont coupés ; le PC reste allumé.
    const relaunch = action === 'restart-app';
    log(relaunch ? 'Redemarrage du Tunnel Manager demande depuis le telephone' : 'Arret du Tunnel Manager demande depuis le telephone');
    res.json({ ok: true, delay: 0, cancellable: false, relaunch });
    setTimeout(() => {
      if (relaunch) {
        try {
          // Petit processus détaché : attend 2,5 s que l'ancien libère le port, puis relance index.js en arrière-plan.
          const code = "setTimeout(function(){require('child_process').spawn(process.argv[1],[process.argv[2]],{cwd:process.argv[3],detached:true,stdio:'ignore',windowsHide:true}).unref();},2500);";
          spawn(process.execPath, ['-e', code, process.execPath, __filename, __dirname], { detached: true, stdio: 'ignore', windowsHide: true }).unref();
        } catch (e) { log('Relance impossible : ' + e.message); }
      }
      process.exit(0);
    }, 400);
    return;
  }
  let cmd;
  if (process.platform === 'win32') {
    cmd = `shutdown ${action === 'restart' ? '/r' : '/s'} /t ${POWER_DELAY_S} /c "Tunnel Manager : ${action === 'restart' ? 'redemarrage' : 'arret'} demande depuis le telephone"`;
  } else if (process.platform === 'darwin') {
    cmd = `osascript -e 'tell app "System Events" to ${action === 'restart' ? 'restart' : 'shut down'}'`;
  } else {
    cmd = action === 'restart' ? 'systemctl reboot' : 'systemctl poweroff';
  }
  log(`Alimentation : ${action === 'restart' ? 'redemarrage' : 'arret'} du PC demande depuis le telephone`);
  exec(cmd, { windowsHide: true }, (err, stdout, stderr) => {
    if (err) {
      powerPending = null;
      return res.status(500).json({ error: String(stderr || err.message).trim() || 'commande refusée' });
    }
    powerPending = { action, at: Date.now() };
    res.json({ ok: true, delay: process.platform === 'win32' ? POWER_DELAY_S : 0, cancellable: process.platform === 'win32' });
  });
});

app.post('/api/power/cancel', (req, res) => {
  if (!POWER_ENABLED) return res.status(403).json({ error: 'Alimentation désactivée' });
  if (process.platform !== 'win32') return res.status(400).json({ error: 'Annulation non disponible sur ce système' });
  exec('shutdown /a', { windowsHide: true }, (err, stdout, stderr) => {
    if (err) return res.status(500).json({ error: 'Rien à annuler (ou trop tard)' });
    powerPending = null;
    log('Alimentation : operation annulee');
    res.json({ ok: true });
  });
});

  const target = req.query.path;
  if (!target) {
    return res.json({ path: null, parent: null, entries: listRootsEntries() });
  }
  if (!isPathAllowed(target)) return res.status(403).json({ error: 'Chemin non autorisé' });
  try {
    const stat = fs.statSync(target);
    if (!stat.isDirectory()) return res.status(400).json({ error: "Ce n'est pas un dossier" });
    const isRoot = getRoots().includes(path.resolve(target));
    res.json({
      path: target,
      parent: isRoot ? null : path.dirname(target),
      entries: listDir(target),
    });
  } catch (err) {
    res.status(404).json({ error: err.message });
  }
});

  // Change le zoom en gardant fixe le point de l'image situé sous (mx, my) (coordonnées écran).
  function setScale(ns, mx, my) {
    ns = Math.max(MIN_SCALE, Math.min(MAX_SCALE, ns));
    var v = el.scrView, im = el.scrImg;
    var r = im.getBoundingClientRect();
    if (mx == null) {
      var vr = v.getBoundingClientRect();
      mx = vr.left + vr.width / 2; my = vr.top + vr.height / 2;
    }
    var fx = r.width ? Math.min(1, Math.max(0, (mx - r.left) / r.width)) : 0.5;
    var fy = r.height ? Math.min(1, Math.max(0, (my - r.top) / r.height)) : 0.5;
    scale = ns;
    layoutImg();
    var r2 = im.getBoundingClientRect();
    v.scrollLeft += (r2.left + fx * r2.width) - mx;
    v.scrollTop += (r2.top + fy * r2.height) - my;
  }

  function connect() {
    clearTimeout(reconnectTimer);
    if (ws) { try { ws.onclose = null; ws.onmessage = null; ws.close(); } catch (e) {} }
    gotReady = false;
    setStatus('wait', 'Connexion…');
    var proto = location.protocol === 'https:' ? 'wss:' : 'ws:';
    var sock = new WebSocket(proto + '//' + location.host + '/ws/screen?key=' + encodeURIComponent(getKey()));
    ws = sock;
    sock.binaryType = 'blob';
    sock.onopen = function () { lastMsgAt = Date.now(); sendCfg(); };
    sock.onmessage = onMessage;
    sock.onerror = function () {};
    sock.onclose = function () {
      if (ws !== sock || !wantOpen) return;
      if (document.hidden) { setStatus('off', 'En pause'); return; }
      if (!gotReady) failCount++;
      if (failCount >= 8) {
        wantOpen = false;
        setStatus('off', 'Connexion impossible (clé invalide, écran désactivé ou PC éteint ?)');
        return;
      }
      // Délai croissant : 1 s, 2 s, 4 s… plafonné à 8 s (+ un peu de hasard pour ne pas marteler le serveur)
      var delay = Math.min(8000, 1000 * Math.pow(2, retry)) + Math.round(Math.random() * 400);
      retry = Math.min(retry + 1, 10);
      setStatus('off', 'Déconnecté, reconnexion…');
      reconnectTimer = setTimeout(connect, delay);
    };
  }

  function onMessage(ev) {
    lastMsgAt = Date.now();
    if (typeof ev.data !== 'string') {
      var blob = ev.data;
      sessionBytes += blob.size;
      updateMb();
      var old = curUrl;
      curUrl = URL.createObjectURL(blob);
      el.scrImg.src = curUrl;
      el.scrImg.style.display = 'block';
      el.scrEmpty.style.display = 'none';
      if (old) URL.revokeObjectURL(old);
      return;
    }
    var m;
    try { m = JSON.parse(ev.data); } catch (e) { return; }
    if (m.t === 'ready') {
      gotReady = true; failCount = 0; retry = 0;
      serverViewOnly = !!m.viewOnly;
      updateLockUi();
      setStatus('on', serverViewOnly ? 'Connecté (lecture seule)' : 'Connecté');
    } else if (m.t === 'hb') {
      /* signal de vie du serveur : lastMsgAt est déjà à jour */
    } else if (m.t === 'screens') {
      fillScreens(m.list || []);
    } else if (m.t === 'error') {
      if (m.soft) { setStatus('wait', m.message); }
      else { wantOpen = false; setStatus('off', m.message); el.scrEmpty.style.display = 'flex'; el.scrEmpty.textContent = m.message; }
    }
  }

  // ---------- Souris / doigt ----------
  function frac(e) {
    var r = el.scrImg.getBoundingClientRect();
    return { x: r4((e.clientX - r.left) / Math.max(1, r.width)), y: r4((e.clientY - r.top) / Math.max(1, r.height)) };
  }

  function setupPointer() {
    var v = el.scrView;
    var mouseBtn = null;
    var pts = {};          // doigts posés : id -> { x, y }
    var pinch = null;      // { d0, s0, mx, my } pendant un pincement
    var pan = null;        // { t, vx, vy } pendant un déplacement à un doigt
    var inertia = 0;
    var lastTap = null;    // dernier toucher bref : { t, x, y } (pour « double-toucher puis glisser »)

    function ids() { return Object.keys(pts); }
    function stopInertia() { if (inertia) { cancelAnimationFrame(inertia); inertia = 0; } }
    function startInertia(vx, vy) {
      stopInertia();
      var last = performance.now();
      function step(now) {
        var dt = Math.min(50, now - last); last = now;
        var k = Math.pow(0.94, dt / 16);
        vx *= k; vy *= k;
        if (Math.abs(vx) < 0.02 && Math.abs(vy) < 0.02) { inertia = 0; return; }
        v.scrollLeft -= vx * dt; v.scrollTop -= vy * dt;
        inertia = requestAnimationFrame(step);
      }
      inertia = requestAnimationFrame(step);
    }
    function killTap() { if (tp && !tp.dead) { cancelTouch(); } }

    v.addEventListener('contextmenu', function (e) { e.preventDefault(); });

    v.addEventListener('wheel', function (e) {
      e.preventDefault();
      var n = Math.max(1, Math.round(Math.abs(e.deltaY) / 100));
      send({ t: 'wheel', d: e.deltaY > 0 ? -n : n });
    }, { passive: false });

    v.addEventListener('pointerdown', function (e) {
      if (e.pointerType === 'mouse') {
        if (locked || serverViewOnly) return;
        var f = frac(e);
        mouseBtn = e.button === 2 ? 'right' : e.button === 1 ? 'middle' : 'left';
        send({ t: 'down', x: f.x, y: f.y, b: mouseBtn });
        try { v.setPointerCapture(e.pointerId); } catch (err) {}
        return;
      }
      stopInertia();
      pts[e.pointerId] = { x: e.clientX, y: e.clientY };
      var n = ids().length;
      if (n === 1) {                        // nouveau geste : on repart de zéro
        killTap(); tp = null; pinch = null; pan = null;
      }
      if (isViewLike() || mode === 'mouse') {
        if (n === 2) {                      // deuxième doigt : pincement (zoom + déplacement de la vue)
          killTap();
          tp = { dead: true };
          var a = pts[ids()[0]], b = pts[ids()[1]];
          pinch = { d0: Math.max(10, Math.hypot(a.x - b.x, a.y - b.y)), s0: scale,
                    mx: (a.x + b.x) / 2, my: (a.y + b.y) / 2 };
          pan = null;
          return;
        }
        if (n > 2) return;
      }
      var f0 = frac(e);
      tp = { id: e.pointerId, x0: e.clientX, y0: e.clientY, ly: e.clientY, f0: f0, lastF: f0,
        moved: false, long: false, dragging: false, acc: 0, timer: null,
        armed: !!(lastTap && e.timeStamp - lastTap.t < 380 && Math.hypot(e.clientX - lastTap.x, e.clientY - lastTap.y) < 45) };
      if (isViewLike()) pan = { t: performance.now(), vx: 0, vy: 0 };
      tp.timer = setTimeout(function () {
        if (tp && !tp.dead && !tp.moved && !locked && !serverViewOnly) {
          tp.long = true;
          if (navigator.vibrate) navigator.vibrate(30);
          ripple(tp.x0, tp.y0);
          send({ t: 'click', x: tp.f0.x, y: tp.f0.y, b: 'right' });
        }
      }, 550);
    });

    v.addEventListener('pointermove', function (e) {
      if (e.pointerType === 'mouse') {
        if (locked || serverViewOnly) return;
        var now = performance.now();
        if (now - lastMoveAt < MOVE_THROTTLE_MS) return;
        lastMoveAt = now;
        var f = frac(e);
        send({ t: 'move', x: f.x, y: f.y });
        return;
      }
      var prev = pts[e.pointerId];
      if (!prev) return;
      var ddx = e.clientX - prev.x, ddy = e.clientY - prev.y;
      pts[e.pointerId] = { x: e.clientX, y: e.clientY };

      if (isViewLike() || pinch) {
        // --- Vue : pincement = zoom, un doigt = déplacement de la vue (le pincement marche aussi en mode Souris) ---
        if (pinch && ids().length >= 2) {
          var a = pts[ids()[0]], b = pts[ids()[1]];
          var d = Math.hypot(a.x - b.x, a.y - b.y);
          var mx = (a.x + b.x) / 2, my = (a.y + b.y) / 2;
          setScale(pinch.s0 * d / pinch.d0, pinch.mx, pinch.my);   // zoom autour des doigts
          v.scrollLeft -= (mx - pinch.mx);                          // + déplacement des doigts
          v.scrollTop -= (my - pinch.my);
          pinch.mx = mx; pinch.my = my;
          return;
        }
        if (!tp || tp.dead || e.pointerId !== tp.id) return;
        var dx = e.clientX - tp.x0, dy = e.clientY - tp.y0;
        if (!tp.moved) {
          if (Math.hypot(dx, dy) <= 8) return;
          tp.moved = true;
          clearTimeout(tp.timer);
          v.scrollLeft -= dx; v.scrollTop -= dy;
        } else {
          v.scrollLeft -= ddx; v.scrollTop -= ddy;
        }
        if (pan) {
          var t = performance.now(), dt = t - pan.t;
          if (dt > 0) { pan.vx = pan.vx * 0.5 + (ddx / dt) * 0.5; pan.vy = pan.vy * 0.5 + (ddy / dt) * 0.5; }
          pan.t = t;
        }
        return;
      }

      // --- Souris : glisser = molette ; double-toucher puis glisser = cliquer-déplacer ---
      if (!tp || tp.dead || e.pointerId !== tp.id) return;
      var dx2 = e.clientX - tp.x0, dy2 = e.clientY - tp.y0;
      if (!tp.moved && Math.hypot(dx2, dy2) > 10) {
        tp.moved = true;
        clearTimeout(tp.timer);
        if (tp.armed && !tp.long) {
          tp.dragging = true;
          if (navigator.vibrate) navigator.vibrate(15);
          send({ t: 'down', x: tp.f0.x, y: tp.f0.y, b: 'left' });
        }
      }
      if (!tp.moved) return;
      if (tp.dragging) {
        tp.lastF = frac(e);
        var now2 = performance.now();
        if (now2 - lastMoveAt >= MOVE_THROTTLE_MS) {
          lastMoveAt = now2;
          send({ t: 'move', x: tp.lastF.x, y: tp.lastF.y });
        }
      } else {
        tp.acc += e.clientY - tp.ly;
        var n = Math.trunc(tp.acc / SCROLL_PX);
        if (n) { send({ t: 'wheel', d: n }); tp.acc -= n * SCROLL_PX; }
