# Tunnel Manager

Un seul fichier à lancer, une seule URL à ouvrir sur ton téléphone. Pas de terminal à toucher côté mobile.

## Mise en route (une seule fois)

1. Dézippe le dossier où tu veux sur ton PC.
2. Réserve un domaine Ngrok fixe (gratuit) :
   - Va sur ton dashboard Ngrok → **Universal Edge > Domains**
   - **+ New Domain**, choisis un nom, ex. `mon-pc-perso`
   - Tu obtiens `mon-pc-perso.ngrok-free.app`
3. Ouvre `tunnels.config.json` et colle ce domaine dans `ngrok.staticDomain` :

```json
{
  "statusServerPort": 4041,
  "ngrok": { "staticDomain": "mon-pc-perso.ngrok-free.app" },
  "tunnels": [],
  "fileBrowser": { "enabled": true, "roots": [] }
}
```

(Tu peux laisser `staticDomain` vide si tu n'as pas encore de domaine — Ngrok démarrera quand même, mais avec une URL aléatoire qui changera à chaque relance.)

## Démarrer

**Windows :** double-clique sur `start.bat`
**Linux/Mac :** `./start.sh`

Ce fichier fait tout, à chaque fois : il installe automatiquement ce qui manque la première fois, lance Ngrok, et démarre l'interface. Laisse la fenêtre ouverte tant que tu veux garder tes tunnels actifs.

## Clé d'accès (important, à lire)

Toute l'interface — gestion des tunnels **et** explorateur de fichiers — est maintenant protégée par une clé.

- Au tout premier lancement, le programme génère une clé aléatoire et l'affiche dans le terminal, en plus de l'écrire dans un fichier `access.key` créé à côté d'`index.js`.
- La première fois que tu ouvres l'URL sur ton téléphone, un écran de verrouillage te la demande. Une fois entrée, elle reste enregistrée sur ce téléphone (dans le navigateur) — tu n'as plus à la retaper.
- **Ne partage jamais** le lien Ngrok et la clé dans le même message ou au même endroit : si les deux fuitent ensemble, n'importe qui peut accéder à ton PC.
- Ne commite jamais `access.key` sur un dépôt public, et ne l'envoie à personne.
- Si tu veux forcer une nouvelle clé (par exemple si tu penses qu'elle a fuité), supprime le fichier `access.key` et relance le programme : une nouvelle sera générée. Il faudra alors la ressaisir sur tous tes appareils.

## Depuis ton téléphone

Ouvre `https://mon-pc-perso.ngrok-free.app` (ton domaine fixe) dans un navigateur, entre la clé une fois. C'est la seule adresse à retenir, mets-la en favori.

### Onglet Tunnels

- **+ Nouveau port** : donne un nom et le port local de ton programme, le tunnel démarre immédiatement
  - Coche **"Mon programme tourne en HTTPS en local"** si ton programme répond en `https://` sur ton PC (et pas en `http://`). Sans ça, le tunnel essaiera de lui parler en http et ça échouera.
- Le lien généré pour chaque tunnel, avec un bouton **Copier**
- Un badge **HTTPS** sur les tunnels concernés, pour t'y retrouver
- Un bouton **Retirer** pour fermer un tunnel

### Onglet Fichiers

Explorateur de fichiers limité aux dossiers que tu autorises explicitement (voir ci-dessous). Tu peux naviguer dedans et appuyer sur **Lancer** pour ouvrir un fichier sur le PC, comme si tu avais double-cliqué dessus.

**Configurer les dossiers accessibles** — édite `fileBrowser.roots` dans `tunnels.config.json` :

```json
"fileBrowser": {
  "enabled": true,
  "roots": [
    "C:/Users/Oniix/Desktop",
    "C:/Users/Oniix/Documents/MesProgrammes"
  ]
}
```

- Si `roots` est vide, ton dossier utilisateur complet est utilisé par défaut.
- **Recommandation :** limite `roots` aux dossiers dont tu as vraiment besoin (ex. juste le dossier contenant les programmes que tu veux lancer à distance), plutôt que tout `C:/`. Impossible de sortir de ces dossiers depuis l'interface, donc plus la liste est restreinte, plus la surface exposée est petite.
- Mets `"enabled": false` pour désactiver complètement l'explorateur si tu ne l'utilises pas.

Tout se fait depuis cette page, sans jamais retoucher au PC ni à un terminal.

## Si "Cannot find module" apparaît

Ça veut dire que les dépendances n'ont pas été installées dans ce dossier. `start.bat`/`start.sh` s'en occupe automatiquement à chaque lancement s'il détecte qu'elles manquent — donc si ça arrive quand même, vérifie que tu lances bien le `.bat`/`.sh` qui se trouve **dans le même dossier** que `index.js`, `package.json` et `tunnels.config.json` (ne les déplace pas séparément).

## Si ton programme local est en HTTPS

Si tu ouvres normalement ton programme dans le navigateur avec une adresse en `https://localhost:PORT`, alors coche la case HTTPS quand tu crées le tunnel. Sinon laisse-la décochée. Un certificat auto-signé (le genre qui affiche "connexion non sécurisée" en local) est géré automatiquement, pas besoin de rien configurer de plus.

function loadOrCreateAccessKey() {
  if (fs.existsSync(KEY_PATH)) return fs.readFileSync(KEY_PATH, 'utf8').trim();
  const key = crypto.randomBytes(24).toString('hex');
  fs.writeFileSync(KEY_PATH, key, 'utf8');
  return key;
}

function checkKey(req, res, next) {
  const provided = String(req.headers['x-access-key'] || '');
  const a = Buffer.from(provided);
  const b = Buffer.from(ACCESS_KEY);
  const valid = a.length === b.length && crypto.timingSafeEqual(a, b);
  if (!valid) return res.status(401).json({ error: 'cle invalide' });
  next();
}

// ---------- Ngrok ----------

function startNgrok() {
  const args = ['http', String(STATUS_PORT)];
  if (config.ngrok && config.ngrok.staticDomain) {
    args.push(`--url=${config.ngrok.staticDomain}`);
  }

  log('Lancement de Ngrok...');
  const ngrokProcess = spawn('ngrok', args, { shell: true });

  ngrokProcess.stdout.on('data', () => {}); // silencieux, on lit l'URL via l'API locale de ngrok
  ngrokProcess.stderr.on('data', (d) => process.stderr.write(`[ngrok] ${d}`));

  ngrokProcess.on('error', (err) => {
    ngrokError = `Ngrok introuvable (${err.message}). Vérifie qu'il est bien installé et accessible en tapant "ngrok" dans un terminal.`;
    log('ERREUR:', ngrokError);
  });

  ngrokProcess.on('exit', (code) => {
    log(`Ngrok s'est arrêté (code ${code}), relance dans 5s...`);
    ngrokPublicUrl = null;
    setTimeout(startNgrok, 5000);
  });

  setTimeout(fetchNgrokUrl, 2000);
}

async function fetchNgrokUrl(retries = 12) {
  try {
    const res = await fetch('http://127.0.0.1:4040/api/tunnels');
    const data = await res.json();
    const t = (data.tunnels || []).find((x) => x.proto === 'https') || (data.tunnels || [])[0];
    if (t) {
      ngrokPublicUrl = t.public_url;
      ngrokError = null;
      log('URL Ngrok publique :', ngrokPublicUrl);
      return;
    }
    throw new Error('pas encore de tunnel');
  } catch (err) {
    if (retries > 0) setTimeout(() => fetchNgrokUrl(retries - 1), 1500);
    else { ngrokError = "Impossible de récupérer l'URL Ngrok."; log('ERREUR:', ngrokError, err.message); }
  }
}

// ---------- Local Tunnel ----------

function nextId() {
  return Date.now().toString(36) + Math.random().toString(36).slice(2, 6);
}

async function startTunnel({ id, name, port, https }) {
  tunnels[id] = { id, name, port, https: !!https, url: null, error: null, handle: null };

  try {
    const options = { port };
    if (https) {
      options.local_https = true;
      options.allow_invalid_cert = true; // accepte les certificats auto-signés (courant en local)
    }
    const handle = await localtunnel(options);
    if (!tunnels[id]) { handle.close(); return; } // retiré entre-temps
    tunnels[id].handle = handle;
    tunnels[id].url = handle.url;
    tunnels[id].error = null;
    log(`[${name}] actif :`, handle.url);

    handle.on('close', () => {
      if (!tunnels[id]) return;
      log(`[${name}] fermé, relance dans 5s...`);
      tunnels[id].url = null;
      tunnels[id].error = 'reconnexion...';
      setTimeout(() => { if (tunnels[id]) startTunnel(tunnels[id]); }, 5000);
    });
    handle.on('error', (err) => { if (tunnels[id]) tunnels[id].error = err.message; });
  } catch (err) {
    if (!tunnels[id]) return;
    tunnels[id].error = err.message;
    log(`[${name}] échec :`, err.message, '- nouvelle tentative dans 10s');
    setTimeout(() => { if (tunnels[id]) startTunnel(tunnels[id]); }, 10000);
  }
}

function stopTunnel(id) {
  const t = tunnels[id];
  if (!t) return;
  if (t.handle) { try { t.handle.close(); } catch (e) {} }
  delete tunnels[id];
}

  .map((p) => path.resolve(p))

function isPathAllowed(target) {
  const resolved = path.resolve(target);
  return FB_ROOTS.some((root) => resolved === root || resolved.startsWith(root + path.sep));
}

function listRootsEntries() {
  return FB_ROOTS.map((root) => ({ name: root, path: root, type: 'dir', size: 0, mtime: 0 }));
}

function listDir(dirPath) {
  const entries = fs.readdirSync(dirPath, { withFileTypes: true });
  const result = [];
  for (const entry of entries) {
    if (entry.name.startsWith('.')) continue; // fichiers/dossiers cachés ignorés
    const full = path.join(dirPath, entry.name);
    let stat;
    try { stat = fs.statSync(full); } catch (e) { continue; } // lien cassé, permission refusée...
    result.push({
      name: entry.name,
      path: full,
      type: entry.isDirectory() ? 'dir' : 'file',
      size: stat.size,
      mtime: stat.mtimeMs,
    });
  }
  result.sort((a, b) => (a.type === b.type ? a.name.localeCompare(b.name) : a.type === 'dir' ? -1 : 1));
  return result;
}

function launchFile(filePath) {
  if (process.platform === 'win32') {
    // "start" ouvre le fichier avec son programme associé, comme un double-clic
    spawn('cmd.exe', ['/c', 'start', '""', filePath], { detached: true, stdio: 'ignore', windowsHide: true }).unref();
  } else if (process.platform === 'darwin') {
    spawn('open', [filePath], { detached: true, stdio: 'ignore' }).unref();
  } else {
    spawn('xdg-open', [filePath], { detached: true, stdio: 'ignore' }).unref();
  }
}

function escapeHtml(s) {
  return s.replace(/[&<>"']/g, (c) => ({ '&':'&amp;', '<':'&lt;', '>':'&gt;', '"':'&quot;', "'":'&#39;' }[c]));
}

async function loadFiles(dirPath) {
  const fbList = document.getElementById('fbList');
  const fbPathEl = document.getElementById('fbPath');
  const fbBack = document.getElementById('fbBack');
  fbList.innerHTML = '<div class="empty">Chargement...</div>';

  const url = dirPath ? '/api/fb/list?path=' + encodeURIComponent(dirPath) : '/api/fb/list';
  try {
    const res = await fetch(url, { headers: authHeaders() });
    if (res.status === 401) { logout(); return; }
    const data = await res.json();
    if (data.error) { fbList.innerHTML = '<div class="empty">' + escapeHtml(data.error) + '</div>'; return; }

    currentFbPath = data.path;
    fbPathEl.textContent = data.path || 'Dossiers autorisés';
    fbBack.innerHTML = data.parent !== undefined && data.parent !== null
      ? '<button class="btn btn-back" data-path="' + encodeURIComponent(data.parent) + '" onclick="loadFiles(decodeURIComponent(this.dataset.path))">← Retour</button>'
      : (data.path ? '<button class="btn btn-back" onclick="loadFiles(null)">← Retour</button>' : '');

    if (data.entries.length === 0) {
      fbList.innerHTML = '<div class="empty">Dossier vide.</div>';
      return;
    }

    fbList.innerHTML = data.entries.map(e => {
      const encPath = encodeURIComponent(e.path);
      if (e.type === 'dir') {
        return '<div class="file-row dir" data-path="' + encPath + '" onclick="loadFiles(decodeURIComponent(this.dataset.path))">' +
          '<div class="left"><span class="icon">📁</span><span class="name">' + escapeHtml(e.name) + '</span></div>' +
        '</div>';
      }
      return '<div class="file-row">' +
        '<div class="left"><span class="icon">📄</span><span class="name">' + escapeHtml(e.name) + '</span></div>' +
        '<button class="btn btn-launch" data-path="' + encPath + '" onclick="launchFile(decodeURIComponent(this.dataset.path))">Lancer</button>' +
      '</div>';
    }).join('');
  } catch (e) {
    fbList.innerHTML = '<div class="empty">Erreur de chargement.</div>';
  }
}

  if (!FB_ENABLED) return res.status(403).json({ error: 'Explorateur désactivé' });
  const target = req.query.path;
  if (!target) {
    return res.json({ path: null, parent: null, entries: listRootsEntries() });
  }
  if (!isPathAllowed(target)) return res.status(403).json({ error: 'Chemin non autorisé' });
  try {
    const stat = fs.statSync(target);
    if (!stat.isDirectory()) return res.status(400).json({ error: "Ce n'est pas un dossier" });
    const isRoot = FB_ROOTS.includes(path.resolve(target));
    res.json({
      path: target,
      parent: isRoot ? null : path.dirname(target),
      entries: listDir(target),
    });
  } catch (err) {
    res.status(404).json({ error: err.message });
  }
});
