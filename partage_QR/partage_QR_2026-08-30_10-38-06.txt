# Partage PC → Téléphone

Petite application de bureau pour partager des fichiers de ton PC vers ton smartphone
par QR code, sans installation compliquée côté téléphone (juste scanner avec l'appareil
photo ou un lecteur QR — aucune appli à installer sur le mobile).

## Installation automatique (Windows)

Double-clique simplement sur **`install.bat`**. Le script :

1. Vérifie si Python 3.10 ou supérieur est déjà installé (dans le PATH, via le
   lanceur `py`, ou à l'emplacement d'installation standard).
2. S'il est absent ou trop ancien, télécharge et installe automatiquement
   Python 3.10 en mode silencieux, en l'ajoutant au PATH — aucune fenêtre
   d'installation à valider manuellement.
3. Crée l'environnement virtuel dans `venv/` à côté du script.
4. Installe toutes les dépendances de `requirements.txt` dans cet environnement.

`install.bat` et `install.ps1` doivent rester dans le même dossier que `app.py`
et `requirements.txt` (c'est ce dossier qui sert de "dossier du projet").

Une fois l'installation terminée, lance l'application en double-cliquant sur
**`lancer_app.bat`**. Il utilise `pythonw.exe` (au lieu de `python.exe`), donc
aucune fenêtre d'invite de commande ne reste ouverte en arrière-plan pendant
que l'application tourne.

> **Où passent les erreurs ?** Comme `pythonw.exe` n'a pas de console, `app.py`
> détecte ce cas et redirige automatiquement les messages (démarrage du
> serveur, éventuelles erreurs) vers un fichier `app.log` créé à côté du
> script. En cas de souci (l'application ne s'ouvre pas), consulte ce fichier
> en premier.

Pour lancer l'application avec une console visible (utile pour le débogage,
avec les messages affichés en direct au lieu d'aller dans `app.log`) :

```
venv\Scripts\python.exe app.py
```

> **Remarque** : `install.bat` appelle `install.ps1` via
> `powershell -ExecutionPolicy Bypass`, donc aucune modification permanente
> de la politique d'exécution PowerShell de ta machine n'est nécessaire.
> Le téléchargement de Python se fait depuis `python.org` — une connexion
> Internet est requise uniquement si Python 3.10+ n'est pas déjà présent.

## Installation manuelle (Windows, macOS, Linux)

Il te faut Python 3.10+ installé. Ensuite, dans un terminal :

```bash
cd pc2phone
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

## Lancer l'application

```bash
python app.py
```

Une fenêtre s'ouvre avec :
1. Une **zone de glisser-déposer** (ou clic pour parcourir) pour ajouter des fichiers.
2. La **liste des fichiers** ajoutés — un clic dessus génère instantanément le QR code.
3. Un **menu déroulant "Réseau à utiliser"** listant toutes les adresses IP locales
   disponibles sur le PC, mis à jour automatiquement.
4. Le **QR code**, à scanner avec le téléphone.

Scanner le code avec l'appareil photo du téléphone ouvre directement le lien de
téléchargement dans le navigateur mobile, et le téléchargement démarre tout de suite
(le fichier est envoyé en pièce jointe, pas juste affiché).

### Sélection multiple

- **Ctrl-clic** (ou **Cmd-clic** sur Mac) / **Shift-clic** sur plusieurs fichiers de la
  liste, ou bouton **"☑ Tout sélectionner"**, pour choisir plusieurs fichiers à la fois.
- Un seul QR code est alors généré, pointant vers une **archive ZIP** créée à la volée
  par le serveur — le téléphone télécharge un unique fichier `partage.zip` contenant
  tous les fichiers sélectionnés.

### Supprimer des fichiers de la liste

- Sélectionner un ou plusieurs fichiers puis bouton **"🗑 Supprimer la sélection"**
  (ou touche `Suppr`/`Retour arrière`).
- Ou **clic droit sur un fichier précis** → "🗑 Supprimer ce fichier" pour une
  suppression individuelle rapide, sans toucher au reste de la sélection.
- La suppression ne touche qu'à la liste de partage : le fichier original reste
  intact sur le disque.

### Mise à jour automatique du réseau

Un thread d'arrière-plan vérifie les interfaces réseau toutes les 2 secondes. Si une
nouvelle adresse IP apparaît (par exemple juste après avoir activé un point d'accès
mobile), elle est ajoutée automatiquement au menu déroulant et un message
"Réseaux mis à jour ✓" s'affiche brièvement. Le choix déjà fait par l'utilisateur est
conservé tant que cette adresse reste valide — inutile de cliquer sur quoi que ce soit.

## Cas 1 — Même Wi-Fi (PC et téléphone sur le même routeur)

C'est le cas par défaut : choisis simplement l'IP correspondant à ta carte Wi-Fi/Ethernet
dans le menu déroulant (généralement affichée `Wi-Fi — 192.168.x.x` ou similaire).

## Cas 2 — Le PC crée son propre point d'accès ("wifi direct")

Il n'y a pas besoin d'implémenter du vrai Wi-Fi Direct (protocole fragile et très
dépendant du pilote réseau) : le plus simple et le plus fiable est d'utiliser la
fonctionnalité **native** de point d'accès mobile de ton OS :

- **Windows** : bouton *"📶 Activer le point d'accès"* dans l'application (ouvre
  directement `Réglages > Réseau > Point d'accès mobile`), ou manuellement via
  `Paramètres > Réseau et Internet > Point d'accès mobile`.
- **macOS** : `Réglages système > Général > Partage > Partage Internet`.
- **Linux (GNOME)** : `Paramètres > Wi-Fi > menu ⋮ > Point d'accès Wi-Fi`.

Une fois le point d'accès activé et le téléphone connecté dessus, la nouvelle IP
(souvent de la forme `192.168.137.x` sur Windows) apparaît **automatiquement** dans
le menu déroulant en quelques secondes — pas besoin de rafraîchir manuellement.
Sélectionne-la, le QR code se met à jour aussitôt.

## Notes

- Le serveur écoute sur le port `8000`. Si un pare-feu bloque les connexions entrantes,
  autorise Python (ou le port 8000) sur les réseaux privés.
- Serveur de développement Flask utilisé volontairement pour rester léger — parfait pour
  un usage ponctuel entre deux appareils personnels, à ne pas exposer sur Internet.
- Les fichiers restent sur le disque du PC ; l'app ne fait que les servir tant qu'elle
  tourne.

"""
Partage PC -> Téléphone
------------------------
Petite application de bureau légère permettant de partager des fichiers
depuis un PC vers un smartphone via QR code, sans installation compliquée.

Fonctionnement :
1. Un serveur HTTP local (Flask) tourne en arrière-plan sur le PC.
2. Une fenêtre tkinter propose une zone de glisser-déposer pour ajouter des fichiers.
3. Un clic sur un fichier (ou plusieurs, en Ctrl/Shift-clic) génère un QR code :
   - un seul fichier sélectionné -> lien de téléchargement direct de ce fichier.
   - plusieurs fichiers sélectionnés -> lien vers une archive ZIP générée à la volée.
4. En scannant le QR code avec un smartphone connecté au même réseau (wifi du routeur,
   OU point d'accès mobile lancé depuis le PC), le téléchargement démarre instantanément
   dans le navigateur du téléphone.
5. La liste des interfaces réseau/IP se met à jour automatiquement en arrière-plan
   (utile quand on active un point d'accès mobile en cours de route). Par défaut,
   l'IP du Wi-Fi local est sélectionnée automatiquement au démarrage. Et quand on
   active le point d'accès mobile depuis l'application, la sélection bascule
   automatiquement sur l'IP du point d'accès dès qu'elle apparaît.

Dépendances : voir requirements.txt
"""

import sys
import os

# Quand ce script est lance avec pythonw.exe (aucune console attachee, par
# exemple via un raccourci ou un .bat utilisant "start ... pythonw.exe"),
# sys.stdout et sys.stderr valent None. Or Flask/Werkzeug ecrivent dans ces
# flux au demarrage (banniere, logs de requetes) : sans ce garde-fou, le
# programme plante immediatement et silencieusement (aucune fenetre pour
# voir l'erreur). On redirige donc vers un fichier journal a cote du script.
if sys.stdout is None or sys.stderr is None:
    _log_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "app.log")
    _log_file = open(_log_path, "a", buffering=1, encoding="utf-8")
    sys.stdout = _log_file
    sys.stderr = _log_file

import io
import platform
import socket
import threading
import time
import uuid
import zipfile
from pathlib import Path

import psutil
import qrcode
from flask import Flask, abort, send_file
from PIL import ImageTk
import tkinter as tk
from tkinter import filedialog, ttk
from tkinterdnd2 import DND_FILES, TkinterDnD

# --------------------------------------------------------------------------
# Serveur HTTP (Flask) — sert les fichiers partagés
# --------------------------------------------------------------------------

SERVER_PORT = 8000
SHARED_FILES: dict[str, Path] = {}     # id -> chemin du fichier
BATCHES: dict[str, list[str]] = {}     # batch_id -> liste d'ids de fichiers

flask_app = Flask(__name__)


@flask_app.route("/download/<file_id>")
def download(file_id):
    path = SHARED_FILES.get(file_id)
    if not path or not path.exists():
        abort(404)
    return send_file(path, as_attachment=True, download_name=path.name)


@flask_app.route("/download-batch/<batch_id>")
def download_batch(batch_id):
    file_ids = BATCHES.get(batch_id)
    if not file_ids:
        abort(404)

    paths = [SHARED_FILES[fid] for fid in file_ids if fid in SHARED_FILES and SHARED_FILES[fid].exists()]
    if not paths:
        abort(404)

    buffer = io.BytesIO()
    used_names: dict[str, int] = {}
    with zipfile.ZipFile(buffer, "w", zipfile.ZIP_DEFLATED) as zf:
        for path in paths:
            name = path.name
            if name in used_names:
                used_names[name] += 1
                stem, suffix = os.path.splitext(name)
                name = f"{stem} ({used_names[name]}){suffix}"
            else:
                used_names[name] = 0
            zf.write(path, arcname=name)
    buffer.seek(0)

    return send_file(
        buffer,
        as_attachment=True,
        download_name="partage.zip",
        mimetype="application/zip",
    )


@flask_app.route("/")
def index():
    return "Serveur de partage actif. Scannez un QR code depuis l'application."


def run_server():
    # use_reloader=False est indispensable : le reloader Flask relance le
    # process et casse tout quand on l'appelle depuis un thread.
    flask_app.run(host="0.0.0.0", port=SERVER_PORT, threaded=True, use_reloader=False)


# --------------------------------------------------------------------------
# Détection des IP locales (routeur wifi, point d'accès mobile, Ethernet, ...)
# --------------------------------------------------------------------------

def get_local_ips() -> list[tuple[str, str]]:
    """Retourne la liste (nom_interface, adresse_ip) pour toutes les IPv4 non-loopback."""
    ips = []
    for iface, addrs in psutil.net_if_addrs().items():
        for addr in addrs:
            if addr.family == socket.AF_INET and not addr.address.startswith("127."):
                ips.append((iface, addr.address))
    return sorted(ips)


def is_wifi_iface(iface: str) -> bool:
    """Heuristique : repère la carte Wi-Fi 'normale' (le vrai adaptateur qui se
    connecte au routeur), en excluant l'adaptateur virtuel que Windows crée
    pour le point d'accès mobile (souvent nommé 'Wi-Fi Direct' ou 'Virtual')."""
    name = iface.lower()
    if "direct" in name or "virtual" in name or "hotspot" in name:
        return False
    return "wi-fi" in name or "wifi" in name or "wlan" in name or "airport" in name


def is_hotspot_candidate(iface: str, ip: str) -> bool:
    """Heuristique : repère l'interface/IP créée par le point d'accès mobile.
    Sous Windows, l'adaptateur virtuel du point d'accès distribue en général
    des IP en 192.168.137.x, avec un nom du type 'Local Area Connection* n'
    ou 'Microsoft Wi-Fi Direct Virtual Adapter'."""
    name = iface.lower()
    if ip.startswith("192.168.137."):
        return True
    return "direct" in name or "virtual" in name or "hotspot" in name or "local area connection*" in name


def open_windows_hotspot_settings():
    """Ouvre directement le panneau 'Point d'accès mobile' de Windows."""
    if platform.system() == "Windows":
        os.startfile("ms-settings:network-mobilehotspot")

    def activate_hotspot(self):
        """Ouvre les réglages du point d'accès mobile Windows, et arme la
        bascule automatique : dès que la nouvelle IP du point d'accès sera
        détectée par le watcher, elle sera sélectionnée sans action manuelle."""
        self._awaiting_hotspot = True
        self.ip_status_label.config(text="En attente du point d'accès…")
        open_windows_hotspot_settings()

    def _start_ip_watcher(self):
        """Thread d'arrière-plan qui détecte les changements d'IP (ex: activation
        d'un point d'accès mobile) et met à jour l'interface en temps réel."""
        def watch():
            while not self._stop_watcher.is_set():
                time.sleep(IP_WATCH_INTERVAL_SEC)
                current = get_local_ips()
                if current != self._last_ips:
                    # self.after() : on repasse par la boucle d'événements tkinter
                    # car les widgets ne doivent être touchés que depuis le thread principal.
                    self.after(0, self._apply_ip_list, current)

        threading.Thread(target=watch, daemon=True).start()

    def _apply_ip_list(self, ips: list[tuple[str, str]]):
        previous_ips = self._last_ips
        changed = ips != previous_ips
        self._last_ips = ips

        display = [f"{iface} — {ip}" for iface, ip in ips]
        previous_selection = self.ip_var.get()
        self.ip_combo["values"] = display
        self._ip_map = {f"{iface} — {ip}": ip for iface, ip in ips}

        # IP apparues depuis le dernier passage (utile pour repérer le point d'accès
        # au moment où il vient de s'activer, sans confondre avec une IP déjà connue).
        new_entries = [entry for entry in ips if entry not in previous_ips]

        target_display = None

        # Cas 1 : on attend le point d'accès (bouton cliqué récemment) et une
        # nouvelle IP qui y ressemble vient d'apparaître -> bascule automatique.
        if self._awaiting_hotspot:
            hotspot_candidates = [
                (iface, ip) for iface, ip in new_entries if is_hotspot_candidate(iface, ip)
            ]
            if hotspot_candidates:
                iface, ip = hotspot_candidates[0]
                target_display = f"{iface} — {ip}"
                self._awaiting_hotspot = False

        # Cas 2 : pas de bascule vers le point d'accès -> on garde le choix
        # actuel de l'utilisateur s'il est toujours valide.
        if target_display is None and previous_selection in display:
            target_display = previous_selection

        # Cas 3 : aucun choix valide encore fait (typiquement au démarrage) ->
        # on sélectionne l'IP du Wi-Fi local par défaut si elle existe, sinon
        # la première IP disponible.
        if target_display is None and display:
            wifi_candidates = [(iface, ip) for iface, ip in ips if is_wifi_iface(iface)]
            if wifi_candidates:
                iface, ip = wifi_candidates[0]
                target_display = f"{iface} — {ip}"
            else:
                target_display = display[0]

        if target_display:
            self.ip_var.set(target_display)
        else:
            self.ip_var.set("")

        if changed:
            self.ip_status_label.config(text="Réseaux mis à jour ✓")
            self.after(2000, lambda: self.ip_status_label.config(text=""))

        self.update_qr()

    def _on_close(self):
        self._stop_watcher.set()
        self.destroy()

    # ---- QR code ------------------------------------------------------------

    def update_qr(self):
        if not self.selected_file_ids:
            return
        ip = self._ip_map.get(self.ip_var.get())
        if not ip:
            return

        if self.current_batch_id:
            url = f"http://{ip}:{SERVER_PORT}/download-batch/{self.current_batch_id}"
            count = len(self.selected_file_ids)
            info_text = f"{count} fichiers sélectionnés — archive ZIP"
        else:
            file_id = self.selected_file_ids[0]
            url = f"http://{ip}:{SERVER_PORT}/download/{file_id}"
            info_text = self.files[file_id].name

        img = qrcode.make(url).resize((260, 260))
        self.qr_photo = ImageTk.PhotoImage(img)
        self.qr_label.config(image=self.qr_photo, text="")
        self.info_label.config(text=info_text)
        self.url_label.config(text=url)
        self.current_url = url

    def copy_url(self):
        if hasattr(self, "current_url"):
            self.clipboard_clear()
            self.clipboard_append(self.current_url)

function Write-Step {
    param([string]$Message)
    Write-Host ""
    Write-Host "==> $Message" -ForegroundColor Cyan
}

function Test-PythonVersion {
    <# Retourne $true si l'executable donne rapporte une version >= MinMajor.MinMinor #>
    param([string]$ExePath)
    try {
        $output = & $ExePath --version 2>&1 | Out-String
        if ($output -match '(\d+)\.(\d+)') {
            $major = [int]$Matches[1]
            $minor = [int]$Matches[2]
            if (($major -gt $MinMajor) -or ($major -eq $MinMajor -and $minor -ge $MinMinor)) {
                return $true
            }
        }
    } catch {
        return $false
    }
    return $false
}

function Find-SuitablePython {
    <#
    Cherche un interpreteur Python >= MinMajor.MinMinor deja installe.
    Retourne soit un chemin d'executable direct, soit "py|-3.X" pour indiquer
    qu'il faut passer par le lanceur 'py' avec cet argument de version.
    #>

    # 1) 'python' dans le PATH (en excluant le stub Microsoft Store, qui ne
    #    correspond pas a une vraie installation)
    $cmd = Get-Command python -ErrorAction SilentlyContinue
    if ($cmd -and $cmd.Source -notlike '*WindowsApps*' -and (Test-PythonVersion $cmd.Source)) {
        return $cmd.Source
    }

    # 2) Le lanceur 'py', installe par defaut avec Python sous Windows,
    #    qui peut donner acces a une version specifique meme si 'python'
    #    seul ne pointe pas vers elle.
    $py = Get-Command py -ErrorAction SilentlyContinue
    if ($py) {
        foreach ($minor in 13..$MinMinor) {
            try {
                $output = & $py.Source "-3.$minor" --version 2>&1 | Out-String
                if ($output -match '(\d+)\.(\d+)') {
                    $major = [int]$Matches[1]
                    $minorFound = [int]$Matches[2]
                    if (($major -gt $MinMajor) -or ($major -eq $MinMajor -and $minorFound -ge $MinMinor)) {
                        return "$($py.Source)|-3.$minor"
                    }
                }
            } catch {
                continue
            }
        }
    }

    # 3) Emplacement d'installation utilisateur standard, au cas ou le PATH
    #    de la session actuelle ne serait pas encore a jour.
    $userInstall = Join-Path $env:LOCALAPPDATA "Programs\Python\Python$MinMajor$MinMinor\python.exe"
    if ((Test-Path $userInstall -PathType Leaf) -and (Test-PythonVersion $userInstall)) {
        return $userInstall
    }

    return $null
}

function Install-Python {
    Write-Step "Python $MinMajor.$MinMinor+ introuvable. Telechargement de Python $PythonVersionToInstall..."
    $installerPath = Join-Path $env:TEMP "python-$PythonVersionToInstall-amd64.exe"
    Invoke-WebRequest -Uri $InstallerUrl -OutFile $installerPath -UseBasicParsing

    Write-Step "Installation silencieuse de Python (ajout automatique au PATH)..."
    $arguments = @(
        '/quiet',
        'InstallAllUsers=0',
        'PrependPath=1',
        'Include_launcher=1',
        'Include_test=0'
    )
    $process = Start-Process -FilePath $installerPath -ArgumentList $arguments -Wait -PassThru
    Remove-Item $installerPath -Force -ErrorAction SilentlyContinue

    if ($process.ExitCode -ne 0) {
        throw "L'installateur Python a echoue avec le code $($process.ExitCode)."
    }

    # Le PATH systeme/utilisateur est mis a jour dans le registre par
    # l'installateur, mais cette session PowerShell deja ouverte ne le
    # voit pas. On localise donc directement l'executable installe.
    $installedExe = Join-Path $env:LOCALAPPDATA "Programs\Python\Python$MinMajor$MinMinor\python.exe"
    if (-not (Test-Path $installedExe -PathType Leaf)) {
        throw "Python semble installe mais l'executable est introuvable a l'emplacement attendu : $installedExe"
    }

    Write-Step "Python $PythonVersionToInstall installe avec succes."
    return $installedExe
}

function Invoke-Python {
    <# Execute l'executable/lanceur Python retourne par Find-SuitablePython ou Install-Python #>
    param(
        [Parameter(Mandatory)][string]$PythonRef,
        [Parameter(ValueFromRemainingArguments)][string[]]$Arguments
    )
    if ($PythonRef -like '*|*') {
        $parts = $PythonRef -split '\|', 2
        & $parts[0] $parts[1] @Arguments
    } else {
        & $PythonRef @Arguments
    }
}
